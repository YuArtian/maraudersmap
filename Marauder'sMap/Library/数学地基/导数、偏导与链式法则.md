# 导数、偏导与链式法则

> 反向传播用到的全部微积分就在这一篇里。只有三个概念，且每一个都能用「动一点点，看变多少」当场验算——不需要信任任何公式

> [!note] 定位
> **这篇讲**：反向传播用到的全部微积分——导数（读成「灵敏度」）、偏导数、梯度、链式法则，以及梯度消失与爆炸的由来。全篇结论都能用「把变量加 0.001 重算一遍」当场验证，文末有六道带答案的自测题。
> **这篇不讲**：这三样工具怎么拼成反向传播的完整演算（去 [[神经网络的训练过程]] 第 5 节）；拿到梯度之后怎么更新参数（去 [[机器学习基础概念]] 第 7 节）。
> **前置**：[[向量与数量积]]（梯度是一个向量）。数学上只需要初中代数。

## TL;DR

- **导数 = 灵敏度**：这个数动一点点，结果变多少。「切线斜率」那个说法对机器学习没用，换成灵敏度就全通了
- **求导只需四条公式**，加上 ReLU 和「变量乘变量」两条特例，反向传播就够了
- **偏导数 = 只动一个变量、其他全部按住不动**。「偏」就是偏心地只看一个；记号从 $d$ 换成 $\partial$，算法完全一样
- **梯度 = 全部偏导数排成一个向量**，与参数一一对应（7B 参数 → 70 亿维梯度），指向上升最快的方向，所以下山要取负梯度
- **链式法则 = 套娃函数的灵敏度相乘**：x 动 1 使 y 动 2、y 动 1 使 z 动 3，则 x 动 1 使 z 动 6
- **导数的符号比数值更重要**：正数说明「变量增大 → 结果增大」，负数说明相反。梯度下降要的就是这个信息
- 全文每条公式后面都附了「加 0.001 硬算一遍」的验算，文末有自测题

## 1. 导数：读成「灵敏度」

### 它是一个比率

课本把导数定义成切线斜率，这个说法在机器学习里帮不上忙。真正好用的读法是：

> **导数 = 自变量动一点点时，结果变化量与自变量变化量的比率。**

### 硬算一遍

拿 $y = x^2$，看它在 $x = 3$ 附近有多「灵敏」：

```text
x = 3      → y = 9
x = 3.001  → y = 9.006001

结果变了 0.006001，自变量变了 0.001
比率 = 0.006001 / 0.001 ≈ 6
```

这个 **6** 就是 $y = x^2$ 在 $x = 3$ 处的导数。

### 求导：不必真的去试

上面那样一点点试太慢。数学家早就把各种函数的比率提前推好了，套公式即可——**「求导」就是套公式算出这个比率的过程**。$y = x^2$ 的公式是 $\frac{dy}{dx} = 2x$，代入 $x=3$ 得 6，与硬算一致。

### 四条够用的公式

| 函数 | 导数 | 怎么理解 |
| --- | --- | --- |
| 常数 $c$ | $0$ | 常数不跟着变，灵敏度为零 |
| $x$ | $1$ | x 动 1，结果就动 1 |
| $x^n$ | $n \cdot x^{n-1}$ | $x^2 \to 2x$，$x^3 \to 3x^2$ |
| $c \cdot f$ | $c \cdot f'$ | 常数倍原样保留 |
| $f + g$ | $f' + g'$ | 各项分别求导再相加 |

**应用：平方误差损失。** $L = (\hat{y} - y)^2$，其中 $y$ 是标准答案（常数）。把 $(\hat{y}-y)$ 看作整体套幂函数公式：

$$\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y)$$

预测 24、答案 10 时，这个值是 $2 \times 14 = 28$——**这是反向传播整条链的起点。**

### 符号的意义

数值大小说明「有多敏感」，**正负号说明「往哪边」**：

```text
导数 > 0  →  变量增大，结果增大   →  想让结果变小，就把变量调小
导数 < 0  →  变量增大，结果减小   →  想让结果变小，就把变量调大
导数 = 0  →  动它没有影响（可能到了谷底，也可能卡在平地上）
```

梯度下降那个减号就是从这里来的：**永远往导数的反方向走。**

### 三种等价记号

$$\frac{dy}{dx} \qquad f'(x) \qquad y'$$

意思完全一样。$\frac{dy}{dx}$ 最直观——它长得就像「y 的变化量 ÷ x 的变化量」这个比率本身。

## 2. ReLU 的导数

$\mathrm{ReLU}(z) = \max(0, z)$ 是分段函数，分段求导：

```text
z > 0  区间上 ReLU(z) = z    →  导数 = 1   （原样输出，动 1 变 1）
z < 0  区间上 ReLU(z) = 0    →  导数 = 0   （被砍成 0，怎么动都不变）
z = 0  处不可导（左右两边不一致），框架统一取 0
```

验算 $z = 6$ 处：$\mathrm{ReLU}(6.001) = 6.001$，变化量 0.001，比率 = 1 ✓

**导数为 0 这件事有实际后果**：如果某个神经元的 $z$ 长期为负，流过它的梯度会被乘上 0，它的权重就永远不再更新——这叫 **dead ReLU（神经元死亡）**。这也解释了现代大模型为什么改用 GELU、SiLU 这些在 0 附近平滑、负半轴导数不完全为 0 的变体（见 [[神经网络]] 第 4 节）。

## 3. 偏导数：多变量时只动一个

损失函数有 70 亿个自变量。这时问「导数是多少」没有意义，必须问「**对哪个**参数的导数」。

> **偏导数**：只动其中一个变量，把其他变量全部当作常数按住不动，量出来的灵敏度。

「偏」就是「偏心地只看一个」。记号从 $d$ 换成 $\partial$（读作 partial），**计算方法完全一样**——把其他变量当常数，套第 1 节那四条公式。

$L = w_1^2 + 3w_2^2$ 为例：

```text
对 w₁ 求偏导：把 3w₂² 当常数（导数 0）  →  ∂L/∂w₁ = 2w₁
对 w₂ 求偏导：把 w₁²  当常数（导数 0）  →  ∂L/∂w₂ = 6w₂
```

在 $(w_1, w_2) = (2, 1)$ 处，两个偏导分别是 4 和 6。验算前者：

```text
(2, 1)      → L = 4 + 3 = 7
(2.001, 1)  → L = 4.004001 + 3 = 7.004001
比率 = 0.004001 / 0.001 ≈ 4     ✓
```

### 反向传播只需要的两条

线性层做的事是 $z = w \cdot a + b$，其中 $w$、$a$、$b$ 都是变量。这三个偏导构成了反向传播的全部本地计算：

| 偏导 | 结果 | 记法 |
| --- | --- | --- |
| $\partial z / \partial w$ | $a$ | 对权重求导 → 得到**输入值** |
| $\partial z / \partial a$ | $w$ | 对输入求导 → 得到**权重值** |
| $\partial z / \partial b$ | $1$ | 偏置的灵敏度恒为 1 |

道理很朴素：$z = 4a$ 时 a 动 1 则 z 动 4（系数就是灵敏度）；$z = 6w$ 时 w 动 1 则 z 动 6。**「变量乘变量」对其中一个求偏导，答案就是另一个的当前值。**

## 4. 梯度：偏导数排成的向量

$$\nabla L = \left[\frac{\partial L}{\partial w_1},\ \frac{\partial L}{\partial w_2},\ \dots,\ \frac{\partial L}{\partial w_n}\right]$$

就是这样，没有别的内容。读作 nabla L 或 grad L。

- **和参数一一对应**：7B 模型的梯度是一个 70 亿维向量，每个分量对应一个参数的灵敏度
- **它是一个向量**，所以 [[向量与数量积]] 里关于向量的一切都适用
- **它是激活值那一类的数字**，不是参数——每一批样本算出来的梯度都不一样（见 [[模型里的四类数字]]）

### 为什么说它指向「上升最快的方向」

每个分量告诉你「沿这个坐标轴走，L 会涨多少」。把这些涨幅当作各方向上的分量拼成一个向量，得到的就是涨得最快的那个方向。

于是**负梯度就是降得最快的方向**，梯度下降照它走：

$$w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$$

### 走一步验算

$L = w_1^2 + 3w_2^2$，起点 $(2, 1)$，梯度 $[4, 6]$，学习率 $\eta = 0.1$：

```text
w₁ ← 2 − 0.1 × 4 = 1.6
w₂ ← 1 − 0.1 × 6 = 0.4

L 从 2² + 3×1²   = 7
  降到 1.6² + 3×0.4² = 2.56 + 0.48 = 3.04      ✓ 确实下降了
```

注意 $w_2$ 的偏导（6）大于 $w_1$ 的（4），所以它被挪得更多——**梯度自动做到了「谁影响大就多调谁」**，这是它比「所有参数一律挪同样多」高明的地方。

## 5. 链式法则：灵敏度相乘

如果 $z$ 依赖 $y$，$y$ 又依赖 $x$，那么：

$$\frac{dz}{dx} = \frac{dz}{dy} \times \frac{dy}{dx}$$

**读成一句话：x 动 1 使 y 动 2，y 动 1 使 z 动 3，那么 x 动 1 使 z 动 6。** 两级灵敏度乘起来，和齿轮的传动比相乘是同一回事。

### 验算

$y = 2x$，$z = y^2$，在 $x = 3$ 处：

```text
套公式：dy/dx = 2        dz/dy = 2y = 12        dz/dx = 12 × 2 = 24

硬算：  x = 3      → y = 6     → z = 36
        x = 3.001  → y = 6.002 → z = 36.024004
        比率 = 0.024004 / 0.001 ≈ 24            ✓
```

### 链条多长都一样

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \times \frac{\partial a}{\partial z} \times \frac{\partial z}{\partial w}$$

一路乘下去即可。**这是本篇唯一需要记住的公式**，反向传播就是它在几十层上的机械执行。

### 为什么神经网络离不开它

因为神经网络就是层层套娃的复合函数：

```text
L  依赖  ŷ
ŷ  依赖  第 2 层的权重、第 1 层的输出
第 1 层的输出  依赖  第 1 层的权重、输入 x
```

你想知道第 1 层某个权重的灵敏度 $\partial L / \partial w_1$，但它和 $L$ 之间隔着好几层，**没有直达公式**——只能用链式法则一层层乘过去。

把这三样（偏导、梯度、链式法则）拼起来，就是反向传播。完整的逐步演算见 [[神经网络的训练过程]] 第 5 节。

## 6. 梯度消失与爆炸：同一串乘法的两个方向

链式法则是**一串乘法**，每穿过一层就乘一次那层的本地导数。于是层数一多，两种失控都可能发生：

```text
每层导数 < 1（如 Sigmoid，最大 0.25）：
  10 层 → 0.25¹⁰ ≈ 0.0000010    梯度传到前面几层几乎等于 0
  → 前面的参数收不到信号，训不动             ← 梯度消失

每层导数 = 1（ReLU 正半轴）：
  10 层 → 1¹⁰ = 1               传多少层都不衰减

每层导数 > 1：
  10 层 → 连乘爆炸，参数被巨大的步长甩飞      ← 梯度爆炸
  → 靠梯度裁剪（gradient clipping）压住上限
```

**这就是 ReLU 取代 Sigmoid 的根本原因**，也是残差连接（给梯度开一条乘 1 的旁路）要解决的问题（见 [[Transformer]]）。

## 7. 记号速查

| 记号 | 读法 | 含义 |
| --- | --- | --- |
| $\frac{dy}{dx}$、$f'(x)$ | 导数 | 单变量的灵敏度 |
| $\partial$ | partial | 偏导，只动一个变量 |
| $\frac{\partial L}{\partial w}$ | L 对 w 的偏导 | 动 w 一点点，L 变多少 |
| $\nabla L$ | nabla L / grad L | 梯度，全部偏导排成的向量 |
| $\eta$ | eta | 学习率 |
| $\max(0, z)$ | | ReLU |

## 自测

每题都能在纸上算完，答案在下方。**验算方法统一是「把变量加 0.001，重算一遍，看比率」。**

1. $y = x^3$ 在 $x = 2$ 处的导数是多少？用硬算验证一遍。
2. $L = (\hat{y} - 10)^2$，当 $\hat{y} = 13$ 时 $\partial L / \partial \hat{y}$ 是多少？
3. $z = w \cdot a$，当前 $a = 5$。$\partial z / \partial w$ 是多少？$\partial z / \partial a$ 需要知道什么？
4. 某神经元当前 $z = -2$。ReLU 在这里的导数是多少？这一步它的权重会被更新吗？
5. 三层套娃：a 动 1 使 b 动 3，b 动 1 使 c 动 0.5，c 动 1 使 d 动 4。a 动 1 使 d 动多少？
6. $L = w_1^2 + 3w_2^2$ 在 $(1, 2)$ 处的梯度是多少？学习率 0.1 走一步后，$L$ 变成多少？

<br/>

> [!success]- 答案
> 1. $3x^2 = 12$。验算：$2.001^3 = 8.012006$，比率 $= 0.012006 / 0.001 \approx 12.006$ ✓
> 2. $2(\hat{y} - 10) = 2 \times 3 = 6$
> 3. $\partial z / \partial w = a = 5$；$\partial z / \partial a = w$，所以需要知道 $w$ 的当前值。**「变量乘变量」求偏导，答案是另一个的当前值**
> 4. 导数为 0。**不会被更新**——梯度乘 0 等于 0，梯度下降那一步挪动量是 0。长期如此就是 dead ReLU
> 5. $3 \times 0.5 \times 4 = 6$
> 6. 梯度 $= [2w_1,\ 6w_2] = [2, 12]$。更新后 $w_1 = 1 - 0.2 = 0.8$，$w_2 = 2 - 1.2 = 0.8$。$L$ 从 $1 + 12 = 13$ 降到 $0.64 + 3 \times 0.64 = 2.56$ ✓
