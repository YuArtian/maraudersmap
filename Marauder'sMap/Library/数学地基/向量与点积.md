# 向量与点积

> AI 世界的通用语言：一排数字、一支箭，以及衡量两支箭"像不像"的方法

## TL;DR

- **简短定义**：既有大小又有方向的量叫做向量（对比标量：只有大小）——适用于几何向量
- **一般定义**：向量 = 向量空间（满足八条公理的集合）中的元素——由"能参与哪些运算"定义，可覆盖多项式、函数、矩阵
- **坐标 ≠ 向量**：坐标是向量**在选定基下**的表示；换基则坐标变、向量不变（第 3 节）
- **长度和夹角不是自带的**：向量空间本身没有模和角，要靠额外附加的**内积**才有（第 3 节）
- **直观图景**：一排数字 ↔ 一段带方向的位移，坐标是两者的桥梁
- **名字由来**：vector 源自拉丁语"搬运者"，中文"向量"即"有方向的量"的直译
- **向量没有出发点**：只记录"怎么走"，不记录"从哪出发"（像 git 的 patch）
- **五种表示法**：字母符号 $\vec{a}$（粗体 **a**）、起点终点 $\vec{AB}$、坐标 (3,4)、列向量、模+方向角——内容等价，场合不同
- **四则运算全部逐格进行**：加 = 位移接力，减 = 算 diff，数乘 = 缩放，点积 = 夹角
- **意思藏在方向里**：语义相近 = 方向相近 = 夹角小 = 点积大（余弦相似度的由来）
- 同一模型内所有向量长度严格相等；句子变长，变的是向量个数，不是长度

## 1. 向量是什么：一排数字，也是一支箭

> 本节与第 2 节讲的是**几何向量**，中学定义在此适用。推广到多项式、函数、矩阵等对象的一般定义见第 3 节。

### 定义

> **既有大小又有方向的量叫做向量**（vector）；只有大小、没有方向的量叫做**标量**（scalar）。

这是中学教材的标准表述，也是最常用的简短定义。它针对的是平面与空间中的向量，在这个范围内完全严格——"大小和方向都相同"可以精确化为有向线段的平移等价关系，向量即等价类（见第 2 节）。

### 名字由来

物理学把量分成两种：

```text
标量（只有大小）:    温度 25°C、体重 60kg、价格 100 元
                    → 一个数字说完

向量（大小 + 方向）: 风速 "5 米/秒，朝东北"、力 "10 牛顿，往下压"
                    → 光说多大不够，还得说朝哪
```

"向量" = "有方向的量"的直译。英文 vector 源自拉丁语"搬运者"——它把你从 A 点搬到 B 点，本质是一段带方向的位移。

### 坐标是两幅面孔的桥梁

```text
  y
  4 ┤           ● (3,4)
    │         ↗
  3 ┤       ↗
    │     ↗        这支箭的两个属性:
  2 ┤   ↗          量（长度）= √(3²+4²) = 5
    │ ↗            向（方向）= 偏右上方
  0 └─┬───┬───┬── x
      1   2   3
```

描述这支箭只需说 [3, 4]——**数字排是箭的档案，箭是数字排的画像**。二维 2 个数字，三维 3 个，AI 里的 768 维就是 768 个数字：箭还在，只是插在人脑画不出的 768 维空间里，但长度、方向、夹角照常可算。

### 意思藏在方向里

词向量的世界：**语义相近 = 箭头方向相近**。

```text
        "猫" ↗
       "狗" ↗        ← 两支箭几乎同向（语义像）

  "Python" →→        ← 指向完全不同的方向
```

向量数据库里的"**余弦相似度**"，字面意思就是"夹角的余弦"——纯粹用方向算相似、忽略箭的长短。RAG 检索一次查询 = 在几百万支箭里找"和问题指向最接近的那几支"。

## 2. 向量没有出发点

```text
从 (0,0)  走到 (3,4)：右移 3，上移 4
从 (1,1)  走到 (4,5)：右移 3，上移 4
从 (-2,3) 走到 (1,7)：右移 3，上移 4

→ 三支箭画在不同位置，长度方向相同 = 同一个向量 [3,4]
```

向量描述"怎么走"（位移），不描述"你在哪"（位置），可以随意平移——数学上叫**自由向量**。

严格说法：在所有有向线段构成的集合上定义关系 ~，规定 $\overrightarrow{AB} \sim \overrightarrow{CD}$ 当且仅当 $B - A = D - C$（平移后可重合）。可验证 ~ 满足自反、对称、传递，是**等价关系**。自由向量即定义为有向线段在 ~ 下的**等价类** $[\overrightarrow{AB}]$。所以向量不是某一条具体线段，而是一整族彼此平移等价的线段——上面三行写的正是同一个等价类的三个代表元。

### 想表示一支"钉死在某处"的箭？

补上出发点即可，这叫**有向线段**：

```text
箭 = (起点, 向量)   或   (起点, 终点)

类比 git:
  向量     ≈ 一个 diff/patch（不关心应用到哪）
  有向线段 ≈ patch 应用在某个具体 commit 上（base + diff）
```

### 为什么大家默认从原点画？

约定俗成的"**位置向量**"：尾巴钉在原点，箭头恰好落在坐标 = [3,4] 的点上，于是**每支箭 ↔ 一个点**一一对应。AI 里的词向量用的就是这个视角——"猫的向量"= 768 维空间里的一个点。分工：**点的位置存含义，点与点之间的箭存关系**（见下文 king − man）。

## 3. 一般定义：向量空间与内积

### 两套定义的分工

第 1 节的"既有大小又有方向的量"是**几何向量的描述性定义**，在平面与空间（$\mathbb{R}^2$、$\mathbb{R}^3$）中完全正确且通用。本节的公理化定义不是否定它，而是**扩大外延**：

```text
几何向量（既有大小又有方向）  ⊊  向量空间的元素
```

之所以需要推广，有两个原因：

其一，**外延不够**。多项式、连续函数、矩阵的加法与数乘规律与几何向量完全一致，线性代数的整套结论（线性无关、基、维数、线性变换）对它们照样成立，但它们没有"大小和方向"可言。要把这些一并纳入，只能改用"由运算规律刻画"的定义。

其二，**逻辑上会循环**。在 $n$ 维空间里"方向"本身是靠内积定义出来的（夹角 $\cos\theta := \langle u,v\rangle/\|u\|\|v\|$，见本节末），再用"方向"去定义向量就成了循环论证。

这和"数"的概念演进是同一回事：小学的"数"是用来计数的，到了复数域这个描述不再适用，但并不意味着小学的说法是错的。**定义随适用范围扩大而抽象化，前者仍是后者的特例。**

另外要澄清的是，"向量 = 一排数字"在任何范围内都不成立——理由见下文"坐标依赖基"。

### 定义顺序：先有空间，才有向量

**向量是向量空间中的元素。** 不是先定义向量再把它们凑成空间，而是先规定一个集合连同其上的运算需要满足什么，再把该集合的元素称作向量。

设 $F$ 是一个域（通常取 $\mathbb{R}$ 或 $\mathbb{C}$），$V$ 是非空集合，其上定义了加法 $+ : V \times V \to V$ 与数乘 $\cdot : F \times V \to V$。若对任意 $u, v, w \in V$ 与任意 $a, b \in F$ 满足下列八条公理，则称 $(V, +, \cdot)$ 为 $F$ 上的**向量空间**（线性空间），其元素称为**向量**：

```text
加法部分（V 关于加法构成交换群）
  A1 结合律      (u + v) + w = u + (v + w)
  A2 交换律      u + v = v + u
  A3 零元存在    ∃ 0 ∈ V，使 v + 0 = v
  A4 负元存在    ∀v ∈ V，∃ (−v) ∈ V，使 v + (−v) = 0

数乘部分
  M1 对向量加法的分配律   a(u + v) = au + av
  M2 对标量加法的分配律   (a + b)v = av + bv
  M3 与域乘法相容        a(bv) = (ab)v
  M4 单位元作用          1·v = v      （1 是 F 的乘法单位元）
```

关键：**这八条里没有出现"大小""方向""数字""几何"中的任何一个**。向量由"能参与哪些运算、这些运算满足什么规律"定义，而不由"长什么样"定义。因此下列都是货真价实的向量空间，其中的元素都是向量，却没有一个画得出图形：

| 向量空间 | 里面的"向量"是 |
|---|---|
| $P_n$ | 次数不超过 n 的实多项式 |
| $C[0,1]$ | 区间 $[0,1]$ 上的连续函数 |
| $M_{m\times n}$ | 所有 $m \times n$ 实矩阵 |
| $\mathbb{R}^n$ | 有序实数组（最熟悉的特例） |

### 坐标依赖基的选择

设 $V$ 是 $n$ 维向量空间，$B = \{e_1, \dots, e_n\}$ 是它的一组**基**（线性无关且张成 $V$）。由基的定义可证：每个 $v \in V$ 有**唯一**表示

$$v = a_1 e_1 + a_2 e_2 + \cdots + a_n e_n$$

由此得坐标映射 $[\,\cdot\,]_B : V \to F^n,\ v \mapsto (a_1, \dots, a_n)$，可证它是**线性同构**。这才是"坐标是桥梁"的严格含义——第 4 节的五种表示法，本质上都是在这个同构下换记号。

但要害在于：**这个同构依赖基 $B$ 的选择，不是典范的。** 换一组基，同一个 $v$ 的坐标完全变了，而 $v$ 本身没有任何变化。所以准确表述是"**向量在指定基下的坐标是一排数字**"，而非"向量是一排数字"。第 10 节"不同模型的向量互相不可比"，理论根据正在于此：两个模型的 embedding 空间基不同，坐标不在同一套参照系里。

### 长度和夹角需要额外结构

八条公理里没有"长度"和"角度"。**裸的向量空间无法谈论模与夹角**，必须附加内积：

在实向量空间 $V$ 上定义 $\langle \cdot, \cdot \rangle : V \times V \to \mathbb{R}$，满足对称性、对每个变元的线性、以及正定性（$\langle v,v\rangle \ge 0$，等号仅当 $v = 0$），则称 $(V, \langle\cdot,\cdot\rangle)$ 为**内积空间**。此时才能定义

$$\|v\| := \sqrt{\langle v, v\rangle}$$

有限维实内积空间即**欧几里得空间**。$\mathbb{R}^n$ 配以标准内积 $\langle u,v\rangle = \sum_i u_i v_i$——也就是本文的点积（第 7 节）——是最常见的例子，此时 $\|v\| = \sqrt{\sum_i x_i^2}$，正是勾股定理的推广（第 4 节）。

夹角同理。高维空间里没有可直观感知的角，它是被**定义**出来的。由 **Cauchy–Schwarz 不等式**

$$|\langle u, v\rangle| \le \|u\|\,\|v\|$$

知 $\dfrac{\langle u,v\rangle}{\|u\|\|v\|} \in [-1, 1]$，于是可以合法地定义

$$\cos\theta := \frac{\langle u, v\rangle}{\|u\|\,\|v\|}, \qquad \theta \in [0, \pi]$$

**这就是余弦相似度的严格来源**：它不是"二维里长这样所以高维照搬"，而是 Cauchy–Schwarz 保证了该定义良定的结果。正交性也随之严格定义为 $\langle u, v\rangle = 0$——第 7 节"点积 ≈ 0 即互相垂直"说的就是这条，只不过那里是从几何直觉出发，这里是定义本身。

### 一句话

**向量是向量空间的元素；它在给定基下对应一个坐标数组，但该对应依赖基的选择；长度与夹角由内积额外赋予，并非向量与生俱来的属性。**

## 4. 向量的五种表示方法

同一个向量有五种常用写法，内容完全等价，只是场合不同。下面统一用同一个例子：**从点 A(1,1) 移动到点 B(4,5)**。

### 写法一：字母符号 $\vec{a}$

不需要给出具体数值、只是泛指某个向量时，用小写字母加箭头符号表示，如 $\vec{a}$；印刷体常用粗体 $\mathbf{a}$（手写不方便加粗，所以手写才用箭头符号代替）。作用类似编程里的变量名：只报名字，不带值。

### 写法二：起点 + 终点 $\vec{AB}$

把起点、终点两个字母写在一起，读作"向量 AB"，表示从 A 到 B 的位移。字母顺序有意义：前一个是起点，后一个是终点；$\vec{BA}$ 和 $\vec{AB}$ 方向相反，是另一个向量。这就是第 2 节"有向线段"的记法，几何题里最常用，因为题目给的条件就是一堆点。

### 写法三：坐标 (3, 4)

报出每个坐标轴方向上移动了多少：

$\vec{AB} = (4-1,\ 5-1) = (3,\ 4)$

规则是**终点坐标减起点坐标**，结果的含义：x 方向移动 3，y 方向移动 4。坐标是一切计算的载体——第 6 节的加减、数乘、点积全部按坐标进行。二维用 2 个数，三维用 3 个数，AI 里的 768 维向量就是 768 个数。

### 写法四：列向量（坐标竖排）

线性代数和机器学习里，坐标习惯竖着写：

```text
⎡3⎤
⎣4⎦
```

内容和 (3, 4) 完全一样。竖排的原因：矩阵乘法按"行 × 列"配对，向量竖排尺寸才对得上；需要横排时写 xᵀ（T 表示转置）。代码里对应一维数组 `np.array([3, 4])`。

### 写法五：模 + 方向角

把"多大"和"朝哪个方向"分成两个数报：

```text
模（大小） = √(3² + 4²) = 5           ← 勾股定理，第 1 节算过
方向角 θ  ：tan θ = 4/3 → θ ≈ 53°     ← 和 x 轴正方向的夹角

反过来，由模和方向角还原坐标：
x = 模·cos θ = 3，  y = 模·sin θ = 4   ← 物理课的"正交分解"
```

物理里最常见：风速报"5 米/秒，朝东北"，报的就是模和方向，不是坐标。

**模是什么**：向量的"大小"，一个不带方向的非负数。位移向量的模 = 起点到终点的直线距离；风速向量的模 = 风有多快；力向量的模 = 力有多大。记号 $|\vec{a}|$，线性代数里写 $\|\vec{a}\|$——沿用绝对值的竖线，因为做的是同一件事：数轴上 $|-3| = 3$ 抹掉方向只留大小，平面上 $|(3,4)| = 5$ 同理。**模永远非负**（平方和开根，见第 9 节）。

**光有模不够**：5 米/秒的风可以朝任意方向，模相同的向量有无数个，所以必须再补方向才算说完整。

**为什么要拆到坐标轴上**：因为"东北"是个词，不是数，没法参与运算。两个轴互不干扰（往东跑不影响往北跑了多远），所以可以分开记账、分开算、最后合起来。例：5 米/秒东北风 + 3 米/秒正东风 = ?　用词算不出来，换成坐标只是逐位相加：(3.54, 3.54) + (3, 0) = (6.54, 3.54)，模 ≈ 7.44，θ ≈ 28°，再换回人话就是"7.44 米/秒，东偏北 28°"。**模+方向适合报结果给人听，坐标适合拿去算**，中间那步换算就是两者之间的通道。

### 补充：模的公式就是勾股定理

$|\vec{a}| = \sqrt{x^2 + y^2}$ 不是新规定，是勾股定理换了个写法。

```text
勾股定理：直角三角形中，两直角边平方和 = 斜边平方
          a² + b² = c²        ← 必须是直角三角形才成立
          名字出自《周髀算经》"勾三股四弦五"：勾=短直角边，股=长直角边，弦=斜边

向量 (3,4) 的两个坐标天然构成直角三角形：
          x 分量水平、y 分量竖直，两者垂直 = 两条直角边
          模量的正是那条斜边

          3² + 4² = 5²  →  |a| = √(3²+4²) = 5
```

**为什么勾股定理成立**——用面积拼图，不需要代数技巧：

```text
边长 (a+b) 的大正方形，切出四个相同的直角三角形，
中间剩下一个边长为 c 的斜放正方形：

  大正方形面积 = (a+b)²
              = 四个三角形 + 中间正方形
              = 4 × (ab/2) + c²
              = 2ab + c²

  于是  a² + 2ab + b² = 2ab + c²
  两边减 2ab：a² + b² = c²        ← 同一块面积数两遍，一比对就出来了
```

**推广到高维**：三维只是把勾股定理用两次——先在底面算出水平方向的合成长度，再和 z 方向凑成新的直角三角形，得 $\sqrt{x^2+y^2+z^2}$。这个模式一路推下去，768 维向量的模就是 768 个数的平方和再开根号，公式长得一模一样，只是画不出来了。

顺带记几个常用整数组合：3-4-5、5-12-13、8-15-17 及其倍数。定理反过来也成立（三边满足 $a^2+b^2=c^2$ 就一定是直角三角形），古埃及人用打了 12 个等距结的绳子围出 3-4-5 三角形来量直角，就是靠这个。

### 补充：坐标的每一位都有方向含义

把 (3, 4) 拆开看：

$(3,\ 4) = 3 \times (1,\ 0) + 4 \times (0,\ 1) = 3\vec{i} + 4\vec{j}$

其中 $\vec{i} = (1, 0)$、$\vec{j} = (0, 1)$ 是 x、y 轴方向的**单位向量**（也叫基向量），这种写法叫**基向量分解**。它说明坐标不是随便一排数：**第 k 个数 = 向量在第 k 个坐标轴方向上的分量**。第 6、8 节的玩具例子给每一格标含义（王室度、跟火锅有关），标的正是"这一格对应的方向代表什么特征"。

### 五种写法速查

| 写法 | 本例中的样子 | 常用场合 |
|---|---|---|
| 字母符号 | $\vec{a}$ 或粗体 **a** | 泛指向量，不给具体数值 |
| 起点终点 | $\vec{AB}$ | 几何，强调从 A 到 B |
| 坐标 | (3, 4) | 一切具体计算 |
| 列向量 | (3, 4) 竖排 | 线性代数、机器学习 |
| 模 + 方向角 | 模 5，方向角 53° | 物理，大小和方向分开报 |

## 5. 加权求和

不同因素重要程度不同，各配一个"重要性系数"（**权重**）：

```text
面积 120 × 3    = 360   ← 权重 3，很重要
卧室 3   × 1    = 3     ← 权重 1，一般
距离 2   × 0.5  = 1     ← 权重 0.5，不太重要
─────────────────────
加起来          = 364   ← 加权求和
```

**"加权" = 各乘各的重要性系数，"求和" = 加起来。** 对比普通求和（120+3+2=125）：一视同仁，不合理。

一个神经元做的事就是"加权求和 + 激活函数"；模型"学习"学的就是这些权重（见 [[神经网络]]、[[大模型如何训练]]）。

## 6. 向量的运算：全部逐格进行

### 加法 = 位移接力

```text
[3, 4] + [1, 2] = [3+1, 4+2] = [4, 6]

        ↗ [1,2]          "右3上4"走完接着"右1上2"
      ↗ ↑                总效果 = 一步走"右4上6"
    ↗   合计 [4,6]        → 画出来是首尾相接
  ↗ [3,4]
起点
```

### 减法 = 算 diff（从 A 到 B 怎么走）

```text
diff = 终点 − 起点 = B − A

从 (1,1) 到 (4,5)：[4,5] − [1,1] = [3,4]
反向 (4,5) 到 (1,1)：[1,1] − [4,5] = [-3,-4]   ← 回程，每格取反
```

### king − man + woman ≈ queen

词向量史上最著名的算式，逐格算就能看懂（假想 3 维，真实几百维同理）：

```text
格子含义:      [王室度,  男性度,  人类度]

king  = [0.9,  0.9,  1.0]
man   = [0.1,  0.9,  1.0]
woman = [0.1,  0.1,  1.0]

diff = king − man = [0.8, 0, 0]      ← 共有成分被减掉，只剩"王室成分"
woman + diff      = [0.9, 0.1, 1.0]  ← 王室 + 女性 ≈ queen 的位置
```

同类："北京 − 中国 ≈ 巴黎 − 法国"（首都关系）、"cats − cat ≈ dogs − dog"（复数关系）。

### 运算家族一览

| 运算 | 算法 | 几何含义 | 在哪见过它 |
|---|---|---|---|
| 加法 | 逐格相加 | 位移接力 | 词向量+位置编码；残差连接 x+F(x) |
| 减法 | 逐格相减 | 从 A 到 B 的箭 | king − man 算关系 diff |
| 数乘 | 每格乘同一个数 | 方向不变，长度缩放（乘负数=调头） | 注意力里 0.87 × V |
| 点积 | 逐格相乘再求和 | 夹角/相似度 | Q·K 匹配分、RAG 检索 |

所有运算都逐格进行 → 参与运算的向量必须等长（见第 10 节）。

## 7. 点积（dot product）

**两个向量对应格子相乘、再全部加起来**，得到一个数：

```text
房子向量:  [120,   3,   2 ]
             ×     ×    ×      ← 上下对齐，各乘各的
权重向量:  [ 3,    1,  0.5]
             ↓     ↓    ↓
           360  +  3  +  1  = 364
```

三个易错点：

- **"对应位置"的"位置" = 格子编号**（第 1 格乘第 1 格），和 Transformer 的"位置编码"（词在句子里的位置）是两回事，纯属中文撞车
- 位置**不参与计算**，只决定谁跟谁配对——两队人握手，1 号跟 1 号握
- 点积是对称的，**两排数字互为权重**——点积就是加权求和的另一个名字

### 点积的几何真身：看夹角

| 点积 | 夹角 | 几何关系 | 语义关系 |
|---|---|---|---|
| > 0 | < 90° | 方向大体一致 | 相近 |
| ≈ 0 | ≈ 90° | 互相垂直 | 不相干 |
| < 0 | > 90° | 背道而驰 | 相斥倾向 |

---

## 8. 点积为什么能衡量"像不像"

玩具例子（3 个格子，假装标上含义；真实模型几千格、含义是训练自发形成的）：

```text
格子含义:        [跟吃有关, 跟火锅有关, 跟编程有关]

Q "附近的火锅店" = [1,  2,  0]
K 海底捞         = [2,  3,  0]
K 川菜馆         = [2,  1,  0]
K Python教程     = [0, -1,  2]

Q·K(海底捞) = 1×2 + 2×3 + 0×0  = 8    ← 非常匹配
Q·K(川菜馆) = 1×2 + 2×1 + 0×0  = 4    ← 沾点边
Q·K(Python) = 1×0 + 2×(-1) + 0×2 = -2 ← 毫不相干
```

一格要贡献大正数，必须**两个向量在这格上都有大数字**——"我们俩在同一特征上都很强"。点积大 = 强项重合 = 语义相近。注意力的 Q·K 匹配分（[[Transformer]]）、RAG 的相似度检索（[[Vector Database]]）算的都是它。

## 9. 负数在向量里的含义

负数是日常，不是例外，出现在三个地方：

```text
格子为负:  沿这条轴的反方向
           [3,4] 右上 ←→ [-3,-4] 左下（同一支箭调头，= 乘 −1）

diff 为负: 往回走 / 减掉某种成分
           man − king = [-0.8, 0, 0]（王室度被减掉）

点积为负:  两支箭方向相反 → 语义相斥（见第 7 节三档表）
```

唯一永远非负的是**长度**（模）= √(各格平方和)。直觉："往左走 3 步"合法，"走了负 3 步的路程"不成立——**方向可以反，路程不能负**。真实词向量里正负格子约各占一半（火锅例子的 [0,-1,2]、embedding 表里的 -0.83 都见过了）。

## 10. 向量长度的规矩

**同一模型内，所有向量长度严格相等**（这个长度叫"维度"：原始 Transformer 512，BERT-base 768，LLaMA-2 4096）。三个原因：

| 原因 | 说明 |
|---|---|
| 点积/加减法要求格子对齐 | 3 格对 5 格，多出的 2 格找谁配对？ |
| 权重矩阵尺寸固定 | 模具只接受固定尺寸的原料 |
| 残差连接要求 x+F(x) 能相加 | 对应格子相加，前后必须等长 |

**易混点：句子变长，变的是向量"个数"不是"长度"**。"我爱火锅"是 4 个向量，千字文是一千多个向量，每个都还是 768 格。数据形状 = 词数 × 维度，行数随句子变，列数永远固定。

**推论**：不同模型维度不同、坐标系不通 → 向量互相不可比 → RAG 换 embedding 模型要整库重灌。
