# 向量与数量积

> [!note] 定位
> **这篇讲**：AI 里最基础的那个数据结构——一排数字。它怎么参与运算、怎么衡量「像不像」、为什么全模型的向量必须等长。
> **这篇不讲**：矩阵和线性变换（去 [[矩阵与线性变换]]）；什么是线性函数、∑ 与下标怎么读（去 [[线性代数入门]]）；这些向量在模型里从哪查出来（去 [[Token 与 Embedding 表]]）。
> **前置**：无。全篇只用到加减乘除和一次开根号。
> 数学系那套公理化定义（向量空间八条公理、内积、Cauchy–Schwarz）**不是读 AI 笔记的必需品**，已移到文末附录，需要时再看。

## TL;DR

- **在 AI 里，向量就是一排数字**——768 维就是 768 个数。这个说法在本篇涉及的所有场景里都够用
- 它同时也是**一支箭**（一段带方向的位移）：一排数字记录「怎么走」，长度和方向都能从这排数字算出来
- **加权求和** = 各乘各的重要性系数再加起来。一个神经元做的就是这件事
- **数量积（scalar product，俗称点积）= 加权求和的另一个名字**：两个向量逐格相乘再求和，得到一个数
- **数量积的几何公式** $a \cdot b = |a||b|\cos\theta$：a 的长度 × b 在 a 方向上的投影长度；除以两个模就是余弦相似度
- **数量积衡量「像不像」**：数量积大 = 两个向量在同一批格子上都有大数值 = 强项重合 = 语义相近。注意力的匹配分、RAG 的相似度检索算的都是它
- **四则运算全部逐格进行** → 参与运算的向量必须等长
- **同一模型内所有向量长度严格相等**；句子变长，变的是向量**个数**，不是长度
- 严格说，这排数字是「向量**在选定基下的坐标**」，向量本身和坐标不是一回事——这个区分只在**比较两个不同模型的向量**时才会用到（第 6 节），完整解释在附录 B

## 1. 向量：一排数字，也是一支箭

### 在 AI 里，它就是一排数字

`[0.12, -0.34, 0.87, ...]`——768 个数排成一行，就是一个 768 维向量。代码里对应 `np.array([...])`，一维数组。

**本篇之后所有的运算都是对着这排数字做的**，不需要更多。

> 严格说，这排数字是「这个向量在某一套坐标系（**基**）下的坐标」，向量本身和它的坐标不是一回事。这个区分在一处会真正用到——**两个不同模型的向量不能互相比较**（第 6 节），理由在附录 B。除此之外，把向量当成一排数字，在本篇和后续所有 AI 笔记里都不会出错。

### 它同时是一支箭

这排数字还有个几何身份：一段**带方向的位移**。

```text
  y
  4 ┤           ● (3,4)
    │         ↗
  3 ┤       ↗
    │     ↗        这支箭的两个属性:
  2 ┤   ↗          量（长度，也叫「模」）= √(3²+4²) = 5
    │ ↗            向（方向）= 偏右上方
  0 └─┬───┬───┬── x
      1   2   3
```

描述这支箭只需说 `[3, 4]`。二维 2 个数字，三维 3 个，AI 里的 768 维就是 768 个数：箭还在，只是插在人脑画不出的 768 维空间里，但长度、方向、夹角照常可算——**算法一模一样，只是加数变多了**。

**模**就是这支箭的长度，记号 $|\vec{a}|$ 或 $\|\vec{a}\|$，等于各格平方和再开根号。它永远非负（第 5 节末尾说明为什么）。

### 意思藏在方向里

词向量的世界：**语义相近 = 箭头方向相近**。

```text
        "猫" ↗
       "狗" ↗        ← 两支箭几乎同向（语义像）

  "Python" →→        ← 指向完全不同的方向
```

向量数据库里的「**余弦相似度**」，字面意思就是「夹角的余弦」——纯粹用方向算相似、忽略箭的长短。

> 用它的地方：**RAG**（检索增强生成，先从知识库里捞出相关内容、再让模型基于这些内容作答，见 [[RAG]]）检索一次查询，就是在几百万支箭里找「和问题指向最接近的那几支」。

## 2. 加权求和：一个神经元做的事

不同因素重要程度不同，各配一个「重要性系数」（**权重**）：

```text
面积 120 × 3    = 360   ← 权重 3，很重要
卧室 3   × 1    = 3     ← 权重 1，一般
距离 2   × 0.5  = 1     ← 权重 0.5，不太重要
─────────────────────
加起来          = 364   ← 加权求和
```

**「加权」= 各乘各的重要性系数，「求和」= 加起来。** 对比普通求和（120 + 3 + 2 = 125）：一视同仁，不合理。

这是整个 AI 里最高频的一个操作。**一个神经元做的事就是「加权求和 + 偏置 + 激活函数」**，模型「学习」学的就是这批权重（见 [[神经网络]]）。

## 3. 数量积：加权求和的另一个名字

**数量积**（scalar product，也叫标量积）：**两个向量对应格子相乘、再全部加起来**，得到一个数。名称以国家标准 GB 3102.11-93 第 11-12.6 条为准；「点积」「点乘」（dot product）是按符号 $\cdot$ 起的俗称，读资料时遇到指的就是它。

```text
房子向量:  [120,   3,   2 ]
             ×     ×    ×      ← 上下对齐，各乘各的
权重向量:  [ 3,    1,  0.5]
             ↓     ↓    ↓
           360  +  3  +  1  = 364
```

和第 2 节是同一笔账——**数量积就是加权求和换了个名字**，只不过现在把「权重」也看成一个向量。

三个易错点：

- **「对应位置」的「位置」= 格子编号**（第 1 格乘第 1 格），和 Transformer 里的「位置编码」（词在句子中的第几个）是两回事，**纯属中文撞车**
- 位置**不参与计算**，只决定谁跟谁配对——两队人握手，1 号跟 1 号握
- 数量积是**对称的**：谁当权重、谁当数据，算出来一样

### 数量积的几何真身：看夹角

上面是数量积的**代数算法**。它还有一个等价的**几何公式**：

$$a \cdot b = |a|\,|b|\cos\theta$$

其中 $|a|$ 是向量 a 的**模**（长度，二维里 $|(3,4)| = \sqrt{3^2+4^2} = 5$），θ 是两支箭之间的**夹角**。

**前置：cos θ（余弦，cosine）是什么。** 直角三角形里 $\cos\theta = \text{邻边} / \text{斜边}$。换一个可操作的读法：一根长 L 的线段与某条直线成 θ 角，它落在这条直线上的**投影**（从线段两端向直线作垂线，垂足之间的那一段）长度是 $L\cos\theta$。

| θ | cos θ | 投影长度（L = 1） |
|---|---|---|
| 0° | 1 | 1，线段本来就躺在直线上 |
| 45° | ≈ 0.707 | 变短 |
| 90° | 0 | 0，线段垂直于直线 |
| 180° | −1 | 1，但落在反方向，记为负 |

**公式的读法：长度 × 投影。** 把公式拆成两半：

$$a \cdot b = |a| \times \underbrace{|b|\cos\theta}_{\text{b 在 a 方向上的投影}}$$

数量积 = a 的长度 × b 在 a 所在直线上的投影长度。它回答的是：**b 有多少成分沿着 a 的方向**。b 同向时投影最长，斜过去变短，垂直时为 0，反向时为负。

```text
  y
  │      b=(2,2)
  │     ↗
  │   ↗  θ=45°
  │ ↗
  ┼──────────→──── x     a = (3,0)
  0     2    3
  └──┬──┘
  b 的投影 = 2
```

**数值验证：两种算法得到同一个数。** 取 $a = (3, 0)$，$b = (2, 2)$：

```text
代数算法:  a·b = 3×2 + 0×2 = 6

几何公式:  |a| = 3
           |b| = √(2²+2²) = 2√2 ≈ 2.828
           θ = 45°，cos 45° = √2/2 ≈ 0.707
           投影 = |b| cos θ = 2√2 × √2/2 = 2      ← 正是 b 的 x 坐标
           a·b = 3 × 2 = 6
```

a 躺在 x 轴上，所以 b 的投影就是 b 的 x 坐标，一眼可见。

**为什么两种算法总相等（推导）。** 把整个坐标系旋转，让 a 落到 x 轴正方向上。旋转不改变箭的长度和两箭的夹角，所以公式右边 $|a||b|\cos\theta$ 不变；左边的数量积也不变（这一步此处先承认，附录 E 给出不依赖旋转的完整证明）。转好之后：

```text
a = (|a|, 0)
b = (|b| cos θ, |b| sin θ)       ← 按 cos、sin 的定义，b 与 x 轴成 θ 角
a·b = |a|×|b| cos θ + 0×|b| sin θ = |a| |b| cos θ
```

这里 θ 指两向量的夹角；第 7 节「方向角」里的 θ 是向量与 x 轴的夹角，旋转后两者恰好重合。

**余弦相似度（cosine similarity）就是这个公式的变形**：

$$\cos\theta = \frac{a \cdot b}{|a|\,|b|}$$

数量积除以两个模，长度的影响被除掉，只剩方向，结果落在 $[-1, 1]$：同向 1，垂直 0，反向 −1。例：$a=(1,2,3)$，$b=(2,4,6)$，$a\cdot b = 28$，$|a||b| = \sqrt{14}\times\sqrt{56} = 28$，余弦相似度 = 1——b 只是 a 拉长两倍，方向完全一致。第 1 节说的「纯粹用方向算相似、忽略箭的长短」，指的就是这一步除法。

由于 $|a|$、$|b|$ 恒为正，**数量积的正负完全由 cos θ 决定**，于是得到三档：

| 数量积 | 夹角 | 几何关系 | 语义关系 |
|---|---|---|---|
| > 0 | < 90° | 方向大体一致 | 相近 |
| ≈ 0 | ≈ 90° | 互相垂直 | 不相干 |
| < 0 | > 90° | 背道而驰 | 相斥倾向 |

## 4. 数量积为什么能衡量「像不像」

玩具例子：3 个格子，假装给每格标上含义（真实模型几千格，含义是训练时自发形成的，没人指定）。

> 下面出现的 **Q** 和 **K** 是注意力机制里的两组向量（完整含义见 [[Transformer]]）。这里只需要把它们当成两排普通数字：**Q 那排代表「我要找什么」，K 那排代表「我是什么」**。

```text
格子含义:        [跟吃有关, 跟火锅有关, 跟编程有关]

Q "附近的火锅店" = [1,  2,  0]
K 海底捞         = [2,  3,  0]
K 川菜馆         = [2,  1,  0]
K Python教程     = [0, -1,  2]

Q·K(海底捞) = 1×2 + 2×3 + 0×0    =  8    ← 非常匹配
Q·K(川菜馆) = 1×2 + 2×1 + 0×0    =  4    ← 沾点边
Q·K(Python) = 1×0 + 2×(-1) + 0×2 = -2    ← 毫不相干
```

一格要贡献大正数，必须**两个向量在这格上都有大数字**——「我们俩在同一个特征上都很强」。

**数量积大 = 强项重合 = 语义相近。** 注意力的 Q·K 匹配分（[[Transformer]]）和 RAG 的相似度检索（[[Vector Database]]）算的都是这个。

## 5. 向量的四则运算：全部逐格进行

### 加法 = 位移接力

```text
[3, 4] + [1, 2] = [3+1, 4+2] = [4, 6]

        ↗ [1,2]          "右3上4"走完接着"右1上2"
      ↗ ↑                总效果 = 一步走"右4上6"
    ↗   合计 [4,6]        → 画出来是首尾相接
  ↗ [3,4]
起点
```

### 减法 = 算 diff（从 A 到 B 怎么走）

```text
diff = 终点 − 起点 = B − A

从 (1,1) 到 (4,5)：[4,5] − [1,1] = [3,4]
反向 (4,5) 到 (1,1)：[1,1] − [4,5] = [-3,-4]   ← 回程，每格取反
```

### king − man + woman ≈ queen

词向量史上最著名的算式，逐格算就能看懂（假想 3 维，真实几百维同理）：

```text
格子含义:      [王室度,  男性度,  人类度]

king  = [0.9,  0.9,  1.0]
man   = [0.1,  0.9,  1.0]
woman = [0.1,  0.1,  1.0]

diff = king − man = [0.8, 0, 0]      ← 男性度和人类度两格数值相同，相减抵消，
                                        只剩下两者真正不同的那一格
woman + diff      = [0.9, 0.1, 1.0]  ← 王室 + 女性 ≈ queen 的位置
```

同类：「北京 − 中国 ≈ 巴黎 − 法国」（首都关系）、「cats − cat ≈ dogs − dog」（复数关系）。

### 负数是日常，不是例外

```text
格子为负:  沿这条轴的反方向
           [3,4] 右上 ←→ [-3,-4] 左下（同一支箭调头，= 乘 −1）

diff 为负: 往回走 / 减掉某种成分
           man − king = [-0.8, 0, 0]（王室度被减掉）

数量积为负:  两支箭方向相反 → 语义相斥（见第 3 节三档表）
```

真实词向量里正负格子约各占一半。

**唯一永远非负的是模**（长度）= √(各格平方和)：平方把符号消掉了。直觉上也说得通——「往左走 3 步」合法，「走了负 3 步的路程」不成立，**方向可以反，路程不能负**。

### 运算家族一览

| 运算 | 算法 | 几何含义 | 在哪见过它 |
|---|---|---|---|
| 加法 | 逐格相加 | 位移接力 | 词向量 + 位置编码；残差连接 x+F(x) |
| 减法 | 逐格相减 | 从 A 到 B 的箭 | king − man 算关系 diff |
| 数乘 | 每格乘同一个数 | 方向不变，长度缩放（乘负数 = 调头） | 注意力里 0.87 × V |
| 数量积 | 逐格相乘再求和 | 夹角 / 相似度 | Q·K 匹配分、RAG 检索 |

> 最右列里的**位置编码、残差连接、注意力**都是后面才讲的机制（见 [[Transformer]]），这里只是先标出「这些运算将来用在哪」，不需要现在就懂。

**所有运算都逐格进行 → 参与运算的向量必须等长**，下一节说明这条约束的后果。

## 6. 所有向量必须等长

**同一模型内，所有向量长度严格相等。** 这个长度叫「维度」——原始 Transformer 是 512，BERT-base 是 768，LLaMA-2 是 4096。

三个原因：

| 原因 | 说明 |
|---|---|
| 数量积和加减法要求格子对齐 | 3 格对 5 格，多出的 2 格找谁配对？ |
| 权重矩阵尺寸固定 | 矩阵的列数必须等于输入向量的长度，否则维数对不上 |
| 残差连接要求 x + F(x) 能相加 | 对应格子相加，前后必须等长 |

### 易混点：句子变长，变的是向量的「个数」

「我爱火锅」是 4 个向量，千字文是一千多个向量，**每个都还是 768 格**。

```text
数据形状 = 词数 × 维度
           ↑      ↑
        随句子变  永远固定
```

### 推论：换模型必须整库重灌

不同模型的维度不同，即使维度碰巧相同，**坐标系也不通**——两个模型各自学出来的基不一样，坐标不在同一套参照系里（理由见附录 B）。所以两个模型的向量**互相不可比**。

直接后果：**RAG 换 embedding 模型，整个向量库必须重新灌一遍**（见 [[Vector Database]]）。

## 7. 五种写法：读论文时认记号

同一个向量有五种常用写法，内容完全等价，只是场合不同。统一用同一个例子：**从点 A(1,1) 移动到点 B(4,5)**。

| 写法 | 本例中的样子 | 常用场合 |
|---|---|---|
| 字母符号 | $\vec{a}$ 或粗体 $\mathbf{a}$ | 泛指某个向量，不给具体数值 |
| 起点终点 | $\vec{AB}$ | 几何，强调从 A 到 B |
| 坐标 | (3, 4) | 一切具体计算 |
| 列向量 | (3, 4) 竖排 | 线性代数、机器学习 |
| 模 + 方向角 | 模 5，方向角 53° | 物理，大小和方向分开报 |

几点补充：

- **坐标**的算法是**终点坐标减起点坐标**：$\vec{AB} = (4-1,\ 5-1) = (3, 4)$
- **列向量**竖着写是因为矩阵乘法按「行 × 列」配对，向量竖排尺寸才对得上；需要横排时写 $x^\mathsf{T}$（T 表示转置）
- **模 + 方向角**：模 $= \sqrt{3^2+4^2} = 5$，方向角 $\tan\theta = 4/3 \to \theta \approx 53°$。反过来 $x = 5\cos\theta = 3$、$y = 5\sin\theta = 4$，这就是物理课的「正交分解」
- **为什么要拆到坐标轴上**：「东北」是个词不是数，没法参与运算。两个轴互不干扰，所以可以分开记账、分开算、最后合起来。**模 + 方向适合报结果给人听，坐标适合拿去算**

### 坐标的每一位都有方向含义

$(3,\ 4) = 3 \times (1,\ 0) + 4 \times (0,\ 1) = 3\vec{i} + 4\vec{j}$

其中 $\vec{i} = (1,0)$、$\vec{j} = (0,1)$ 是两个坐标轴方向上的**单位向量**（也叫**基向量**）。这说明坐标不是随便一排数：**第 k 个数 = 向量在第 k 个坐标轴方向上的分量**。第 2、4 节给每格标含义（重要性、跟火锅有关），标的正是「这一格对应的方向代表什么特征」。

> 2. $120{\times}3 + 3{\times}1 + 2{\times}(-2) = 360 + 3 - 4 = \mathbf{359}$。
> 3. 因为 king 和 man 在「男性度」「人类度」这两格上**数值相同**，相减时被抵消成 0，只剩下两者真正不同的那一格（王室度 0.9 − 0.1 = 0.8）。减法提取的是**差异**，共有成分自动消失。
> 4. $\mathbf{4 \times 768}$；$\mathbf{1000 \times 768}$。行数随句子长度变，列数永远是 768。
> 5. **不能。** 维度相同不代表坐标系相同——两个模型各自学出来的基不一样，坐标不在同一套参照系里（附录 B）。这正是 RAG 换 embedding 模型必须整库重灌的原因。
> 6. $\sqrt{(-3)^2 + (-4)^2} = \sqrt{25} = \mathbf{5}$。模是**平方和开根号**，平方把负号消掉了；几何上也说得通——方向可以反，路程不能负。
> 7. 代数：$4{\times}3 + 0{\times}3 = \mathbf{12}$。几何：$|a| = 4$，$|b| = \sqrt{18} = 3\sqrt2$，θ = 45°，$4 \times 3\sqrt2 \times \tfrac{\sqrt2}{2} = 4 \times 3 = \mathbf{12}$。投影长度 = $|b|\cos 45° = \mathbf{3}$，即 b 的 x 坐标。
> 8. 第一组：数量积 $-2$，模之积 $1 \times 2 = 2$，余弦相似度 $\mathbf{-1}$（反向）。第二组：数量积 $1{\times}2 + 2{\times}(-1) = 0$，余弦相似度 $\mathbf{0}$（垂直）。

## 附录：可以不读的部分

下面几节不影响读任何一篇 AI 笔记。A 是几何上的严格化，B 是数学系的公理化定义，C 是一个初中定理的证明，D 是词源，E 是数量积几何公式的完整证明，F 是机器学习里基本用不到的向量积。**它们照样讲透，只是不该挡在主线上。**

### A. 向量没有出发点

```text
从 (0,0)  走到 (3,4)：右移 3，上移 4
从 (1,1)  走到 (4,5)：右移 3，上移 4
从 (-2,3) 走到 (1,7)：右移 3，上移 4

→ 三支箭画在不同位置，长度方向相同 = 同一个向量 [3,4]
```

向量描述「怎么走」（位移），不描述「你在哪」（位置），可以随意平移——数学上叫**自由向量**。

严格说法：在所有有向线段构成的集合上定义关系 ~，规定 $\overrightarrow{AB} \sim \overrightarrow{CD}$ 当且仅当 $B - A = D - C$（平移后可重合）。可验证 ~ 满足自反、对称、传递，是**等价关系**。自由向量即定义为有向线段在 ~ 下的**等价类** $[\overrightarrow{AB}]$——所以向量不是某一条具体线段，而是一整族彼此平移等价的线段，上面三行正是同一个等价类的三个代表元。

**想表示一支「钉死在某处」的箭**，补上出发点即可，这叫**有向线段**：

```text
箭 = (起点, 向量)   或   (起点, 终点)

对照 git：向量 ≈ 一个 diff/patch（不关心应用到哪）
          有向线段 ≈ patch 应用在某个具体 commit 上（base + diff）
```

**为什么大家默认从原点画**：约定俗成的「**位置向量**」——尾巴钉在原点，箭头恰好落在坐标 (3,4) 的点上，于是每支箭 ↔ 一个点一一对应。AI 里的词向量用的就是这个视角：「猫的向量」= 768 维空间里的一个点。分工是**点的位置存含义，点与点之间的箭存关系**（第 5 节的 king − man）。

### B. 一般定义：向量空间与内积

正文说「向量就是一排数字」，够用但不严格。这里给出数学上的定义，以及正文第 6 节「两个模型的向量不可比」的理论根据。

**为什么需要推广**。第 1 节那个「既有大小又有方向的量」是**几何向量的描述性定义**，在平面与空间中完全正确。推广有两个理由：

其一，**外延不够**。多项式、连续函数、矩阵的加法与数乘规律与几何向量完全一致，线性代数的整套结论（线性无关、基、维数、线性变换）对它们照样成立，但它们没有「大小和方向」可言。

其二，**逻辑上会循环**。在 $n$ 维空间里「方向」本身是靠内积定义出来的（夹角 $\cos\theta := \langle u,v\rangle/\|u\|\|v\|$，见本节末），再用「方向」去定义向量就成了循环论证。

**定义：先有空间，才有向量。** 不是先定义向量再把它们凑成空间，而是先规定一个集合连同其上的运算需要满足什么，再把该集合的元素称作向量。

设 $F$ 是一个域（通常取实数集 $\mathbb{R}$ 或复数集 $\mathbb{C}$），$V$ 是非空集合，其上定义了加法与数乘。若对任意 $u, v, w \in V$ 与任意 $a, b \in F$ 满足下列八条公理，则称 $V$ 为 $F$ 上的**向量空间**（线性空间），其元素称为**向量**：

```text
加法部分（V 关于加法构成交换群）
  A1 结合律      (u + v) + w = u + (v + w)
  A2 交换律      u + v = v + u
  A3 零元存在    ∃ 0 ∈ V，使 v + 0 = v
  A4 负元存在    ∀v ∈ V，∃ (−v) ∈ V，使 v + (−v) = 0

数乘部分
  M1 对向量加法的分配律   a(u + v) = au + av
  M2 对标量加法的分配律   (a + b)v = av + bv
  M3 与域乘法相容        a(bv) = (ab)v
  M4 单位元作用          1·v = v
```

关键：**这八条里没有出现「大小」「方向」「数字」「几何」中的任何一个。** 向量由「能参与哪些运算、这些运算满足什么规律」定义，而不由「长什么样」定义。因此下列都是货真价实的向量空间，其中的元素都是向量，却没有一个画得出图形：次数不超过 $n$ 的实多项式、区间 $[0,1]$ 上的连续函数、所有 $m \times n$ 实矩阵，以及最熟悉的特例——有序实数组 $\mathbb{R}^n$。

**坐标依赖基的选择——这是正文第 6 节的理论根据。** 设 $B = \{e_1, \dots, e_n\}$ 是 $n$ 维空间 $V$ 的一组**基**（线性无关且张成 $V$）。每个 $v \in V$ 有唯一表示

$$v = a_1 e_1 + a_2 e_2 + \cdots + a_n e_n$$

由此得坐标映射 $v \mapsto (a_1, \dots, a_n)$，可证它是**线性同构**。但要害在于：**这个同构依赖基 $B$ 的选择，不是典范的。** 换一组基，同一个 $v$ 的坐标完全变了，而 $v$ 本身没有任何变化。

所以最准确的表述是「**向量在指定基下的坐标是一排数字**」。正文把它简化成「向量就是一排数字」，在**单个模型内部**永远不会出错——因为那时基是固定的；只有跨模型比较时这个简化才失效，因为两个模型的 embedding 空间基不同。

**长度和夹角需要额外结构。** 八条公理里没有「长度」和「角度」，裸的向量空间无法谈论模与夹角，必须附加**内积**：在实向量空间上定义 $\langle \cdot, \cdot \rangle$，满足对称性、对每个变元的线性、以及正定性，此时才能定义 $\|v\| := \sqrt{\langle v, v\rangle}$。

$\mathbb{R}^n$ 配以标准内积 $\langle u,v\rangle = \sum_i u_i v_i$——**也就是正文第 3 节的数量积**——是最常见的例子，此时 $\|v\| = \sqrt{\sum_i x_i^2}$，正是勾股定理的推广（附录 C）。

夹角同理：高维空间里没有可直观感知的角，它是被**定义**出来的。由 **Cauchy–Schwarz 不等式** $|\langle u, v\rangle| \le \|u\|\,\|v\|$ 知比值落在 $[-1, 1]$，于是可以合法地定义

$$\cos\theta := \frac{\langle u, v\rangle}{\|u\|\,\|v\|}, \qquad \theta \in [0, \pi]$$

**这就是余弦相似度的严格来源**：它不是「二维里长这样所以高维照搬」，而是 Cauchy–Schwarz 保证了该定义良定的结果。正交性也随之严格定义为 $\langle u, v\rangle = 0$——正文第 3 节「数量积 ≈ 0 即互相垂直」说的就是这条，只不过那里从几何直觉出发，这里是定义本身。

**一句话**：向量是向量空间的元素；它在给定基下对应一个坐标数组，但该对应依赖基的选择；长度与夹角由内积额外赋予，并非向量与生俱来的属性。

### C. 模的公式就是勾股定理

$|\vec{a}| = \sqrt{x^2 + y^2}$ 不是新规定，是勾股定理换了个写法。

```text
勾股定理：直角三角形中，两直角边平方和 = 斜边平方
          a² + b² = c²
          名字出自《周髀算经》"勾三股四弦五"：勾=短直角边，股=长直角边，弦=斜边

向量 (3,4) 的两个坐标天然构成直角三角形：
          x 分量水平、y 分量竖直，两者垂直 = 两条直角边
          模量的正是那条斜边          3² + 4² = 5²
```

**为什么勾股定理成立**——用面积拼图，不需要代数技巧：

```text
边长 (a+b) 的大正方形，切出四个相同的直角三角形，
中间剩下一个边长为 c 的斜放正方形：

  大正方形面积 = (a+b)²
              = 四个三角形 + 中间正方形
              = 4 × (ab/2) + c²  =  2ab + c²

  于是  a² + 2ab + b² = 2ab + c²
  两边减 2ab：a² + b² = c²        ← 同一块面积数两遍，一比对就出来了
```

**推广到高维**：三维只是把勾股定理用两次——先在底面算出水平方向的合成长度，再和 z 方向凑成新的直角三角形，得 $\sqrt{x^2+y^2+z^2}$。这个模式一路推下去，768 维向量的模就是 768 个数的平方和再开根号，公式长得一模一样，只是画不出来了。

### D. 「向量」这个名字

物理学把量分成两种：**标量**（scalar）只有大小，如温度 25°C、体重 60kg；**向量**（vector）有大小也有方向，如风速「5 米/秒，朝东北」。

「向量」是「有方向的量」的直译。英文 vector 源自拉丁语「搬运者」——它把你从 A 点搬到 B 点，本质是一段带方向的位移。

### E. 数量积几何公式的完整证明（不依赖旋转）

第 3 节的推导承认了「旋转不改变数量积」。这里用**余弦定理**（law of cosines）给一个只靠坐标的证明。余弦定理：三角形两边长 p、q，夹角 θ，第三边长 r，则 $r^2 = p^2 + q^2 - 2pq\cos\theta$（θ = 90° 时 cos θ = 0，退化成勾股定理）。

a、b 从同一点出发，第三边就是 $a - b$。对它的长度平方算两遍：

```text
按余弦定理:  |a−b|² = |a|² + |b|² − 2|a||b| cos θ

按坐标展开:  |a−b|² = Σ(aᵢ − bᵢ)²
                    = Σaᵢ² + Σbᵢ² − 2Σaᵢbᵢ
                    = |a|² + |b|² − 2(a·b)

两式相等，消去 |a|² + |b|²，两边除以 −2：
             a·b = |a||b| cos θ
```

任意维度都成立，因为坐标展开那一步对多少个分量都一样。

### F. 向量积：三维专属的另一种向量乘法

**向量积**（vector product，也叫矢量积；俗称叉积、叉乘，cross product）只对**三维**向量定义，结果是一个**新向量**，不是数。名称以 GB 3102.11-93 第 11-12.7 条为准。部分教材把它叫「外积」，不规范：规范用法里「外积」指外代数的 $a \wedge b$，是另一种运算。

$$a \times b = (a_2b_3 - a_3b_2,\; a_3b_1 - a_1b_3,\; a_1b_2 - a_2b_1)$$

```text
a = (1, 2, 3), b = (4, 5, 6)
a × b = (2×6 − 3×5, 3×4 − 1×6, 1×5 − 2×4) = (−3, 6, −3)

验证垂直:  (−3,6,−3)·a = −3 + 12 − 9  = 0
           (−3,6,−3)·b = −12 + 30 − 18 = 0
```

| 性质 | 数量积 $a \cdot b$ | 向量积 $a \times b$ |
|---|---|---|
| 结果 | 一个数 | 一个三维向量 |
| 适用维度 | 任意维，只要等长 | 只有三维 |
| 几何量 | $\|a\|\|b\|\cos\theta$，投影 | 长度 $\|a\|\|b\|\sin\theta$ = 以 a、b 为邻边的平行四边形面积 |
| 方向 | 无 | 同时垂直于 a 和 b，按右手定则（四指从 a 弯向 b，拇指所指） |
| 交换律 | $a\cdot b = b \cdot a$ | $a \times b = -(b \times a)$ |
| 用在哪 | 相似度、加权求和、注意力 | 物理（力矩）、图形学（求平面法向量） |

上例长度验证：$|a \times b| = \sqrt{9+36+9} = \sqrt{54}$；另一边 $|a|^2 = 14$，$|b|^2 = 77$，$a \cdot b = 32$，$|a|^2|b|^2\sin^2\theta = |a|^2|b|^2 - (a\cdot b)^2 = 1078 - 1024 = 54$，两边一致。

机器学习里的向量动辄几百维，向量积没有定义，所以 AI 笔记里**不会出现向量积**。中文口语里有人把矩阵乘法叫「叉乘」，那是不规范的叫法，与这里的向量积无关（见 [[矩阵与线性变换]] 第 2 节的规范名称与俗称对照）。
