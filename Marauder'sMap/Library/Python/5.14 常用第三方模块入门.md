## 1. Pillow：Python 图像处理

PIL (Python Imaging Library) 是 Python 事实上的图像处理标准库，但只支持到 Python 2.7。**Pillow** 是社区维护的兼容分支，支持 Python 3 并增加了新特性。

```bash
pip install pillow
```

API 仍然叫 `PIL`：

```python
from PIL import Image
```

### 1.1 基础：读、看、写

```python
from PIL import Image

im = Image.open('test.jpg')

# 元信息
print(im.size)        # (1920, 1080)
print(im.format)      # 'JPEG'
print(im.mode)        # 'RGB'

# 显示（弹出系统图片查看器）
im.show()

# 保存（自动按扩展名识别格式）
im.save('out.png')
```

### 1.2 常见操作

```python
# 缩放（保持比例，原地修改）
im.thumbnail((640, 360))

# 裁剪
box = (100, 100, 400, 400)   # (left, top, right, bottom)
cropped = im.crop(box)

# 旋转
rotated = im.rotate(90, expand=True)   # expand 自动调整画布

# 颜色模式转换
gray = im.convert('L')        # 'L' 灰度、'RGB'、'RGBA'、'CMYK'

# 像素级访问
pixel = im.getpixel((100, 100))   # (R, G, B)
im.putpixel((100, 100), (255, 0, 0))
```

### 1.3 滤镜

```python
from PIL import Image, ImageFilter

im = Image.open('test.jpg')
blurred = im.filter(ImageFilter.BLUR)
blurred.save('blur.jpg', 'jpeg')
```

常用滤镜：

| 滤镜 | 作用 |
|---|---|
| `BLUR` | 高斯模糊 |
| `CONTOUR` | 描边 |
| `DETAIL` | 增强细节 |
| `EDGE_ENHANCE` | 边缘增强 |
| `EMBOSS` | 浮雕 |
| `SHARPEN` | 锐化 |
| `SMOOTH` | 平滑 |

参数化滤镜：

```python
im.filter(ImageFilter.GaussianBlur(radius=5))
im.filter(ImageFilter.UnsharpMask(radius=2, percent=150))
```

### 1.4 文字与绘图：生成验证码

```python
from PIL import Image, ImageDraw, ImageFont, ImageFilter
import random

def rndChar():
    return chr(random.randint(65, 90))   # A-Z

def rndColor():
    return (random.randint(64, 255),
            random.randint(64, 255),
            random.randint(64, 255))

def rndColor2():
    return (random.randint(32, 127),
            random.randint(32, 127),
            random.randint(32, 127))

width, height = 60 * 4, 60
image = Image.new('RGB', (width, height), (255, 255, 255))
font = ImageFont.truetype('/Library/Fonts/Arial.ttf', 36)
draw = ImageDraw.Draw(image)

# 随机像素背景
for x in range(width):
    for y in range(height):
        draw.point((x, y), fill=rndColor())

# 4 个随机字符
for t in range(4):
    draw.text((60 * t + 10, 10), rndChar(), font=font, fill=rndColor2())

image = image.filter(ImageFilter.BLUR)
image.save('captcha.jpg', 'jpeg')
```

```text
┌──────────────────────┐
│  随机彩色噪点背景       │
│                      │
│   W   Y   J   G       │  ← 随机字母，每个不同颜色
│                      │
│  (模糊滤镜让边缘柔和)   │
└──────────────────────┘
```

### 1.5 常见陷阱

| 坑 | 解决 |
|---|---|
| `IOError: cannot open resource` | 字体文件找不到，给绝对路径如 `/Library/Fonts/Arial.ttf` (mac) 或 `C:/Windows/Fonts/Arial.ttf` (Win) |
| 保存 JPEG 时背景变黑 | RGBA 模式有透明通道，JPEG 不支持——先 `im.convert('RGB')` |
| `thumbnail` 改了原图但返回 None | 它是**原地操作**，不返回值 |
| 内存爆炸 | 大图先 `im.thumbnail((max_w, max_h))` 再处理 |

### 1.6 现代替代

| 库 | 何时用 |
|---|---|
| `Pillow` | 一般图像处理（缩放/裁剪/滤镜）|
| `opencv-python` | 计算机视觉（检测/追踪/OCR 预处理）|
| `imageio` | 多帧动画、GIF、视频帧 |
| `Wand` | 调 ImageMagick，做 PDF/SVG 转图像 |

## 2. chardet：检测字节流的编码

```bash
pip install chardet
```

爬来的网页字节流不知道是什么编码？不能直接 `.decode('utf-8')`——`chardet` 帮你猜。

### 2.1 基本用法

```python
import chardet

chardet.detect(b'Hello, world!')
# {'encoding': 'ascii', 'confidence': 1.0, 'language': ''}
```

返回 dict：

| 字段 | 含义 |
|---|---|
| `encoding` | 检测到的编码名 |
| `confidence` | 置信度 0.0 ~ 1.0 |
| `language` | 推断的语言（中文/日文/...）|

### 2.2 多语言示例

```python
# 中文 GBK
data = '离离原上草，一岁一枯荣'.encode('gbk')
chardet.detect(data)
# {'encoding': 'GB2312', 'confidence': 0.74, 'language': 'Chinese'}
# 注：GBK 是 GB2312 超集，识别成 GB2312 也能正确解码

# 中文 UTF-8
data = '离离原上草，一岁一枯荣'.encode('utf-8')
chardet.detect(data)
# {'encoding': 'utf-8', 'confidence': 0.99, 'language': ''}

# 日文 EUC-JP
data = '最新の主要ニュース'.encode('euc-jp')
chardet.detect(data)
# {'encoding': 'EUC-JP', 'confidence': 0.99, 'language': 'Japanese'}
```

### 2.3 实战模式

```python
import chardet

def decode_safely(raw: bytes) -> str:
    """先尝试 UTF-8，失败再用 chardet 猜"""
    try:
        return raw.decode('utf-8')
    except UnicodeDecodeError:
        guess = chardet.detect(raw)
        encoding = guess['encoding'] or 'utf-8'
        return raw.decode(encoding, errors='replace')
```

### 2.4 大文件优化

`chardet.detect()` 会扫描整段字节——大文件 (几百 MB) 会卡。用 `UniversalDetector` 增量探测，置信度够高就提前结束：

```python
from chardet.universaldetector import UniversalDetector

detector = UniversalDetector()
with open('huge.txt', 'rb') as f:
    for line in f:
        detector.feed(line)
        if detector.done:
            break
detector.close()
print(detector.result)
```

### 2.5 局限

- **不是 100% 准确**——尤其短字符串（"abc" 可能识别成不止一种编码）
- 多种编码字节范围重叠时（GBK / Big5 / EUC-CN）容易猜错
- 真正可信的做法：HTTP 头有 `Content-Type: ...; charset=...` 优先用它；HTML 里 `<meta charset>` 次之；都没有再用 chardet

`requests` 库其实内部就会用 chardet 自动检测：

```python
import requests
r = requests.get(url)
r.encoding      # 'utf-8' -- requests 自动检测的结果
r.text          # 用 encoding 解码后的字符串
```

## 3. psutil：获取系统信息

**p**rocess and **s**ystem **util**ities——跨平台获取 CPU/内存/磁盘/网络/进程信息。Linux 的 `ps` / `top` / `free` 用 Python 写一遍：

```bash
pip install psutil
```

### 3.1 CPU 信息

```python
import psutil

psutil.cpu_count()                    # 4    -- 逻辑核数
psutil.cpu_count(logical=False)        # 2    -- 物理核数

psutil.cpu_times()
# scputimes(user=10963.31, nice=0.0, system=5138.67, idle=356102.45)

psutil.cpu_percent(interval=1)         # 5.3  -- 整体 CPU 使用率（1 秒采样）
psutil.cpu_percent(interval=1, percpu=True)
# [14.0, 4.0, 4.0, 4.0]                -- 每个核单独
```

### 3.2 内存信息

```python
mem = psutil.virtual_memory()
# svmem(total=8589934592, available=2866520064, percent=66.6, ...)

mem.total      # 8 GB（字节数）
mem.percent    # 66.6  使用率

swap = psutil.swap_memory()
# sswap(total=1073741824, used=150732800, ...)
```

格式化输出：

```python
def gb(n):
    return f'{n / 1024**3:.1f} GB'

print(f'Memory: {gb(mem.used)} / {gb(mem.total)} ({mem.percent}%)')
# Memory: 6.7 GB / 8.0 GB (66.6%)
```

### 3.3 磁盘信息

```python
psutil.disk_partitions()
# [sdiskpart(device='/dev/disk1', mountpoint='/', fstype='hfs', ...)]

psutil.disk_usage('/')
# sdiskusage(total=998982549504, used=390880133120, free=607840272384, percent=39.1)

psutil.disk_io_counters()
# sdiskio(read_count=988513, write_count=274457,
#         read_bytes=14856830464, write_bytes=17509420032, ...)
```

### 3.4 网络信息

```python
psutil.net_io_counters()
# snetio(bytes_sent=3885744870, bytes_recv=10357676702, ...)

psutil.net_if_addrs()                 # 所有网卡的地址
psutil.net_if_stats()                  # 网卡状态（is_up / mtu / speed）

# 当前 TCP/UDP 连接（需要 root/管理员权限！）
psutil.net_connections()
```

> 拿不到连接信息？通常是 macOS/Linux 下需要 `sudo` 跑。

### 3.5 进程信息：相当于 `ps` 命令

```python
psutil.pids()                          # 所有进程 PID 列表

p = psutil.Process(3776)              # 拿到某个进程
p.name()                               # 'python3'
p.exe()                                # '/usr/local/bin/python3'
p.cwd()                                # '/Users/me'
p.cmdline()                            # ['python3', 'app.py']
p.ppid()                               # 父进程 PID
p.parent()                             # 父进程对象
p.children()                           # 子进程列表
p.status()                             # 'running' / 'sleeping' / ...
p.username()                           # 'me'
p.create_time()                        # 1511052731.12 (Unix 时间)
p.cpu_times()                          # pcputimes(user=..., system=...)
p.memory_info()                        # pmem(rss=..., vms=...)
p.open_files()                         # 打开的文件
p.connections()                        # 该进程的网络连接
p.num_threads()                        # 线程数
p.threads()                            # 每个线程详情
p.environ()                            # 环境变量
p.terminate()                          # 发 SIGTERM
p.kill()                               # 发 SIGKILL
```

### 3.6 实战：写一个简单的 top

```python
import psutil, time, os

def top():
    while True:
        os.system('clear')
        cpu = psutil.cpu_percent(interval=0)
        mem = psutil.virtual_memory()
        print(f'CPU: {cpu}%   MEM: {mem.percent}%\n')
        print(f'{"PID":>6} {"NAME":<20} {"CPU%":>6} {"MEM%":>6}')
        procs = sorted(psutil.process_iter(['pid', 'name', 'cpu_percent', 'memory_percent']),
                       key=lambda p: p.info['cpu_percent'] or 0,
                       reverse=True)[:10]
        for p in procs:
            info = p.info
            print(f'{info["pid"]:>6} {info["name"][:20]:<20} '
                  f'{info["cpu_percent"]:>6.1f} {info["memory_percent"]:>6.1f}')
        time.sleep(1)

top()
```

50 行不到的 `top` 实现。

### 3.7 何时用 psutil

| 场景 | 用 |
|---|---|
| 监控脚本（看 CPU/内存超阈值告警）| ✓ |
| 自动化运维（找特定进程、kill 它）| ✓ |
| 开发时打 perf 指标 | ✓ |
| Linux/Mac 独占环境 | 也可以——但 stdlib `os` / `resource` 部分也够用 |
| 真正的生产监控 | 用 Prometheus + node_exporter 等专业方案，不是 Python |

## 6. 几个工程经验

| 建议 | 原因 |
|---|---|
| **版本固定**：`requirements.txt` 或 `pyproject.toml` | 否则部署到生产时拉到新版可能挂 |
| **看 GitHub Stars + 最近 commit** | 找包时先看活跃度，停更包别用 |
| **小心 typosquatting** | `requestes`（拼错）可能是恶意包——确认 PyPI 上的官方页面 |
| **选 Pure Python 优先** | 带 C 扩展的包在 ARM Mac / Windows 上经常装不上 |
| **生产环境用 venv / poetry / pdm 隔离** | 别污染系统 Python |
