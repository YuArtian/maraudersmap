# 变量与作用域

## TL;DR

**Python 不需要声明变量，直接赋值即可，作用域按 LEGB 规则查找。** 核心要点：

- 没有 `let` / `const` / `var`，直接 `x = 10` 就是变量
- LEGB 查找顺序：Local → Enclosing → Global → Built-in
- **没有块级作用域**，`if` / `for` 不形成作用域
- 函数内修改外层变量要用 `global` / `nonlocal`

---

## 1. 变量直接赋值

```python
a = 10                  # 直接用，类型也不写
name = 'Bob'
items = [1, 2, 3]
```

```javascript
// JS 必须先声明
let a = 10
const name = 'Bob'
```

| | Python | JavaScript |
|---|---|---|
| 声明 | 不需要 | `let` / `const` / `var` |
| 类型 | 不写 | 不写（TS 写） |

---

## 2. LEGB 规则

Python 查找变量时，按这个顺序找：

```text
L  →  E  →  G  →  B
Local  Enclosing  Global  Built-in
（局部）  （外层函数）  （全局）  （内置）
```

```python
# G (Global) -- 模块顶层
x = 'global'

def outer():
    # E (Enclosing) -- 外层函数
    x = 'enclosing'

    def inner():
        # L (Local) -- 当前函数
        x = 'local'
        print(x)   # 'local' -- 先在 L 找到了

    inner()

outer()
```

完整示意图：

```text
┌─────────────────────────────────────┐
│  Built-in（print, len, abs...）      │
│  ┌────────────────────────────────┐ │
│  │  Global（模块顶层）              │ │
│  │  ┌──────────────────────────┐  │ │
│  │  │  Enclosing（外层函数）     │  │ │
│  │  │  ┌────────────────────┐  │  │ │
│  │  │  │  Local（当前函数）   │  │  │ │
│  │  │  │  → 查找从这里开始    │  │  │ │
│  │  │  └────────────────────┘  │  │ │
│  │  └──────────────────────────┘  │ │
│  └────────────────────────────────┘ │
└─────────────────────────────────────┘
```

从内向外查找，找到就停，找不到 → `NameError`。

## 3. 没有块级作用域

`if` / `for` / `while` 不形成作用域：

```python
if True:
    x = 10
print(x)   # 10，能访问

for i in range(3):
    pass
print(i)   # 2，循环变量也能在外面访问
```

只有**函数**和**类**形成作用域：

```python
def foo():
    y = 20
print(y)   # NameError，访问不到
```

| | Python | JavaScript |
|---|---|---|
| if 形成作用域 | 否 | `let`/`const` 形成 |
| for 形成作用域 | 否 | `let`/`const` 形成 |
| 函数形成作用域 | 是 | 是 |

## 4. global 和 nonlocal

默认情况下，函数里赋值会**创建新的局部变量**：

```python
x = 10

def foo():
    x = 20      # 新建局部 x，不是修改全局
    print(x)    # 20

foo()
print(x)        # 10，全局 x 没变
```

### `global`：修改全局变量

```python
x = 10

def foo():
    global x
    x = 20      # 修改全局 x

foo()
print(x)        # 20
```

### `nonlocal`：修改外层函数的变量

```python
def outer():
    x = 10

    def inner():
        nonlocal x   # 不加这个就会创建 inner 的局部 x
        x = 20

    inner()
    print(x)         # 20

outer()
```

### 只读不需要 global/nonlocal

```python
x = 10

def foo():
    print(x)    # 直接读，OK

foo()           # 10
```

**只有赋值时**才需要 global/nonlocal，否则 Python 会以为你在创建新的局部变量。

## 5. 常见的坑

### UnboundLocalError

```python
def foo():
    print(x)    # UnboundLocalError!
    x = 10

foo()
```

为什么报错？Python 在编译时扫描整个函数，看到下面有 `x = 10` 就把 `x` 标记为**局部变量**。然后第一行 `print(x)` 就成了"使用未赋值的局部变量"。

修复：

```python
def foo():
    global x    # 明确说 x 是全局的
    print(x)
    x = 10
```

### 类作用域不被方法继承

```python
class A:
    x = 10

    def method(self):
        print(x)        # NameError! 类作用域不传递
        print(self.x)   # 10，要通过 self 访问
```

类作用域比较特殊：定义类时是一个作用域，但方法内部不能直接看到类属性，必须通过 `self` 或 `A.x` 访问。
