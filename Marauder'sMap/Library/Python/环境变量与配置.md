# 环境变量与配置

## TL;DR

**`os.environ` 是 Python 读写环境变量的接口，主要用来读取配置，避免硬编码敏感信息。** 核心要点：

- `os.environ` 是 dict-like 对象，但值**永远是字符串**
- 用 `.get(key, default)` 安全读取，避免 KeyError
- 推荐用 `.env` 文件 + `python-dotenv` 管理配置
- 修改 `os.environ` 只影响当前进程的副本

---

## 1. 基本用法

```python
import os

# 读取
os.environ['HOME']               # 不存在会 KeyError
os.environ.get('HOME')           # 不存在返回 None
os.environ.get('XXX', '默认值')  # 提供默认值

# 设置
os.environ['MY_VAR'] = 'hello'

# 删除
del os.environ['MY_VAR']

# 查看所有
for key, value in os.environ.items():
    print(f'{key}={value}')
```

---

## 2. 三个重要特性

### 值永远是字符串

```python
os.environ['PORT'] = 8080        # TypeError! 必须是字符串
os.environ['PORT'] = '8080'      # OK

port = int(os.environ['PORT'])   # 用的时候手动转类型
debug = os.environ.get('DEBUG', 'false') == 'true'
```

### 只是当前进程的副本

```python
os.environ['MY_VAR'] = 'hello'
# 只在这个 Python 进程里有效
# 退出后 shell 里 echo $MY_VAR 还是空的
```

### 修改会传给子进程

```python
import subprocess
os.environ['MY_VAR'] = 'hello'
subprocess.run(['env'])   # 子进程能看到 MY_VAR=hello
```

## 3. 实际场景：配置管理

最常见的用途是**避免敏感信息硬编码**：

```python
# 危险！密码写死在代码里
DB_PASSWORD = 'my_secret_123'

# 应该从环境变量读
DB_PASSWORD = os.environ.get('DB_PASSWORD')
API_KEY = os.environ['OPENAI_API_KEY']
DEBUG = os.environ.get('DEBUG', 'false') == 'true'
```

运行时通过环境变量传入：

```bash
DB_PASSWORD=my_secret_123 python app.py
```

---

## 4. python-dotenv（最常见做法）

用 `.env` 文件 + `python-dotenv` 库管理配置：

```text
.env 文件（不要提交到 git！）:
DB_PASSWORD=my_secret_123
API_KEY=sk-xxxxx
DEBUG=true
```

```python
from dotenv import load_dotenv
load_dotenv()   # 把 .env 加载到 os.environ

import os
db_password = os.environ['DB_PASSWORD']
```

记得把 `.env` 加到 `.gitignore`：

```text
.gitignore:
.env
```

通常项目会提供一个 `.env.example` 作为模板：

```text
.env.example（提交到 git）:
DB_PASSWORD=
API_KEY=
DEBUG=false
```

## 5. 对比 JS / Node.js

| Python | Node.js |
|--------|---------|
| `os.environ['HOME']` | `process.env.HOME` |
| `os.environ.get('XXX', '默认值')` | `process.env.XXX ?? '默认值'` |
| `os.environ['X'] = '1'` | `process.env.X = '1'` |
| `python-dotenv` | `dotenv` |

完全一样的概念，API 名字不同。
