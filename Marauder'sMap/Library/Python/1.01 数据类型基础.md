# Python 数据类型基础

## TL;DR

Python 区分 `int` 和 `float` 两种数字类型。整数**无限精度**，浮点数有限制（64 位 IEEE 754）。布尔值大写开头（`True`/`False`），空值用 `None`。与 JS 的关键区别：JS 的 `Number` 全是浮点数。

---

## 1. 整数 (int)

Python 整数**没有大小限制**，数字小时占内存少，大了自动扩展：

```python
>>> 2 ** 10
1024
>>> 2 ** 1000
# 正常输出一个巨大的数，不会溢出
```

### 其他语言有限制

大多数语言用固定大小的内存存整数：

| 字节数 | bit 数 | 最大值 | 计算方式 |
|--------|--------|--------|----------|
| 1 | 8 | 255 | 2⁸ - 1 |
| 2 | 16 | 65535 | 2¹⁶ - 1 |
| 4 | 32 | 4294967295（约 42 亿） | 2³² - 1 |

Java 的 32 位有符号整数（1 位符号 + 31 位数值）：-2³¹ 到 2³¹-1（约 ±21 亿），超过就溢出。

JS 的 `Number` 全是 64 位浮点数，整数安全范围是 -2⁵³+1 到 2⁵³-1（约 ±9000 万亿），超过运算就不精确。后来加了 `BigInt`（加 `n` 后缀）来解决。

---

## 2. 浮点数 (float)

Python 浮点数是 **64 位 IEEE 754**，和 JS 的 `Number` 底层一样：

- 最大约 1.8 × 10³⁰⁸，超过变成 `inf`（无穷大）
- 精度 53 位，可能有四舍五入误差

```python
>>> 1.8e308
1.8e+308
>>> 1.8e309
inf
```

### 误差从哪来：二进制装不下 0.1

**先排除一半嫌疑：整数转二进制永远是有限位。** 算法是辗转除 2 记余数，商每步至少减半、严格递减且非负，**必然在有限步内撞到 0**，不存在"除不完"：

```text
233 ÷ 2 = 116 余 1        14 ÷ 2 = 7 余 0
116 ÷ 2 =  58 余 0         7 ÷ 2 = 3 余 1
 58 ÷ 2 =  29 余 0         3 ÷ 2 = 1 余 1
 29 ÷ 2 =  14 余 1         1 ÷ 2 = 0 余 1   ← 商到 0，结束

倒着读余数: 11101001
```

位数还能直接算：整数 n 需要 `⌊log₂n⌋ + 1` 位。所以 `int` 的"完全精确"是有保证的，不是碰巧。

**会无限循环的是小数。** 规律比想象中简单：

> 最简分数 `p/q` 在底数 b 下是有限小数 ⟺ **q 的每个质因数都能整除 b**

| | 底数的质因数 | 什么分母能除尽 |
|---|---|---|
| 十进制 | 10 = 2 × 5 | 分母只含 2 和 5：1/2、1/4、1/5、1/20 ✓ |
| **二进制** | 2 = 2 | **分母只能是 2 的幂**：1/2、1/4、1/8 ✓ |

**二进制比十进制更严格**——因为 {2} 是 {2, 5} 的真子集。所以十进制里干干净净的 `0.1`、`0.2`（分母含质因数 5），在二进制里是无限循环小数。手算（乘 2 取整）：

```text
0.1 × 2 = 0.2  → 0
0.2 × 2 = 0.4  → 0
0.4 × 2 = 0.8  → 0
0.8 × 2 = 1.6  → 1（余 0.6）
0.6 × 2 = 1.2  → 1（余 0.2）  ← 0.2 出现过了，开始循环

0.1 = 0.00011001100110011...  = 0.0(0011) 循环
```

**double 只有 52 位尾数，循环被砍断**——所以存进去的"0.1"根本不是 0.1，而是一个略大一点的数：

```python
>>> 0.1 + 0.2
0.30000000000000004
>>> from decimal import Decimal
>>> Decimal(0.1)                       # 看它实际存了什么
Decimal('0.1000000000000000055511151231257827021181583404541015625')
```

反过来，分母是 2 的幂就精确，一个 bit 不差：

```python
>>> 0.5 + 0.25 == 0.75
True
```

（`1/3` 十进制二进制都循环；π 这类无理数在任何底数下都无限不循环——计算机一律截断。**误差的根源是"有限位存无限位"，不是二进制有什么毛病**。）

### 浮点数实战三条

**一、别用 `==` 比浮点数，用 `math.isclose`：**

```python
>>> 0.1 + 0.2 == 0.3
False
>>> import math
>>> math.isclose(0.1 + 0.2, 0.3)
True
```

**二、钱和需要精确小数的场景用 `Decimal`（十进制运算）或直接用 `int` 存「分」：**

```python
>>> from decimal import Decimal
>>> Decimal('0.1') + Decimal('0.2') == Decimal('0.3')
True
```

注意必须传**字符串** `Decimal('0.1')`。传 `Decimal(0.1)` 是先造了个有误差的 float 再转过来，误差已经进去了。

**三、`round()` 不是"四舍五入"，有两个独立的坑：**

```python
>>> round(0.5), round(1.5), round(2.5)
(0, 2, 2)              # 坑1：银行家舍入 —— .5 往最近的偶数走
>>> round(2.675, 2)
2.67                   # 坑2：2.675 存进去其实是 2.67499999999999982...
```

坑 1 是故意设计的（避免大批数据统一往上舍入产生系统性偏高），坑 2 才是二进制误差。要真正的四舍五入用 `Decimal` 配 `ROUND_HALF_UP`。

### int vs float 对比

| | `int` | `float` |
|---|---|---|
| 大小限制 | 无限制，自动扩展 | 最大约 1.8e308 |
| 超出后 | 正常算，只是变慢 | 变成 `inf` |
| 精度 | 完全精确 | 53 位精度，可能有误差 |
| 有无小数点 | `1` | `1.0` |

```python
>>> type(1)
<class 'int'>
>>> type(1.0)
<class 'float'>
>>> 1 == 1.0     # 值相等（Python 自动转换后比较）
True
>>> 1 is 1.0     # 不是同一个对象
False
```

### 整数除法是精确的

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `//` | 整数除法（取整） | `10 // 3` | `3`（int，精确） |
| `/` | 普通除法 | `10 / 3` | `3.3333...`（float，可能不精确） |

只要在整数世界里运算（加减乘和 `//`），结果永远精确。

### 大整数和浮点数怎么比较

Python **不会**无脑把大 `int` 转成 `float`（那样会丢精度），而是用专门的比较逻辑：

```python
>>> 2**53 + 1 == float(2**53 + 1)
False    # Python 能发现 float 丢了精度
```

### 与 JS 的关键区别

| | Python | JavaScript |
|---|---|---|
| 数字类型 | `int` 和 `float` 分开 | 只有 `Number`（全是 float） |
| `1` 和 `1.0` | 不同类型 | 完全一样 |
| 整数能无限大 | 能（int 专门实现） | 不能（受 float 精度限制，除非用 BigInt） |

## 3. 布尔值

Python 大写开头：

| | Python | JavaScript |
|---|---|---|
| 真 | `True` | `true` |
| 假 | `False` | `false` |
| 空 | `None` | `null` |

Python 里写 `true` 会报错 `NameError`。

## 4. None

表示"什么都没有"，用于：

**函数没有返回值：**

```python
def say_hi():
    print("hi")

result = say_hi()
print(result)   # None
```

**函数可能找不到结果：**

```python
def find_user(name):
    if name in database:
        return user
    return None          # 没找到
```

返回 `0` 或 `""` 会引起混淆（它们是有意义的值），`None` 明确表示"没有"。

**变量先占位：**

```python
result = None
if condition:
    result = 100
```

**参数默认值：**

```python
def greet(name=None):
    if name is None:
        print("你好，陌生人")
    else:
        print(f"你好，{name}")
```

与 JS 对比：Python 只有一个 `None`，JS 要区分 `null` 和 `undefined`。

## 5. 字符串与三引号

多行字符串可以用三引号，避免 `\n` 难读：

```python
# 用 \n 写，难读
s = '第一行\n第二行\n第三行'

# 用三引号，直观
s = '''第一行
第二行
第三行'''
```

`'''...'''` 和 `"""..."""` 都行，效果完全一样。

## 6. 字符串是不可变的

Python 和 JS 一样，字符串的方法**返回新字符串**，不会修改原来的：

```python
>>> a = 'abc'
>>> a.replace('a', 'A')
'Abc'
>>> a
'abc'      # 原字符串没变
```

JS 也一样：

```javascript
let a = 'abc'
a.replace('a', 'A')   // 返回 'Abc'
console.log(a)         // 'abc'，没变
```

要让变量更新，得重新赋值：`a = a.replace('a', 'A')`

## 7. tuple（元组）

**不可变的 list**，用圆括号：

```python
t = (1, 2, 3)    # tuple
l = [1, 2, 3]    # list
```

| | tuple | list |
|---|---|---|
| 语法 | `(1, 2, 3)` | `[1, 2, 3]` |
| 能修改吗 | 不能 | 能 |
| 能放进 set 吗 | 能 | 不能 |

函数用逗号返回多个值时，Python 自动打包成 tuple：

```python
def quadratic(a, b, c):
    ...
    return x1, x2    # 等同于 return (x1, x2)
```

JS 没有 tuple，要返回多个值一般用数组或对象。

## 8. raise 抛出异常

`raise` 就是"抛出一个错误"，和 JS 的 `throw` 一样：

| Python | JavaScript |
|--------|-----------|
| `raise ValueError('xxx')` | `throw new Error('xxx')` |

程序遇到 `raise` 就会停下来，除非被 `try...except` 捕获。
