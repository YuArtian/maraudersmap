# 枚举类

## TL;DR

**`Enum` 把一组相关常量定义在一个类里，让常量"有类型、能比较、不可重复"。** 核心要点：

- 用 `Enum('Name', ('A', 'B', 'C'))` 快速建枚举，value 从 1 开始自动赋
- 继承 `Enum` 自己写类，可以指定每个成员的 value
- `@unique` 装饰器防止出现重复 value
- 成员可以用 `EnumClass.Mon` / `EnumClass['Mon']` / `EnumClass(1)` 三种方式访问
- 不同枚举成员之间用 `==` 直接比较，比"魔法字符串/数字"安全得多

---

## 1. 为什么不用普通常量

最朴素的常量定义：

```python
JAN = 1
FEB = 2
MAR = 3
...
```

问题：

| 缺点 | 解释 |
|---|---|
| 类型是 `int` | `if month == 1` 谁知道 1 是 JAN 还是别的什么 |
| 可被覆盖 | `JAN = 99` 没人拦你 |
| 没有"成员"概念 | 没法遍历"所有月份" |
| 容易出现魔法值 | 代码里散落 `if x == 2`, `if x == 11`，谁记得 11 是哪个月 |

`Enum` 解决所有这些问题。

---

## 2. 最简单的写法：直接构造

```python
from enum import Enum

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
                       'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'))

Month.Jan                          # <Month.Jan: 1>
Month.Jan.value                    # 1  -- 自动从 1 开始
Month.Mar.name                     # 'Mar'
```

遍历所有成员：

```python
for name, member in Month.__members__.items():
    print(name, '=>', member, ',', member.value)

# Jan => Month.Jan , 1
# Feb => Month.Feb , 2
# ...
```

---

## 3. 自定义 `Enum` 类：手动指定 value

继承 `Enum`，每个成员显式赋值——能控制起始值（比如从 0 开始表示星期天）：

```python
from enum import Enum, unique

@unique
class Weekday(Enum):
    Sun = 0     # 从 0 开始
    Mon = 1
    Tue = 2
    Wed = 3
    Thu = 4
    Fri = 5
    Sat = 6
```

`@unique` 是个装饰器，确保所有 value 不重复——重复时类定义阶段就报错，避免运行时 bug。

---

## 4. 三种访问方式

| 写法 | 触发 | 结果 |
|---|---|---|
| `Weekday.Mon` | 按属性 | `Weekday.Mon` |
| `Weekday['Mon']` | 按名字字符串 | `Weekday.Mon` |
| `Weekday(1)` | 按 value | `Weekday.Mon` |

```python
Weekday.Mon                # <Weekday.Mon: 1>
Weekday['Mon']             # <Weekday.Mon: 1>  -- 用字符串
Weekday(1)                 # <Weekday.Mon: 1>  -- 用 value

Weekday.Mon.name           # 'Mon'
Weekday.Mon.value          # 1

Weekday(7)                 # ValueError: 7 is not a valid Weekday
```

**按 value 反查**对解析外部数据特别有用——数据库里存的是数字，读出来直接 `Weekday(n)` 就得到枚举成员。

---

## 5. 比较：直接用 `==`

枚举成员可以**直接用 `==`** 比较，比字符串比较更安全：

```python
day = Weekday.Mon
day == Weekday.Mon         # True
day == Weekday.Tue         # False
day == 1                   # False!  -- 跟 int 比是 False
day.value == 1             # True
```

不会有"魔法字符串拼错"的问题：

```python
# ❌ 用字符串
if user.role == 'admimn':              # 拼错了！静默通过，永远是 False
    ...

# ✓ 用 Enum
if user.role == Role.ADMIN:            # 拼错会立刻 NameError
    ...
```

## 6. 实战：把字符串字段改成枚举

```python
from enum import Enum, unique

@unique
class Gender(Enum):
    Male = 0
    Female = 1

class Student:
    def __init__(self, name, gender):
        self.name = name
        self.gender = gender

bart = Student('Bart', Gender.Male)

# 比较
if bart.gender == Gender.Male:
    print('男生')
```

好处：

| 维度 | 字符串 `'male'` | `Gender.Male` |
|---|---|---|
| 拼写错误 | 静默错 | NameError，立刻发现 |
| IDE 自动补全 | 不行 | 可以 |
| 重命名 | 全局搜索替换 | IDE 自动重构 |
| 类型检查 (mypy) | 任意字符串都能传 | 只接受 `Gender` 类型 |

## 7. 进阶：带方法的 Enum

`Enum` 也是普通的类，可以定义方法：

```python
class HttpStatus(Enum):
    OK = 200
    NOT_FOUND = 404
    SERVER_ERROR = 500

    def is_error(self):
        return self.value >= 400

HttpStatus.OK.is_error()              # False
HttpStatus.NOT_FOUND.is_error()       # True
```

也可以为每个成员附加多个属性——常用于配置：

```python
class Currency(Enum):
    USD = ('美元', '$')
    CNY = ('人民币', '¥')
    EUR = ('欧元', '€')

    def __init__(self, label, symbol):
        self.label = label
        self.symbol = symbol

Currency.USD.label                    # '美元'
Currency.USD.symbol                   # '$'
```

## 8. 和 JavaScript / TypeScript 对比

| | Python | TypeScript |
|---|---|---|
| 定义 | `class X(Enum):` | `enum X {}` |
| 默认 value | 1, 2, 3, ... | 0, 1, 2, ... |
| 反查 | `X(value)` | `X[value]` 反向（数字枚举）|
| 防重复 | `@unique` 装饰器 | 自动检查 |
| 字符串枚举 | 直接 `'a'` 作为 value | `enum X { A = 'a' }` |

Python 的 Enum 比 JS 的更"动态"——能加方法、能多字段。但纯静态项目里 TS 的字符串枚举写起来更顺手。
