# 表达式与语句

## TL;DR

**表达式（Expression）能算出一个值，语句（Statement）执行一个动作。** 核心要点：

- 判断方法：能放在 `=` 右边的就是表达式
- 三元表达式 `a if 条件 else b` 是 Python 版的 `条件 ? a : b`
- **海象运算符 `:=`（3.8+）是「赋值的表达式版」**：绑定名字的同时把值交出去，专治「算一次、用两次」
- 理解这个区别，就能理解列表生成式里 if/else 的规则

---

## 1. 表达式 vs 语句

| | 表达式（Expression） | 语句（Statement） |
|---|---|---|
| 定义 | 能算出一个**值**的代码片段 | 执行一个**动作**，不产生值 |
| 判断方法 | 能放在 `=` 右边 | 不能放在 `=` 右边 |

```python
# 表达式 -- 每个都能算出一个值
1 + 2              # → 3
x * x              # → 某个数
"hello".upper()    # → "HELLO"
x > 5              # → True 或 False
x if x > 0 else -x # → 某个数
len([1, 2, 3])     # → 3

# 语句 -- 执行动作，没有值
x = 10             # 赋值语句
if x > 0:          # if 语句
    print(x)
for i in range(3): # for 语句
    pass
import os          # import 语句
```

最简单的验证：

```python
result = 1 + 2                    # OK，表达式
result = x if x > 0 else -x      # OK，表达式
result = len([1, 2])              # OK，表达式
result = for i in range(3): pass  # SyntaxError! 语句不能放这里
```

---

## 2. 三元表达式

Python 的条件表达式（三元表达式）：

```python
a if 条件 else b
```

| Python | JavaScript |
|--------|-----------|
| `a if 条件 else b` | `条件 ? a : b` |

```python
# Python
status = "偶数" if x % 2 == 0 else "奇数"

# JavaScript（等价）
// const status = x % 2 === 0 ? "偶数" : "奇数"
```

三元表达式是**表达式**，所以能出现在任何需要值的地方：赋值右边、函数参数、列表生成式的 for 前面等。

## 3. 海象运算符 `:=`

### 3.1 它把赋值变成了表达式

第 1 节说过：`x = 10` 是**语句**，没有值，所以不能写在需要值的地方。海象运算符（Python 3.8+ 引入，正式名叫**赋值表达式**）就是它的表达式版本：

```python
x = 10        # 语句：绑定名字，不产生值
(x := 10)     # 表达式：绑定名字，并且把 10 交出去
```

名字来自 `:=` 长得像海象的眼睛和獠牙。

**一句话理解它的价值：把一个值绑定到名字上的同时，还能立刻用这个值。** 这样就不用为了「用两次」而把表达式写两遍，也不用为了「先算出来」而多写一行。

### 3.2 用法一：算一次，判断一次，再用一次

```python
# 不用海象：要么算两遍，要么多一行
if len(data) > 3:
    print(f"长度 {len(data)} 超过 3")      # len 算了两遍

n = len(data)                              # 或者多占一行
if n > 3:
    print(f"长度 {n} 超过 3")

# 用海象：一行搞定，只算一次
if (n := len(data)) > 3:
    print(f"长度 {n} 超过 3")
```

正则匹配是最经典的场景（见 [[5.01 正则表达式]]）：

```python
if (m := re.search(r'\d+', text)):
    print(m.group())          # 匹配对象立刻能用
```

### 3.3 用法二：while 循环读到没有为止

Python 没有 `do-while`，读文件、读 socket 这类「先取一次、取到空就停」的模式过去写起来很别扭：

```python
# 不用海象：要么在循环外先读一次，要么死循环 + break
while True:
    line = f.readline()
    if not line:
        break
    process(line)

# 用海象
while line := f.readline():
    process(line)
```

[[5.13 网络编程]] 里的 echo 服务器就是这个写法：

```python
while data := conn.recv(1024):
    conn.sendall(b'echo: ' + data)
```

### 3.4 用法三：推导式里避免重复计算

这是海象最实用的场景。推导式的过滤条件和输出表达式如果都要用同一个计算结果，不用海象就只能算两遍：

```python
# 不用海象：slow(x) 在 if 里算一次，在输出位又算一次
[slow(x) for x in range(5) if slow(x) > 4]

# 用海象：算一次，绑给 y，两处都用它
[y for x in range(5) if (y := slow(x)) > 4]
```

实测调用次数（`range(5)`，最终留下 2 个元素）：

```text
不用海象，调用次数: 7        ← 5 次过滤 + 2 次输出
用了海象，调用次数: 5        ← 只有 5 次过滤
结果相同: True [9, 16]
```

推导式的完整语法见 [[1.08 列表生成式]]。

### 3.5 作用域：它绑的变量会「泄漏」出推导式

推导式在 Python 3 里**自带一个独立作用域**，循环变量不会跑到外面去。但**海象绑的变量会**：

```python
[q := i * 2 for i in range(3)]

print(q)    # 4      ← 海象绑的，泄漏出来了
print(i)    # NameError: name 'i' is not defined   ← 循环变量，没泄漏
```

这是设计上有意为之：海象的意图就是「我要在外面用这个值」。但它容易造成困惑——**推导式里两个看起来一样的名字，行为完全相反**。

作用域规则本身见 [[1.03 变量与作用域]]。

### 3.6 五条限制

海象不是万能替代 `=`，语言层面给它划了明确的边界：

| 限制 | 例子 | 结果 |
|---|---|---|
| 语句层不能裸用 | `x := 5` | `SyntaxError`——必须加括号 `(x := 5)` |
| 不能绑属性 | `(obj.attr := 1)` | `SyntaxError: cannot use assignment expressions with attribute` |
| 不能绑下标 | `(d['k'] := 1)` | `SyntaxError: cannot use assignment expressions with subscript` |
| 不支持增强赋值 | `x +:= 1` | `SyntaxError`——没有 `+:=` 这种写法 |
| 不能同时绑多个 | `(a := b := 1)` | 不支持链式，`a, b = 1, 2` 这种解包也不行 |

**第一条是刻意的设计**：不加括号就写不出 `x := 5`，这样就杜绝了「本来想写 `==` 结果手滑写成赋值」这个 C 语言里的经典 bug——那正是 Python 当初把赋值定成语句的初衷。海象把这个能力加回来了，但要求你显式加括号表明「我是故意的」。

### 3.7 优先级陷阱

`:=` 的优先级**比几乎所有运算符都低**，所以括号加在哪里结果完全不同：

```python
data = [1, 2, 3, 4, 5]

n = (n := len(data) > 3)      # n = True   ← 绑的是比较结果！
m = ((m := len(data)) > 3)    # m = 5      ← 这才是长度
```

第一行会被解析成 `n := (len(data) > 3)`。**规则是：把 `:=` 连同它要绑的那个表达式一起用括号裹起来。**

### 3.8 字节码：它只比普通赋值多一条指令

```text
n = len(d) 然后比较              (n := len(d)) > 3
─────────────────────           ─────────────────────
LOAD_NAME    len                LOAD_NAME    len
LOAD_NAME    d                  LOAD_NAME    d
CALL         1                  CALL         1
STORE_NAME   n                  COPY         1        ← 多的就是这一条
LOAD_NAME    n                  STORE_NAME   n
LOAD_CONST   3                  LOAD_CONST   3
COMPARE_OP   >                  COMPARE_OP   >
```

`STORE_NAME` 会把值从栈上**弹掉**，所以普通赋值之后要再 `LOAD_NAME` 取回来。海象在存之前先 `COPY 1` 复制一份留在栈上——**「赋值表达式」在机器层面就是这么一件事：照常赋值，但顺手留一个副本当作表达式的值。**

（字节码和栈式虚拟机见 [[5.15 CPython 解释器原理]]。）

### 3.9 什么时候不该用

海象容易写出「聪明但难读」的代码。三条经验：

- **一行里最多用一次**。`if (a := f()) and (b := g(a)) > (c := h(b)):` 这种没人看得懂
- **值只用一次时别用**。`print(x := f())` 不如 `print(f())`
- **需要复杂表达式时，老老实实多写一行**。海象的收益是省一行，不值得拿可读性换

它的最佳场景就是前面那三个：`if` 判断后要复用、`while` 读到空为止、推导式里避免重算。

## 4. 为什么这个概念重要

理解了表达式和语句的区别，很多语法规则都不用死记：

**列表生成式**：`for` 左边是表达式位，必须算出值；`for` 右边是子句位，只接受 `if` 过滤。

```python
[表达式  for x in ...  if 过滤条件]
```

- `x if c else y` 能放在 for 前面，因为它是表达式（有值）
- `x if c` 不能，因为它不是完整的表达式（算不出值）
- for 后面的 `if` 是子句语法，不是表达式，所以不能带 `else`

**f-string 的 `{}` 里**：只能写表达式，不能写语句。

```python
f"result: {x + 1}"           # OK，表达式
f"result: {x = 10}"          # SyntaxError! 赋值语句写不进去
f"result: {(x := 10)}"       # OK，海象是表达式（见第 3 节）
```

顺带分清一个长得很像、但完全无关的东西——**f-string 的调试写法 `f"{x=}"`**：

```python
val = 42
f"{val=}"        # → 'val=42'      打印「变量名 + 值」，调试用
```

这里的 `=` 是 f-string 自己的格式说明符，不是赋值，也不是海象。写法上只有一个等号且紧贴右花括号。

## 5. Python vs JS 对比

| 概念 | Python | JavaScript |
|------|--------|-----------|
| 条件表达式 | `a if c else b` | `c ? a : b` |
| 条件语句 | `if c: ... else: ...` | `if (c) {...} else {...}` |
| 赋值 | **语句**（`x = 1` 没有值） | **表达式**（`x = 1` 返回 `1`） |
| 赋值表达式 | `(x := 1)`（3.8+，必须带括号） | 就是普通赋值，无需特殊语法 |
| 函数调用 | 表达式 | 表达式 |
| lambda | 表达式（`lambda x: x+1`） | 表达式（`x => x+1`） |

**这一格差异值得单独说**：JS 里赋值天生是表达式，所以能直接写 `if (x = getValue())`——方便，但也埋了「本想写 `==` 手滑写成 `=`」这个经典 bug，以至于 ESLint 有专门的规则去拦它。

Python 当初把赋值定成语句，就是为了从语法层面杜绝这个 bug。3.8 加回海象时保留了这份谨慎：**必须写成 `(x := 1)`，括号是强制的**，等于要求你显式声明「我是故意在这里赋值的」。
