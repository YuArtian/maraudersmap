# 序列化

## TL;DR

**序列化 = 把内存里的对象变成可存储/可传输的字节流；反序列化 = 反过来还原。** Python 提供两条路径：

| 方案 | 用途 | 优缺点 |
|---|---|---|
| `pickle` | Python ↔ Python | 万能（几乎能存任何对象），但**只 Python 能读**，版本间不保证兼容；**永远不要 unpickle 不信任的数据** |
| `json` | 跨语言、走 Web | 文本格式人类可读，所有语言都能解析；但只支持基本类型，自定义类要手动转 |

四个核心函数（pickle 和 json 接口一致）：

| 函数 | 方向 | 目标 |
|---|---|---|
| `dumps(obj)` | 序列化 | 返回 `bytes`（pickle）或 `str`（json） |
| `dump(obj, f)` | 序列化 | 写入 file-like 对象 |
| `loads(data)` | 反序列化 | 从 bytes/str 还原 |
| `load(f)` | 反序列化 | 从 file-like 对象还原 |

口诀：**带 `s` 的处理字符串/字节流，不带 `s` 的处理文件**。

---

## 1. 为什么需要序列化

```python
d = dict(name='Bob', age=20, score=88)
# 程序结束，d 占用的内存被回收，下次重启又得重新构造
```

把 `d` "拍扁"成可保存的字节序列，写到磁盘 / 通过网络发出去——这就是序列化。其他语言里也叫 **serialization / marshalling / flattening**，意思一样。

```text
内存对象  ──序列化──►  字节流 ──存盘/网络──►  字节流  ──反序列化──► 内存对象
{name:Bob,         b'\x80\x03...'                        {name:Bob,
 age:20,                                                  age:20,
 score:88}                                                score:88}
```

## 2. pickle：Python 自己的序列化

### 基本用法

```python
import pickle

d = dict(name='Bob', age=20, score=88)

# 序列化为 bytes
data = pickle.dumps(d)
# b'\x80\x03}q\x00(X\x03\x00\x00\x00ageq\x01K\x14...'

# 反序列化
d2 = pickle.loads(data)
# {'name': 'Bob', 'age': 20, 'score': 88}
```

### 直接读写文件

```python
# 写
with open('dump.pkl', 'wb') as f:        # 注意 'wb'，二进制模式
    pickle.dump(d, f)

# 读
with open('dump.pkl', 'rb') as f:
    d = pickle.load(f)
```

**注意文件模式必须是二进制** (`'wb'` / `'rb'`)，因为 pickle 输出的是 bytes 不是字符串。

### pickle 能存什么

| 能 | 不能 |
|---|---|
| 基本类型 (int/float/str/bool/None) | 文件句柄、socket、数据库连接 |
| 容器 (list/dict/tuple/set) | lambda、嵌套函数 |
| 自定义类的实例（自动）| 系统资源相关的对象 |
| 普通的 `def` 函数 | 一些 C 扩展对象 |

### pickle 的两大局限

| 问题 | 详情 |
|---|---|
| **Python 专属** | 别的语言读不了；甚至不同 Python 版本之间也可能不兼容 |
| **不安全** | `pickle.loads()` 等价于"执行任意代码"——绝不能加载来自不可信源的 pickle 数据 |

```python
# ⚠️ 危险示例：构造恶意 pickle 可以触发 RCE
# import os; os.system('rm -rf /')
# 如果反序列化的字节流来自网络或用户上传，这就是远程代码执行漏洞
```

**实战规则**：

- 只用 pickle 做**进程间临时通信**（如 `multiprocessing` 自动用 pickle 传参）
- 做**本地缓存**可以用（自己写自己读）
- **绝不**接收外部 pickle 数据
- **绝不**用 pickle 做长期存储（Python 升级可能就读不回来了）

## 3. json：跨语言的标准格式

JSON 是文本格式，所有主流语言都能读。Python 内置 `json` 模块。

### 类型对应表

| JSON 类型 | Python 类型 |
|---|---|
| `{}` | `dict` |
| `[]` | `list` |
| `"string"` | `str` |
| `1234.56` | `int` 或 `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

**注意 JSON 没有的类型**：tuple、set、bytes、datetime、自定义类——这些都要先转换。

### 基本用法

```python
import json

d = dict(name='Bob', age=20, score=88)

# 序列化为字符串
s = json.dumps(d)
# '{"name": "Bob", "age": 20, "score": 88}'

# 反序列化
d2 = json.loads(s)
# {'name': 'Bob', 'age': 20, 'score': 88}
```

### 读写文件（文本模式）

```python
with open('data.json', 'w', encoding='utf-8') as f:    # 文本模式!
    json.dump(d, f)

with open('data.json', 'r', encoding='utf-8') as f:
    d = json.load(f)
```

跟 pickle 不同——JSON 是文本，文件用 `'w'` / `'r'`。

### 美化输出

```python
print(json.dumps(d, indent=2, sort_keys=True))
# {
#   "age": 20,
#   "name": "Bob",
#   "score": 88
# }
```

| 参数 | 作用 |
|---|---|
| `indent=2` | 缩进，便于人类阅读 |
| `sort_keys=True` | key 按字母顺序排，diff 友好 |
| `ensure_ascii=False` | **中文不被转义成 `\uXXXX`** |
| `separators=(',', ':')` | 紧凑模式（去掉默认的空格）|

### ensure_ascii 中文坑

```python
obj = {'name': '小明', 'age': 20}

json.dumps(obj)
# '{"name": "\\u5c0f\\u660e", "age": 20}'   ← 默认 True，中文被转义

json.dumps(obj, ensure_ascii=False)
# '{"name": "小明", "age": 20}'             ← 想看到中文必须显式关闭
```

**生产代码几乎都要写 `ensure_ascii=False`**——除非要兼容只认 ASCII 的老系统。

## 4. 自定义类的 JSON 序列化

直接 dump 自定义类会报错：

```python
class Student:
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score

s = Student('Bob', 20, 88)
json.dumps(s)
# TypeError: Object of type Student is not JSON serializable
```

JSON 不知道怎么把 `Student` 对象映射到 `{}`。三种解决：

### 方式一：手写转换函数 + `default` 参数

```python
def student_to_dict(std):
    return {
        'name': std.name,
        'age': std.age,
        'score': std.score
    }

json.dumps(s, default=student_to_dict)
# '{"name": "Bob", "age": 20, "score": 88}'
```

### 方式二：偷懒用 `__dict__`

每个普通类实例都有 `__dict__` 属性，存着所有实例变量：

```python
json.dumps(s, default=lambda obj: obj.__dict__)
# '{"name": "Bob", "age": 20, "score": 88}'
```

适合"字段直接对应"的简单类。例外：用了 `__slots__` 的类没有 `__dict__`。

### 方式三：反向，用 `object_hook` 转回对象

```python
def dict_to_student(d):
    return Student(d['name'], d['age'], d['score'])

s = json.loads(json_str, object_hook=dict_to_student)
# <Student object>
```

`object_hook` 在每解析出一个 dict 时被调用——决定要不要把这个 dict 变成自定义对象。

```text
JSON 字符串
   │ json.loads
   ▼
   dict {name, age, score}
   │ object_hook(dict_to_student)
   ▼
   Student(name='Bob', age=20, score=88)
```

## 5. pickle vs json 怎么选

```text
            是否跨语言?
            ┌────┴────┐
           是          否
            │          │
            ▼          ▼
          json      是否可信源?
                    ┌────┴────┐
                   是          否
                    │          │
                    ▼          ▼
                  pickle      json
                  (或更安全的 (绝不 pickle
                   msgpack/    不可信数据)
                   protobuf)
```

| 维度 | pickle | json |
|---|---|---|
| 跨语言 | ✗ | ✓ |
| 二进制还是文本 | 二进制 | 文本（UTF-8） |
| 体积 | 较小 | 较大（文本开销） |
| 速度 | 通常更快 | 较慢 |
| 类型支持 | 几乎全部 Python 对象 | 仅 JSON 6 种基本类型 |
| 自定义类 | 自动 | 要手动 default / object_hook |
| 安全性 | **危险**（不可加载外部数据） | 安全（只解析数据） |
| 人类可读 | ✗ 乱码 | ✓ |
| 与浏览器/API 互通 | ✗ | ✓ |

**实战默认值**：能用 json 就用 json，pickle 留给"自己存自己读"的内部缓存。

## 6. 其他常见序列化方案

`pickle` 和 `json` 不是全部——根据场景还有：

| 工具 | 何时用 |
|---|---|
| `msgpack` | 二进制 JSON 替代，体积小、速度快、跨语言 |
| `protobuf` | 强 schema、超紧凑、跨语言（gRPC 默认）|
| `yaml` | 配置文件，人类可读，支持注释 |
| `toml` | Python 配置文件标准（`pyproject.toml`）|
| `csv` | 表格数据 |
| `parquet` / `arrow` | 大数据列存格式 |

不知道选什么时的口诀：

- API / 配置 / 跟前端通信 → **JSON**
- Python 内部缓存 / 进程间临时数据 → **pickle**
- 高性能 RPC → **protobuf** 或 **msgpack**
- 人写的配置文件 → **YAML** 或 **TOML**

## 7. 速查表

| 任务 | 写法 |
|---|---|
| Python 对象 → bytes (pickle) | `pickle.dumps(obj)` |
| Python 对象 → 文件 (pickle) | `pickle.dump(obj, open(p, 'wb'))` |
| bytes → 对象 (pickle) | `pickle.loads(data)` |
| 文件 → 对象 (pickle) | `pickle.load(open(p, 'rb'))` |
| Python → JSON str | `json.dumps(obj, ensure_ascii=False, indent=2)` |
| JSON str → Python | `json.loads(s)` |
| Python → JSON 文件 | `json.dump(obj, open(p, 'w', encoding='utf-8'), ensure_ascii=False)` |
| 自定义类 → JSON | `json.dumps(obj, default=lambda o: o.__dict__)` |
| JSON → 自定义类 | `json.loads(s, object_hook=my_constructor)` |

## 8. 与其他语言对比

| | Python | JavaScript |
|---|---|---|
| 对象 → 字符串 | `json.dumps(obj)` | `JSON.stringify(obj)` |
| 字符串 → 对象 | `json.loads(s)` | `JSON.parse(s)` |
| 缩进 | `indent=2` | `JSON.stringify(obj, null, 2)` |
| 跳过特定字段 | `default` 参数 | `replacer` 参数 |
| 自定义还原 | `object_hook` | `reviver` 参数 |

接口几乎一一对应，写多了两种语言就习惯了。
