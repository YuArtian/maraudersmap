# 正则表达式

## TL;DR

**正则 = 用一行模式描述"哪种字符串才算合法"。** Python 的 `re` 模块提供所有正则功能。核心要点：

- **字符串前加 `r`**（raw string）写正则，省得跟 `\` 转义打架
- `\d` / `\w` / `\s` 匹配单字符；`*` / `+` / `?` / `{n,m}` 控制次数
- `^` 行首、`$` 行尾、`.` 匹配任意单字符、`[abc]` 范围、`A|B` 选择
- 用 `()` 分组提取子串，`m.group(1)` 拿第一组
- **默认是贪婪匹配**——加 `?` 变非贪婪（尽可能少匹配）
- 高频用的函数：`match` / `search` / `findall` / `sub` / `split` / `compile`

口诀：**复杂正则不要写在代码里，要么命名、要么用 `re.compile()`、要么写注释。**

---

## 1. 基础字符匹配

直接给字符就是精确匹配。三个最常用的"通配"：

| 元字符 | 匹配 |
|---|---|
| `\d` | 一个数字（0-9）|
| `\w` | 一个字母、数字或下划线 |
| `\s` | 一个空白（空格、tab、换行等）|
| `.` | 一个任意字符（除换行）|

```text
'00\d'    匹配 '007'，不匹配 '00A'
'\d\d\d'  匹配 '010'
'\w\w\d'  匹配 'py3'
'py.'     匹配 'pyc'、'pyo'、'py!'
```

大写版本是**取反**：

| 元字符 | 匹配 |
|---|---|
| `\D` | 非数字 |
| `\W` | 非字母数字下划线 |
| `\S` | 非空白 |

---

## 2. 量词：控制次数

加在元字符或字符后面，决定可以匹配几次：

| 量词 | 含义 |
|---|---|
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `?` | 0 次或 1 次（可选）|
| `{n}` | 恰好 n 次 |
| `{n,m}` | n 到 m 次 |
| `{n,}` | 至少 n 次 |

```text
\d{3}\s+\d{3,8}
 │    │   │
 │    │   └─ 3-8 位数字
 │    └────── 至少一个空白
 └─────────── 3 位数字

匹配：'010 12345'、'138    1234567' 等
```

匹配 `010-12345` 这种带连字符的：`\d{3}\-\d{3,8}`（`-` 需要 `\` 转义）。

---

## 3. 字符集 `[...]` 和选择 `|`

`[]` 表示"任选一个"：

| 模式 | 匹配 |
|---|---|
| `[0-9]` | 一个数字 |
| `[a-z]` | 一个小写字母 |
| `[a-zA-Z0-9_]` | 一个数字/字母/下划线（同 `\w` 但更明确）|
| `[^abc]` | **不是** a/b/c 的字符（`^` 在 `[]` 里是取反） |

```text
[a-zA-Z\_][0-9a-zA-Z\_]{0,19}
   ↑          ↑
首字符不能是数字   最多再来 19 位 → 整个变量名长度 1-20
```

`A|B` 表示 A 或 B：

```text
(P|p)ython     匹配 'Python' 或 'python'
cat|dog|bird   匹配 'cat'、'dog'、'bird'
```

---

## 4. 锚点：`^` 和 `$`

不消耗字符，只表示"位置"：

| 锚点 | 位置 |
|---|---|
| `^` | 行首 |
| `$` | 行尾 |
| `\b` | 单词边界 |
| `\B` | 非单词边界 |

```text
^\d        必须以数字开头
\d$        必须以数字结尾
^py$       整个字符串恰好是 'py'
\bword\b   把 word 当成完整单词（不是 password 的一部分）
```

不加 `^` 和 `$` 时，`match` 只要"开头能匹配上"就算成功——加上才是**整行严格匹配**。

---

## 5. raw string：永远用 `r''` 写正则

Python 字符串本身用 `\` 转义，跟正则的 `\` 打架：

```python
s = 'ABC\\-001'        # 普通字符串：'\\' 表示一个 '\'
# 对应正则其实是: ABC\-001

s = r'ABC\-001'        # raw string：所见即所得
# 对应正则: ABC\-001
```

**写正则永远加 `r` 前缀**——少踩一个坑：

```python
re.match(r'^\d{3}\-\d{3,8}$', '010-12345')   # ✓
re.match('^\d{3}\-\d{3,8}$', '010-12345')     # 也能跑，但读 \d 时心累
```

## 6. re 模块常用函数

### `re.match(pattern, string)`：从开头匹配

```python
import re

m = re.match(r'^\d{3}\-\d{3,8}$', '010-12345')
# <re.Match object; span=(0, 9), match='010-12345'>

re.match(r'^\d{3}\-\d{3,8}$', '010 12345')   # None
```

返回 `Match` 对象（成功）或 `None`（失败）。典型用法：

```python
if re.match(r'pattern', text):
    print('ok')
else:
    print('failed')
```

**注意**：`match` 只匹配**字符串开头**，即使没写 `^`。匹配整个字符串要加 `$`。

### `re.search`：在任意位置找

```python
re.match(r'world', 'hello world')      # None  -- 开头不是 world
re.search(r'world', 'hello world')     # <Match span=(6, 11)>  ✓
```

### `re.findall`：所有非重叠匹配

```python
re.findall(r'\d+', 'a1b22c333')        # ['1', '22', '333']
```

### `re.sub`：替换

```python
re.sub(r'\d+', '#', 'a1b22c333')       # 'a#b#c#'

# 用函数替换：每次匹配调用函数
re.sub(r'\d+', lambda m: str(int(m.group(0)) * 2), 'a1b22')
# 'a2b44'
```

### `re.split`：按正则切分

```python
'a b   c'.split(' ')                   # ['a', 'b', '', '', 'c']  -- 连空格当成多个分隔
re.split(r'\s+', 'a b   c')            # ['a', 'b', 'c']           ✓
re.split(r'[\s,;]+', 'a,b;; c   d')    # ['a', 'b', 'c', 'd']
```

固定字符串的 `split` 无法识别"连续多个分隔符"——正则版可以。

### 函数速查

| 函数 | 返回 | 用途 |
|---|---|---|
| `re.match(p, s)` | `Match` 或 `None` | 从开头匹配 |
| `re.search(p, s)` | `Match` 或 `None` | 任意位置找第一个 |
| `re.fullmatch(p, s)` | `Match` 或 `None` | 严格匹配整个字符串 |
| `re.findall(p, s)` | list | 所有匹配的字符串 |
| `re.finditer(p, s)` | iterator | 所有匹配的 `Match` 对象 |
| `re.sub(p, repl, s)` | str | 替换 |
| `re.split(p, s)` | list | 按正则切分 |
| `re.compile(p)` | `Pattern` | 预编译 |

## 7. 分组 `()`：提取子串

`()` 标记的部分会被**单独提取**：

```python
m = re.match(r'^(\d{3})-(\d{3,8})$', '010-12345')

m.group(0)     # '010-12345'  -- 整个匹配
m.group(1)     # '010'         -- 第 1 组
m.group(2)     # '12345'       -- 第 2 组
m.groups()     # ('010', '12345')
```

```text
^(\d{3})-(\d{3,8})$
  └─ 组1 ─┘ └─ 组2 ─┘

匹配后:
  group(0) = 整个匹配
  group(1) = 第一个 () 抓到的
  group(2) = 第二个 () 抓到的
```

### 命名分组：更易读

```python
m = re.match(r'(?P<area>\d{3})-(?P<num>\d{3,8})', '010-12345')

m.group('area')       # '010'
m.group('num')        # '12345'
m.groupdict()         # {'area': '010', 'num': '12345'}
```

`(?P<name>...)` 给分组起名字——比 `group(1)` / `group(2)` 容易维护得多。

### 非捕获分组 `(?:...)`

只想"分组"不想"捕获"（不占编号）：

```python
re.match(r'(?:abc)+(\d+)', 'abcabc123').groups()
# ('123',)   -- 只有一个捕获组，(?:abc) 不算
```

## 8. 贪婪 vs 非贪婪

**默认贪婪**：尽可能多匹配。

```python
re.match(r'^(\d+)(0*)$', '102300').groups()
# ('102300', '')
# \d+ 贪婪吃光所有数字（包括后面的 00），0* 只能匹配空字符串
```

在量词后加 `?` 变**非贪婪**：

```python
re.match(r'^(\d+?)(0*)$', '102300').groups()
# ('1023', '00')
# \d+? 尽量少吃，把后缀 00 让给 0*
```

| 贪婪 | 非贪婪 |
|---|---|
| `*` | `*?` |
| `+` | `+?` |
| `?` | `??` |
| `{n,m}` | `{n,m}?` |

经典场景：从 HTML/XML 里抓内容时一定要非贪婪：

```python
text = '<b>A</b><b>B</b>'

re.findall(r'<b>(.*)</b>', text)       # ['A</b><b>B']  -- 贪婪吃光中间所有
re.findall(r'<b>(.*?)</b>', text)      # ['A', 'B']      ✓ 非贪婪
```

## 9. 预编译 `re.compile()`

同一个正则用很多次，预编译省下重复解析的开销：

```python
re_telephone = re.compile(r'^(\d{3})-(\d{3,8})$')

re_telephone.match('010-12345').groups()   # ('010', '12345')
re_telephone.match('010-8086').groups()    # ('010', '8086')
```

预编译后返回 `Pattern` 对象，提供同名方法（`match`/`search`/`findall`/...）但不需要再传 pattern。

**何时用**：

- 循环里反复用同一个正则 → **必用** compile
- 一次性用一次 → 不必 compile（`re` 模块内部有缓存）
- 复杂正则需要 verbose 注释 → 用 compile + `re.VERBOSE` 标志

## 10. 常用标志（flags）

```python
re.match(pattern, text, flags=re.IGNORECASE)
re.compile(pattern, re.MULTILINE | re.DOTALL)
```

| 标志 | 简写 | 作用 |
|---|---|---|
| `re.IGNORECASE` | `re.I` | 忽略大小写 |
| `re.MULTILINE` | `re.M` | `^` / `$` 匹配每一行的开头/结尾，而不是整个字符串 |
| `re.DOTALL` | `re.S` | `.` 也能匹配换行符 |
| `re.VERBOSE` | `re.X` | 允许在正则里写空白和 `#` 注释（用 `\ ` `\#` 表示字面量）|

### `VERBOSE` 让长正则可读

```python
re_email = re.compile(r'''
    ^                       # 开头
    [\w\.\-]+               # 用户名
    @                       # at
    [\w\.\-]+               # 域名
    \.[a-z]{2,}             # 顶级域名
    $                       # 结尾
''', re.VERBOSE)
```

复杂正则**强烈推荐**这样写——比一行密集的 `r'^[\w\.-]+@[\w\.-]+\.[a-z]{2,}$'` 易读太多。

## 11. 实战例子

### 验证 Email

```python
def is_valid_email(addr):
    return bool(re.match(r'^[\w\.-]+@[\w\.-]+\.\w+$', addr))

is_valid_email('someone@gmail.com')          # True
is_valid_email('bob#example.com')            # False
```

（真正完整的 Email 规范见 RFC 5322，比这复杂得多——实战通常用这种"足够好"的简化版。）

### 解析带名字的邮箱

```python
def name_of_email(addr):
    # <Name> user@host.com 或 user@host.com
    m = re.match(r'^(?:<([^>]+)>\s*)?([^@\s]+)@', addr)
    return m.group(1) or m.group(2)

name_of_email('<Tom Paris> tom@voyager.org')   # 'Tom Paris'
name_of_email('tom@voyager.org')               # 'tom'
```

### 验证时间 HH:MM:SS

```python
re_time = re.compile(r'^([01]\d|2[0-3]):([0-5]\d):([0-5]\d)$')

re_time.match('19:05:30').groups()   # ('19', '05', '30')
re_time.match('25:00:00')             # None
```

### 替换 URL 为 Markdown 链接

```python
text = 'see https://python.org for docs'
re.sub(r'(https?://\S+)', r'[\1](\1)', text)
# 'see [https://python.org](https://python.org) for docs'
```

替换字符串里 `\1`、`\2` 指代捕获组（也支持 `\g<name>` 引用命名组）。

## 12. 几条经验

| 建议 | 原因 |
|---|---|
| **永远用 `r''`** | 避免 `\` 双重转义 |
| **重复使用就 `re.compile()`** | 性能 + 给正则一个名字 |
| **复杂正则用 `re.VERBOSE`** | 6 个月后自己还看得懂 |
| **能不用正则就不用** | 简单情况用 `str.split` / `in` / `startswith` 更快、更稳 |
| **HTML / XML 别用正则解析** | 用 `BeautifulSoup` / `lxml`，正则解析嵌套结构会疯掉 |
| **测试用 [regex101.com](https://regex101.com)** | 可视化、逐字符解释，比脑内执行靠谱 |
| **正则不是万能验证** | "邮箱看起来合法 ≠ 真实存在"——必要时还得发验证邮件 |

## 13. 与 JavaScript 对比

| 操作 | Python | JavaScript |
|---|---|---|
| 字面量 | `r'\d+'` (raw string) | `/\d+/` |
| 标志 | `re.IGNORECASE`, `re.MULTILINE` | `/.../i`, `/.../m` |
| 测试是否匹配 | `re.match()` | `regex.test(str)` |
| 找所有 | `re.findall()` | `str.matchAll(regex)` |
| 替换 | `re.sub(p, repl, s)` | `str.replace(regex, repl)` |
| 切分 | `re.split(p, s)` | `str.split(regex)` |

JS 的正则是语言级语法，Python 的正则是字符串 + 模块。本质几乎一样。
