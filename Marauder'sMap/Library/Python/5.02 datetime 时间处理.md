# datetime 时间处理

## TL;DR

**`datetime` 模块解决三件事：建/转/算时间，以及处理时区。** 核心要点：

- **时间戳 (timestamp)** = 自 1970-01-01 UTC 起的秒数，**和时区无关**；存数据库就存它
- `datetime.now()` 返回**本地**时间，没带时区信息
- `datetime` 默认不带时区（`tzinfo=None`），需要时区比较或转换时必须先 `replace(tzinfo=...)`
- `strptime` 字符串解析为 datetime；`strftime` datetime 格式化为字符串
- 用 `timedelta` 做时间加减，单位用 `days` / `hours` / `seconds` 等关键字传

---

## 1. 模块与类的"重名坑"

`datetime` 既是模块名，也是模块里的一个**类**——名字一样很容易踩坑：

```python
import datetime                     # 导入模块
datetime.now()                       # AttributeError! 模块没有 now() 方法
datetime.datetime.now()              # 必须写全名

from datetime import datetime        # 导入类
datetime.now()                       # OK ✓
```

实际工程里通常 `from datetime import datetime, timedelta, timezone`。

---

## 2. 构造 datetime

```python
from datetime import datetime

# 当前本地时间
now = datetime.now()                 # 2024-05-14 10:30:00.123456

# 指定日期时间
dt = datetime(2024, 5, 14, 12, 20)   # 2024-05-14 12:20:00

# 看类型
type(now)                            # <class 'datetime.datetime'>
```

`datetime()` 构造函数的参数顺序：年、月、日、时、分、秒、微秒。

---

## 3. 时间戳：和时区无关的"绝对时间"

```text
timestamp = 0  =  1970-01-01 00:00:00 UTC
              =  1970-01-01 08:00:00 北京时间 (UTC+8)
              =  1969-12-31 19:00:00 纽约时间 (UTC-5)

  同一个 timestamp 在任何时区都指向同一个"绝对时刻"
```

```python
dt = datetime(2024, 5, 14, 12, 20)
dt.timestamp()                       # 1715660400.0  -- 浮点数，整数位是秒

datetime.fromtimestamp(1715660400)   # 转回本地时间
datetime.utcfromtimestamp(1715660400)  # 转成 UTC 时间
```

| 语言 | timestamp 单位 |
|---|---|
| Python | **秒** (float)，小数位是微秒 |
| Java / JavaScript | **毫秒** (long/int) |

JS 拿来的时间戳要 `/ 1000` 才能用在 Python 里。

---

## 4. 字符串 ⇄ datetime

`strptime` ("string parse time")：字符串→datetime：

```python
cday = datetime.strptime('2024-6-1 18:19:59', '%Y-%m-%d %H:%M:%S')
```

`strftime` ("string format time")：datetime→字符串：

```python
now.strftime('%Y-%m-%d %H:%M:%S')    # '2024-05-14 10:30:00'
now.strftime('%a, %b %d %H:%M')       # 'Tue, May 14 10:30'
```

常用格式占位符：

| 占位符 | 含义 | 例 |
|---|---|---|
| `%Y` | 4 位年 | 2024 |
| `%y` | 2 位年 | 24 |
| `%m` | 月 | 05 |
| `%d` | 日 | 14 |
| `%H` | 24 小时制时 | 18 |
| `%I` | 12 小时制时 | 06 |
| `%M` | 分 | 30 |
| `%S` | 秒 | 45 |
| `%a` | 缩写星期 | Tue |
| `%A` | 完整星期 | Tuesday |
| `%b` | 缩写月份 | May |
| `%B` | 完整月份 | June |

记忆窍门：大写多代表"完整"或"4 位"，小写代表"缩写"或"2 位"。

## 5. 时间加减：用 `timedelta`

```python
from datetime import datetime, timedelta

now = datetime.now()
now + timedelta(hours=10)            # 10 小时后
now - timedelta(days=1)              # 一天前
now + timedelta(days=2, hours=12)    # 2 天半后
```

`timedelta` 支持的关键字：`days` / `hours` / `minutes` / `seconds` / `milliseconds` / `microseconds` / `weeks`。

**没有 `months`、`years`** —— 因为月份长度不一致。要加月份用 `dateutil.relativedelta`（第三方）。

两个 datetime 相减得到 timedelta：

```python
d = datetime(2024, 12, 31) - datetime(2024, 1, 1)
d.days                               # 365
d.total_seconds()                    # 31536000.0
```

## 6. 时区：默认 None 是个大坑

`datetime` 对象默认 `tzinfo=None`，叫**naive datetime**（"天真"，不知道自己在哪个时区）：

```python
now = datetime.now()
now.tzinfo                           # None  -- 不知道时区
```

要带时区，需要 `timezone` + `timedelta` 构造一个时区，然后 `replace`：

```python
from datetime import datetime, timezone, timedelta

tz_bj = timezone(timedelta(hours=8))         # 东 8 区
now = datetime.now().replace(tzinfo=tz_bj)   # 现在带时区了
now                                  # 2024-05-14 18:30:00+08:00
```

**注意 `replace(tzinfo=...)` 只是"贴标签"，不会换算时间**——它说"这个时间是在 UTC+8 区"，而不是"把它转到 UTC+8"。所以前提是你已经**知道**当前 datetime 本来就在哪个时区。

---

## 7. 时区转换：`astimezone`

```python
from datetime import datetime, timezone, timedelta

# 拿到当前 UTC 时间（贴上 UTC 标签）
utc_dt = datetime.utcnow().replace(tzinfo=timezone.utc)

# 转换到北京时间
bj_dt = utc_dt.astimezone(timezone(timedelta(hours=8)))

# 转换到东京时间
tokyo_dt = utc_dt.astimezone(timezone(timedelta(hours=9)))
```

| 方法 | 作用 |
|---|---|
| `replace(tzinfo=tz)` | 贴标签，**不换算** |
| `astimezone(tz)` | **换算**到目标时区，时分秒会变 |

两个带时区的 datetime 之间随便转——不必经过 UTC。

## 8. 工程实践

### 存数据库：存 timestamp 不存 datetime

```python
# ❌ 直接存本地 datetime，跨时区部署立刻出问题
db.save(created_at=datetime.now())

# ✓ 存时间戳，最安全
db.save(created_at=datetime.now().timestamp())

# ✓ 或者存带 UTC 时区的 datetime
db.save(created_at=datetime.now(timezone.utc))
```

### 读时再转用户本地时区

```python
ts = db.get_created_at()             # 拿到时间戳
local_dt = datetime.fromtimestamp(ts)   # 显示给用户时按本地时区
```

### 比较时间必须带时区

```python
naive_dt = datetime(2024, 1, 1)
aware_dt = datetime(2024, 1, 1, tzinfo=timezone.utc)

naive_dt < aware_dt
# TypeError: can't compare offset-naive and offset-aware datetimes
```

要么都带 tz，要么都不带。

## 9. 速查表

| 需求 | 写法 |
|---|---|
| 当前本地时间 | `datetime.now()` |
| 当前 UTC 时间 | `datetime.utcnow()` 或 `datetime.now(timezone.utc)` |
| 时间戳 → datetime | `datetime.fromtimestamp(ts)` |
| datetime → 时间戳 | `dt.timestamp()` |
| 字符串 → datetime | `datetime.strptime(s, fmt)` |
| datetime → 字符串 | `dt.strftime(fmt)` |
| ISO 8601 字符串 → datetime | `datetime.fromisoformat(s)` |
| 时间加减 | `dt + timedelta(days=1)` |
| 替换时区（不换算） | `dt.replace(tzinfo=tz)` |
| 换算到目标时区 | `dt.astimezone(tz)` |
