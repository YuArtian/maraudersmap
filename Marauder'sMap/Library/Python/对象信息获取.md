# 对象信息获取

## TL;DR

**Python 提供一套内置函数对任意对象做"反射 (introspection)"——拿到类型、属性、方法。** 核心要点：

- `type(x)` 返回类型；`isinstance(x, T)` 判断类型（支持继承链和多类型）
- `dir(x)` 列出对象所有属性和方法（含 dunder）
- `hasattr` / `getattr` / `setattr` 三件套动态读写属性
- 只在"不知道对象是什么"的时候才用反射；直接 `obj.x` 能搞定的不要用 `getattr(obj, 'x')`
- 鸭子类型场景下，`hasattr(obj, 'read')` 比"它是不是 File 类"更符合 Pythonic 思路

---

## 1. `type()`：拿到对象的类型

```python
type(123)              # <class 'int'>
type('abc')            # <class 'str'>
type(None)             # <class 'NoneType'>
type(abs)              # <class 'builtin_function_or_method'>
```

`type()` 返回的是**类对象**本身，可以直接比较：

```python
type(123) == int                   # True
type(123) == type(456)             # True
type('abc') == type(123)           # False
```

对于函数类型，用 `types` 模块里定义的常量：

```python
import types

def fn(): pass

type(fn) == types.FunctionType                # True (def 定义的)
type(abs) == types.BuiltinFunctionType        # True (C 实现的)
type(lambda x: x) == types.LambdaType         # True (lambda)
type((x for x in range(10))) == types.GeneratorType   # True (生成器)
```

详见 [[函数进阶]] 关于函数类型的部分。

## 2. `isinstance()`：考虑继承链的类型判断

`type()` 只判断"是不是该类型本身"，**不认子类**。`isinstance()` 顺着继承链查，更实用：

```python
class Animal: pass
class Dog(Animal): pass
class Husky(Dog): pass

h = Husky()

type(h) == Husky                # True
type(h) == Dog                  # False  -- type() 只看精确类型
isinstance(h, Husky)            # True
isinstance(h, Dog)              # True   -- 父类也算
isinstance(h, Animal)           # True   -- 祖父类也算
```

```text
对象继承链:   Husky → Dog → Animal → object

type(h) 返回:  Husky          (只是最具体的类)
isinstance(h, X):  X 在链上的任何位置都返回 True
```

### 一次判断多个类型

第二个参数传 tuple，匹配其中**任意一个**就返回 True：

```python
isinstance([1, 2], (list, tuple))           # True
isinstance((1, 2), (list, tuple))           # True
isinstance('abc', (int, str, bytes))        # True
```

### 一般用 isinstance，不用 type

| 场景 | 用哪个 |
|---|---|
| 仅需"是否能当某类型用" | `isinstance` ✓ |
| 需要严格精确匹配类型 | `type` |
| 99% 的实际代码 | `isinstance` |

## 3. `dir()`：列出所有属性和方法

```python
dir('ABC')
# ['__add__', '__class__', ..., 'capitalize', 'casefold', ..., 'zfill']
```

返回一个**字符串列表**，包含对象身上所有可访问的名字（包括 dunder）。

实用场景：

```python
# 看看 list 都有哪些方法
[m for m in dir([]) if not m.startswith('_')]
# ['append', 'clear', 'copy', 'count', 'extend', 'index', ...]

# 看看模块里有什么
import collections
dir(collections)
```

`dir(obj)` 本质上调用 `obj.__dir__()`，可以在自己的类里重写来控制 IDE 自动补全显示什么。

## 4. `hasattr` / `getattr` / `setattr`：动态读写属性

| 函数 | 作用 | 等价于 |
|---|---|---|
| `hasattr(obj, 'x')` | obj 有属性 x 吗？ | 试一下，能拿到就 True |
| `getattr(obj, 'x')` | 取 obj.x | `obj.x`，但属性名是字符串 |
| `getattr(obj, 'x', 默认)` | 取不到时返回默认值 | 不会报错 |
| `setattr(obj, 'x', v)` | 设 obj.x = v | `obj.x = v`，但属性名是字符串 |

```python
class MyObject:
    def __init__(self):
        self.x = 9
    def power(self):
        return self.x * self.x

obj = MyObject()

hasattr(obj, 'x')               # True
hasattr(obj, 'y')               # False

setattr(obj, 'y', 19)           # 动态加一个属性
hasattr(obj, 'y')               # True
getattr(obj, 'y')               # 19

getattr(obj, 'z')               # AttributeError!
getattr(obj, 'z', 404)          # 404  -- 用默认值

fn = getattr(obj, 'power')      # 拿到方法本身
fn()                            # 81 -- 等价于 obj.power()
```

## 5. 什么时候真的需要用反射

**默认答案：能直接写 `obj.x` 就别用 `getattr(obj, 'x')`。** 它降低可读性，也躲过静态检查。

```python
# ❌ 没必要
total = getattr(obj, 'x') + getattr(obj, 'y')

# ✓ 直接写
total = obj.x + obj.y
```

合适的场景：

### 场景 1：鸭子类型检测能力

文件类的"能不能读"——不关心传进来的是 file、StringIO、网络流，只要 `read()` 在就行：

```python
def read_image(fp):
    if hasattr(fp, 'read'):
        return read_data(fp)
    return None
```

比 `isinstance(fp, File)` 灵活，更符合 Pythonic 思想。

### 场景 2：属性名是变量

属性名是从配置/数据库/用户输入里来的：

```python
config = load_config()
for key in ['host', 'port', 'username']:
    if hasattr(config, key):
        connection_args[key] = getattr(config, key)
```

### 场景 3：批量复制属性

```python
def copy_attrs(src, dst, *names):
    for name in names:
        setattr(dst, name, getattr(src, name))

copy_attrs(user_form, user, 'name', 'email', 'phone')
```

### 场景 4：序列化 / ORM 框架

ORM 把数据库行映射成对象时，列名只有运行时知道，必须用 `setattr`。

## 6. dunder 方法也可以用反射访问

像 `len()` 这种内置函数其实是调用对应的 dunder：

```python
len('ABC')              # 3
'ABC'.__len__()         # 3  -- 完全等价

# 自定义类也能这样
class MyDog:
    def __len__(self):
        return 100

len(MyDog())            # 100
```

```text
内置函数         对应 dunder
len(x)      →    x.__len__()
str(x)      →    x.__str__()
iter(x)     →    x.__iter__()
x + y       →    x.__add__(y)
```

更多 dunder 方法见 [[定制类]]。

## 7. 速查表

| 需求 | 函数 |
|---|---|
| 看类型 | `type(x)` |
| 判断类型（含子类） | `isinstance(x, T)` |
| 判断是否子类 | `issubclass(B, A)` |
| 列所有属性方法 | `dir(x)` |
| 判断有没有某属性 | `hasattr(x, 'name')` |
| 动态读属性 | `getattr(x, 'name'[, default])` |
| 动态写属性 | `setattr(x, 'name', value)` |
| 动态删属性 | `delattr(x, 'name')` |
| 能不能调用 | `callable(x)` |
