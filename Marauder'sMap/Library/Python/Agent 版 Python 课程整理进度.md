# Agent 版 Python 课程整理进度

## TL;DR

**第二素材源：《Python 语言核心精讲》（袁进，Agent 应用开发向），共 32 章。** 每章一个 `课件.md` 加示例代码与练习。

这门课和本库原有素材（廖雪峰教程）的关系是**互补而非重复**：

- 廖雪峰版覆盖面全、偏标准库使用
- 这门课**弱化 API、强调概念与设计**，且补齐了原有素材的三块空白：元类 / 描述符 / ABC、类型标注、asyncio 全链路（事件循环 → Future → 协程 → 异步编程）

整理原则：**并入已有文章优先，只有原有素材完全没覆盖的主题才新建**。课程特有的作业题记入 [[练习与作业]]，讲师本机路径、课程平台链接、截图不带入。

新增文章要回填 [[Python 教程总览]] 第 2 节的分类表。
