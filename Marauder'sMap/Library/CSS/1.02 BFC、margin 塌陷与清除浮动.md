# BFC、margin 塌陷与清除浮动

## TL;DR

**BFC（块级格式化上下文）= 一个隔离的布局小世界：里面的布局不影响外面，外面也进不来**。三大应用正好对应它的三条特性：**阻断 margin 合并**（同一 BFC 内相邻纵向 margin 才合并）、**包住浮动**（BFC 计算高度包含浮动子元素）、**不与浮动重叠**（两栏自适应布局）。现代触发首选 `display: flow-root`。

---

## 1. BFC 是什么、怎么触发

格式化上下文 = 一块区域内部的布局规则集。BFC 内：盒子纵向排列、**同一 BFC 内相邻盒子的纵向 margin 合并**、区域不与外部浮动重叠、计算高度包含浮动。

触发方式（按推荐排序，全背不如记这几类）：

```css
display: flow-root;        /* ★ 专为创建 BFC 设计，零副作用，现代首选 */
overflow: hidden;          /* 经典手法，副作用：裁剪溢出内容 */
float: left/right;         /* 浮动元素自身成 BFC */
position: absolute/fixed;  /* 绝对定位成 BFC */
display: inline-block / table-cell / flex、grid 容器（严格说建立的是 FFC/GFC，隔离效果类似）
```

（根元素 html 天然是 BFC——这就是为什么大多数页面「默认没事」。）

---

## 2. 应用一：margin 塌陷/合并

两种病症同根（都发生在**同一 BFC 内**）：

- **相邻兄弟合并**：上下两个块的 20px margin 之间只有 20px（取大者），不是 40px；
- **父子塌陷**：子元素的 margin-top「穿透」没有 border/padding 的父元素，把父元素一起顶下来。

```css
/* 父子塌陷的解法（任选） */
.parent { display: flow-root; }   /* 让父元素成为新 BFC，切断内外 margin 关系 */
.parent { padding-top: 1px; }     /* 或 border——制造分隔 */
/* 兄弟合并通常不修——规范行为，排版用单向 margin（只用 margin-bottom）约定规避 */
```

原理一句话：**margin 合并是同一 BFC 内的规则，让父元素自成 BFC，子元素的 margin 就出不去了**。

---

## 3. 应用二：清除浮动（高度塌陷）

子元素全浮动 → 脱离普通流 → 父元素高度算不到它们 → 高度塌陷为 0，背景边框消失。三代解法：

```css
/* ① clearfix 伪元素（兼容时代的标准答案） */
.clearfix::after { content: ''; display: block; clear: both; }

/* ② 父元素成 BFC（利用「BFC 高度包含浮动」特性） */
.parent { display: flow-root; }   /* 或 overflow: hidden */

/* ③ 现代答案：别用 float 做布局，flex/grid 没有这个问题 */
```

面试完整度：说清「浮动为什么塌陷（脱流）→ clear 的原理（clear 让元素的上边缘低于前面浮动元素的下边缘）→ BFC 方案的原理（特性 3）→ 现状（float 回归其排版本职：文字环绕）」。

---

## 4. 应用三：两栏自适应（不与浮动重叠）

```css
.left  { float: left; width: 200px; }
.right { display: flow-root; }   /* 成为 BFC → 不与浮动重叠 → 自动占满剩余宽度 */
```

不加 BFC 时右栏会「钻」到浮动下面、文字环绕；加了 BFC 则两栏泾渭分明——这是 BFC 特性「区域不与 float 盒子重叠」的直接应用（更多布局方案见 [[1.05 经典布局题：三栏、圣杯与双飞翼]]）。

## 面试问答

### Q: 什么是 BFC？怎么触发？有什么用？

满分答案：块级格式化上下文，一块独立布局区域，内外互不影响。触发：display: flow-root（专用零副作用，现代首选）、overflow 非 visible、浮动、绝对定位、inline-block、flex/grid 容器等；根元素天然 BFC。三大应用对应三条特性：父元素成 BFC 阻断父子 margin 塌陷（合并只发生在同一 BFC 内）；BFC 高度计算包含浮动子元素，可清除浮动；BFC 区域不与浮动重叠，实现两栏自适应。

### Q: margin 塌陷/合并是怎么回事？怎么解决？

满分答案：同一 BFC 内相邻块盒的纵向 margin 会合并取大值，两种形态——兄弟间上下 margin 合并；无 border/padding 分隔时子元素 margin-top 穿透父元素（塌陷）。解决：父子塌陷让父元素自成 BFC（flow-root）或加 padding/border 制造分隔；兄弟合并是规范行为，工程上用「单向 margin」约定规避。根因答到「合并是 BFC 内部规则」即满分。

### Q: 清除浮动有哪些方法？原理分别是什么？

满分答案：高度塌陷根因是浮动脱离普通流、父元素计算高度忽略它们。方法一 clearfix：::after 伪元素设 clear: both——clear 强制该元素排在浮动元素下边缘之下，从而撑开父元素；方法二父元素触发 BFC（flow-root/overflow: hidden）——BFC 特性规定高度计算包含内部浮动；方法三釜底抽薪：布局改用 flex/grid，float 只留给文字环绕的本职场景。
