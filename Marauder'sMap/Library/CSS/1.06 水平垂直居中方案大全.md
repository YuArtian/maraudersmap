# 水平垂直居中方案大全

## TL;DR

**答题顺序：flex（两行）→ grid（一行）→ absolute + transform（不知子元素尺寸也行）→ absolute + margin auto（需定尺寸）→ table-cell（考古）**。区分「知不知道子元素尺寸」「子元素是行内还是块级」是把这题答出层次的关键。

---

## 1. 现代三板斧

```css
/* ① flex */
.parent { display: flex; justify-content: center; align-items: center; }

/* ② grid —— 最短答案 */
.parent { display: grid; place-items: center; }
/* 或子元素自决：.child { place-self: center; } */

/* ③ flex + margin auto（少有人答，加分） */
.parent { display: flex; }
.child { margin: auto; }   /* flex 格式化上下文中 auto 纵向也生效 */
```

---

## 2. 定位流派

```css
/* ④ absolute + transform：子元素尺寸未知也可用 */
.parent { position: relative; }
.child {
  position: absolute; top: 50%; left: 50%;
  transform: translate(-50%, -50%);   /* 百分比相对自身尺寸 —— 这是它的关键 */
}

/* ⑤ absolute + margin: auto：要求子元素有确定尺寸 */
.child {
  position: absolute; inset: 0;       /* top/right/bottom/left: 0 */
  margin: auto; width: 200px; height: 100px;
}
```

④ 的原理拆解（常被追问）：`top/left: 50%` 的百分比相对**包含块**，把子元素**左上角**推到中心；`translate(-50%, -50%)` 的百分比相对**自身**宽高，再拉回一半——两个百分比基准不同，正好互补。副作用：非整数像素可能导致文字模糊（可改用 `translate(calc(-50% + 0.5px))` 类技巧或换方案）。

---

## 3. 行内内容与考古方案

```css
/* ⑥ 单行文本垂直居中 */
.parent { height: 40px; line-height: 40px; text-align: center; }

/* ⑦ table-cell（兼容化石，知道即可） */
.parent { display: table-cell; vertical-align: middle; text-align: center; }
.child  { display: inline-block; }
```

行内元素水平居中用父级 `text-align: center`；块级定宽元素用 `margin: 0 auto`（原理：包含块剩余空间被 auto 均分，见 [[1.01 盒模型与 box-sizing]]）。

---

## 4. 选型速查表

| 场景 | 首选 |
|---|---|
| 一切现代项目 | flex / grid（place-items） |
| 弹层/浮层（脱离文档流） | absolute + transform |
| 子元素尺寸未知 | flex、grid、transform 皆可；margin:auto 定位版不行 |
| 单行文字 | line-height |
| 要兼容化石浏览器 | table-cell |

## 面试问答

### Q: 实现水平垂直居中有哪些方法？

满分答案：分层报——现代：flex 的 justify-content + align-items 两行；grid 的 place-items: center 一行；flex 容器内子元素 margin: auto。定位流：absolute + translate(-50%,-50%) 适配未知尺寸（top/left 百分比相对包含块、translate 相对自身，两个基准互补）；absolute + inset:0 + margin:auto 需要定尺寸。行内场景：line-height 等于高度、text-align。收尾给选型：常规 flex/grid，弹层用定位 + transform。

### Q: absolute + transform 方案的原理？为什么不用 margin 负值？

满分答案：top/left: 50% 把子元素左上角定到父容器中心（百分比基准是包含块），translate(-50%,-50%) 再把自身拉回宽高的一半（百分比基准是自身）——不需要预知尺寸。margin 负值方案（margin-left: -宽度/2）效果相同但必须硬编码尺寸的一半，尺寸一改就失效；transform 版的代价是可能产生半像素模糊。这题核心是「两个百分比的参照物不同」。

### Q: margin: 0 auto 为什么能水平居中？为什么垂直方向不行？

满分答案：块级盒在普通流中，水平方向的「包含块宽 = margin + border + padding + width」是强约束等式，两侧 margin 为 auto 时均分剩余空间实现居中；垂直方向没有这个约束（高度由内容决定），auto 被视为 0。但在 flex/grid 格式化上下文和「absolute + inset:0」的定位场景里，垂直 auto 同样参与剩余空间分配——所以 flex 里 margin:auto 可以双向居中，这个例外是加分点。
