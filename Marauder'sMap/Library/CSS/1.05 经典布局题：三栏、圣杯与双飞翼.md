# 经典布局题：三栏、圣杯与双飞翼

## TL;DR

**「左右固定、中间自适应」的答案按时代分层：现代首选 flex / grid（两行代码），经典时代靠浮动 + 负 margin（圣杯用 padding 腾位、双飞翼用内层 margin 腾位），偏门解还有 calc 和绝对定位**。面试要求「至少三种」时，flex、grid、float 各答一种再点出圣杯/双飞翼的差异即封顶。

---

## 1. 现代解法（先答这两个）

```css
/* ① flex —— 最常用 */
.container { display: flex; }
.left, .right { width: 200px; flex: none; }  /* 固定：不伸不缩 */
.main { flex: 1; min-width: 0; }             /* 自适应；min-width 防内容撑爆 */

/* ② grid —— 声明式最简 */
.container { display: grid; grid-template-columns: 200px 1fr 200px; }
```

DOM 顺序即视觉顺序、天然等高、无清除浮动问题。「中间内容优先渲染」的老需求：flex 里给 main 放 DOM 第一位再用 `order` 调整视觉顺序即可——古典方案的核心卖点在现代布局里是一行属性。

---

## 2. 经典浮动方案（理解原理用）

**圣杯布局**（padding 腾位版）：

```html
<div class="container">   <!-- padding: 0 200px 腾出两翼位置 -->
  <div class="main">中间（DOM 在前，优先渲染）</div>
  <div class="left">左</div>
  <div class="right">右</div>
</div>
```

三列全 `float: left`；main 宽 100% 占满；**left 用 `margin-left: -100%` 拉回到 main 行首**，再 `position: relative; left: -200px` 挪进容器 padding 区；right 用 `margin-left: -200px; right: -200px` 同理落位右侧。

**双飞翼布局**：同样的负 margin 套路，区别在**给 main 加一层内层 div，用 `margin: 0 200px` 让内容避开两翼**——不再需要容器 padding 和相对定位，代价是多一层 DOM。

两者异同一句话：**都靠「浮动 + 负 margin 把两翼拉上中间行」，差别只在中间内容怎么躲开两翼——圣杯用父容器 padding + 相对定位，双飞翼用子元素 margin**。

负 margin 的原理支点：`margin-left: -100%` 相对包含块宽度计算，把元素在浮动流里整整拉回一行——理解它需要浮动排布 + 百分比基准两个知识点（见 [[1.01 盒模型与 box-sizing]]）。

---

## 3. 其他解法凑「至少三种」

- **calc**：`.main { width: calc(100% - 400px); }` 三列 float/inline-block 排开——直白但把常量写死进样式；
- **绝对定位**：两翼 absolute 钉住两侧，main 用 `margin: 0 200px` 避让——层级脱流，等高与撑开父容器都成问题；
- **BFC 两栏变体**：左栏浮动 + 右栏 flow-root（原理见 [[1.02 BFC、margin 塌陷与清除浮动]]），两栏题的最优雅浮动解；
- **父容器 padding + 子 100%**：只适合「视觉留白」不适合真三栏（两翼没有内容承载）。

## 面试问答

### Q: 左右固定 200px、中间自适应，写出至少三种方案？

满分答案：flex——容器 flex，两翼 flex:none 定宽，中间 flex:1 加 min-width:0；grid——grid-template-columns: 200px 1fr 200px 一行完成；float 经典——三列浮动配负 margin（圣杯/双飞翼）或两翼浮动 + 中间触发 BFC；再候补 calc 宽度和绝对定位。主动补一句选型：新代码一律 flex/grid，浮动方案的价值在展示对布局机制的理解。

### Q: 圣杯布局和双飞翼布局的区别？

满分答案：共同骨架——中间列 DOM 在前实现优先渲染，三列全浮动，两翼用 margin-left: -100% 和 -200px 的负外边距拉回中间行。分歧在「中间内容如何避开两翼」：圣杯给容器设左右 padding、两翼再用相对定位挪进 padding 区；双飞翼给中间列加内层元素用 margin 避让，省掉相对定位但多一层 DOM。这题实际考负 margin 在浮动流中的行为。

### Q: 为什么现代项目不再用浮动布局？

满分答案：float 的本职是文字环绕，拿来布局是历史妥协——需要清除浮动防高度塌陷、负 margin 技巧可读性差、无法自然等高、响应式适配繁琐。flex/grid 是真正为布局设计的：DOM 顺序与视觉解耦（order/grid-area）、天然等高、间距用 gap、无脱流副作用。浮动方案如今的意义是面试时展示对包含块、浮动流、负 margin 的原理理解。
