# 定位与包含块

## TL;DR

**position 五值：static（默认在流中）、relative（在流中偏移，留坑）、absolute（脱流，锚定「最近的非 static 祖先」）、fixed（脱流，锚定视口）、sticky（阈值内 relative、越过后 fixed 于滚动容器）**。深挖点是**包含块**：百分比尺寸和定位偏移都相对它计算，而 `transform` 会让 fixed/absolute 的包含块变成该祖先——「fixed 失效」名题的答案。

---

## 1. position 五值速查

| 值 | 在流中？ | 定位基准 | 备注 |
|---|---|---|---|
| static | ✔ | — | top/left 等无效 |
| relative | ✔（原位置保留） | 自身原位置 | 常用作 absolute 的锚点 |
| absolute | ✘ 脱流 | 最近的 **position 非 static 祖先**的 padding 边缘 | 找不到就到初始包含块（视口大小） |
| fixed | ✘ 脱流 | **视口** | 滚动不动；被 transform 祖先「劫持」见下 |
| sticky | ✔（不脱流） | 最近**滚动祖先** | 阈值（如 top:0）前 relative、后吸附；**父元素 overflow 非 visible 或不给阈值就「失效」**——两大翻车点 |

z-index 只对定位元素（及 flex/grid 子项）生效；层叠上下文的完整规则可顺势展开（transform/opacity<1/filter 都会创建层叠上下文——这也解释了「z-index 设了 9999 还是被盖住」）。

---

## 2. 包含块：百分比的「分母」

**包含块 ≠ 父元素**——它是「计算百分比和定位偏移的参照盒」，由 position 决定怎么找：

- static/relative/sticky → 最近的**块容器祖先的内容区**（大多数时候恰好是父元素，所以平时无感）；
- absolute → 最近的非 static 祖先的 **padding 区**；
- fixed → **视口**（初始包含块）。

受它影响的属性：`width/height/padding/margin` 的百分比（**注意 margin/padding 的纵向百分比也相对包含块的宽度**）、定位偏移 top/left 的百分比（top 相对包含块**高度**）。「translate(-50%) 居中」里两个百分比基准不同的辨析见 [[1.06 水平垂直居中方案大全]]。

**例外条款（名题）**：某祖先若有 `transform`/`perspective` 非 none、`will-change: transform`、`filter`、`contain: paint`、`backdrop-filter` 等属性，它会**成为 absolute/fixed 后代的包含块**——于是：

- **「fixed 失效」**：祖先加了 transform，fixed 元素不再钉住视口，而是跟着该祖先走（滚动时一起滚）——弹窗放在做过动画的容器里突然「不 fixed 了」的病因；
- 反向利用：想让 fixed「相对某个父元素」定位，给父元素来一句 `transform: rotate(0deg)` 制造包含块——冷技巧但确实是这道题的官方玩法。

## 3. 元素显示类型：block / inline / inline-block

| | block | inline | inline-block |
|---|---|---|---|
| 排列 | 独占一行 | 同行排布 | 同行排布 |
| 宽高 | 可设 | **无效**（宽度由内容定） | 可设 |
| margin/padding | 全方向有效 | **纵向 margin 无效**（纵向 padding 画得出但不占行高） | 全方向有效 |
| 典型 | div、p、h1 | span、a、em | 按钮类 |

inline-block 的经典坑：标签间的换行符渲染成**空白间隙**（解决：父级 font-size:0 / 负 margin / 改 flex）；基线对齐导致图片底部 3px 缝隙（`vertical-align: middle` 或 `display: block`）。

语义补充：HTML 规范早已用「内容模型」取代行内/块级分类，但 CSS 显示类型的这套行为仍是面试标配；`a` 能否包 `div`？——HTML5 规范允许（a 是透明内容模型），只要 a 里别再嵌交互元素。

## 面试问答

### Q: position 各值的区别？sticky 为什么会失效？

满分答案：static 默认；relative 相对自身原位偏移且原空间保留；absolute 脱流、以最近非 static 祖先的 padding 区为基准；fixed 脱流、以视口为基准；sticky 混合体——未达阈值时随流滚动，到达 top/left 阈值后吸附于最近滚动祖先。sticky 失效两大原因：没设 top 等阈值；祖先链上有 overflow: hidden/auto 把「滚动容器」截胡（吸附对象变了或没有滚动空间）。

### Q: 什么是包含块？fixed 定位什么时候不相对视口？

满分答案：包含块是百分比尺寸与定位偏移的计算参照，不一定是父元素——static/relative 找最近块容器内容区，absolute 找最近非 static 祖先的 padding 区，fixed 是视口。例外：祖先有 transform、will-change: transform、filter、perspective、contain: paint 时，它成为 fixed/absolute 后代的包含块——所以 transform 过的容器里 fixed 会「失效」跟着容器滚。反向利用：给父元素加个空 transform 就能让 fixed 相对它定位。

### Q: block、inline、inline-block 的区别？

满分答案：block 独占一行、宽高与四向 margin/padding 全可控；inline 同行排布、设宽高无效、纵向 margin 无效（尺寸交给 line-height 体系）；inline-block 兼得——同行排布且宽高可控。补两个实战坑：inline-block 间的 HTML 空白符会渲染成间隙（父级 font-size:0 或改 flex）；替换元素如 img 的基线对齐产生底部缝隙，用 vertical-align: middle 或 display: block 解决。
