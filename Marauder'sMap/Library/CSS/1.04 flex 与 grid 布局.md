# flex 与 grid 布局

## TL;DR

**flex 是一维布局（一次管一条轴），grid 是二维布局（行列同时规划）**。flex 必背两组：容器六属性（direction/wrap/flow/justify-content/align-items/align-content）+ 项目属性里的 **flex: grow shrink basis** 三元组及四个缩写（1 / auto / 0 / none）。grid 必背 `fr`、`repeat(auto-fill, minmax())`、`grid-template-areas`。

---

## 1. flex：轴的艺术

心智模型：容器定义**主轴**（flex-direction）与交叉轴；justify-content 管主轴分布，align-items 管交叉轴对齐，align-content 管**多行**在交叉轴的分布（单行无效——高频陷阱）。

**flex 三元组**（`flex: grow shrink basis`）：

- `flex-basis`：分配前项目的基准尺寸（auto=内容/width；**优先级高于 width**）；
- `flex-grow`：有剩余空间时按比例**分**（默认 0 不参与）；
- `flex-shrink`：空间不足时按比例**缩**（默认 1；设 0 则寸步不让）。

四个缩写值的差异（面试最爱）：

| 缩写 | 展开 | 行为 |
|---|---|---|
| `flex: 1` | `1 1 0%` | 能伸能缩，**basis 为 0** → 完全按 grow 比例瓜分空间（等分列的正解） |
| `flex: auto` | `1 1 auto` | 能伸能缩，从内容尺寸出发再分剩余 → 内容多者更宽 |
| `flex: 0` | `0 1 0%` | 不伸会缩，表现为最小内容宽 |
| `flex: none` | `0 0 auto` | 完全刚性，不伸不缩 |

`flex: 1` vs `flex: auto` 一句话：**1 是「无视内容平分」，auto 是「按内容加权分」**。

实战小抄：`margin-left: auto` 在 flex 里把某项推到最右（吃掉剩余空间）；`gap` 直接设间距（早已支持 flex）；子项设 `min-width: 0` 解决「文本不截断撑爆容器」的经典 bug（默认 min-width:auto 不允许缩过内容）。

**手写骰子三点**（批次 1 移交题）：容器 `display:flex; justify-content:space-between`，三列各自 `flex-direction:column; justify-content` 分别为 flex-start/center/flex-end——考察的就是「嵌套 flex + 两轴对齐」的组合运用。

## 2. grid：真正的二维

```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));  /* 响应式卡片墙一行搞定 */
  gap: 16px;
}
```

核心概念速查：

- **fr**：按比例瓜分剩余空间（grid 版的 grow）；`minmax(min, max)` 给轨道设上下限；
- **repeat(auto-fill / auto-fit, …)**：不定容器宽自动排列——auto-fill 保留空轨道，auto-fit 折叠空轨道让项目撑满（俩的区别是细节加分题）；
- **grid-template-areas**：ASCII 画布局，语义化到极致：

```css
grid-template-areas:
  "header header"
  "aside  main"
  "footer footer";
/* 子项：grid-area: header; —— 圣杯布局三行代码（见 1.05） */
```

- 项目定位：`grid-column: 1 / 3`（起止网格线）或 `span 2`；
- 对齐体系与 flex 同名复用：justify-\*/align-\* 的 items（格内内容）与 content（整个网格）。

## 3. 选型与协作

| 场景 | 选择 |
|---|---|
| 组件内部一行元素的分布对齐（导航、工具条、卡片内） | flex |
| 页面级行列骨架、卡片墙、重叠区域 | grid |
| 不定数量项目自动换行流 | flex-wrap 或 grid auto-fill 皆可，等宽需求选 grid |

两者不对立：**grid 搭页面骨架，flex 管格子内部**是标准配合。都不产生浮动时代的清除/塌陷问题（见 [[1.02 BFC、margin 塌陷与清除浮动]]）。

## 面试问答

### Q: flex: 1 是什么意思？和 flex: auto 有什么区别？

满分答案：flex 是 grow、shrink、basis 三属性缩写。flex:1 展开为 1 1 0%——基准尺寸归零，剩余空间按 grow 完全平分，是等宽列的正确写法；flex:auto 是 1 1 auto——以内容尺寸为基准再分剩余，内容多的项更宽。再补 flex:none（0 0 auto 完全刚性）和 flex:0（只缩不伸）。追问点：basis 优先级高于 width；文本溢出不缩的坑要配 min-width:0。

### Q: flex 和 grid 怎么选？

满分答案：维度决定——flex 一维，沿一条轴排布，适合组件内部的分布对齐；grid 二维，行列同时声明，适合页面骨架、卡片墙、区域重叠。二者配合而非互斥：grid 画大格局，flex 管格子内部。补充 grid 的杀手锏：repeat(auto-fill, minmax()) 一行实现响应式等宽卡片流、template-areas 用 ASCII 图直接声明圣杯布局。

### Q: justify-content、align-items、align-content 的区别？

满分答案：justify-content 管主轴上项目的分布（start/center/space-between…）；align-items 管交叉轴上每个项目的对齐（stretch 默认/center/baseline）；align-content 管「多行整体」在交叉轴的分布——只有换行产生多条主轴线时才生效，单行设置它没反应是高频陷阱。grid 里同名属性语义对应：items 管单元格内、content 管整个网格轨道。
