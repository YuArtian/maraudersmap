# 模型里的四类数字：超参数、参数、特征、激活值

> 一个模型里全是数字，但它们分属四类。分不清这四类，后面所有讨论都会糊

> [!warning] 本篇的定位
> 这是一篇**纠错型笔记**，专治几个反复绊人的混淆：把参数当成特征、把维度当成参数、把 `4096` 和权重值当成同一回事、把 `Q` 和 `W_q` 当成同一个东西。
> 其余各篇（[[神经网络]]、[[AI/Map|AI 知识地图]]、[[大语言模型]]）在用到这些词时都默认读者已经分清了。

## TL;DR

- 模型里的数字分四类：**超参数、参数、输入特征、激活值**
- 判别只需两问：**换一句输入它变吗？** 变 → 数据侧；不变 → 模型侧。再问 **它是"多大/几个"还是"具体是多少"？** 尺寸 → 超参数；数值 → 参数
- **上两类是模型**（静态，存在文件里）；**下两类是数据**（每次运行时临时产生，用完就丢）
- **"4096"是尺寸，不是参数**；参数是填在 4096 列里的那些数值
- **"1.6T 参数"数的是参数个数**，和"有多少特征"毫无关系——两者差八九个数量级
- **大写 $W$ 是权重（参数），$Q/K/V$ 是算出来的（激活值）**
- 训练动第二类，推理动第三、四类，第一类从头到尾没人碰

---

## 1. 一个完整的例子，所有数字都贴上标签

用 [[神经网络]] 里那个考试预测网络——小到可以把每个数字都写出来。

```text
【结构】2 个输入 → 2 个隐藏神经元 → 1 个输出        ← 超参数

【模型内部的 9 个数】                                ← 参数
   h₁ 的权重 0.5、0.2    偏置 −4
   h₂ 的权重 0.1、0.5    偏置 −3
   输出的权重 1.5、0.8   偏置 −1

【这次的输入】(6, 8)                                 ← 输入特征
【算出来的中间值】h₁ = 0.6、h₂ = 1.6                  ← 激活值
【结果】0.76
```

现在换一个学生，输入变成 (2, 8)：

```text
结构     不变    ← 还是 2→2→1
9 个参数 不变    ← 还是 0.5、0.2、−4 …… 一个都没动
输入特征 变了    ← (2, 8)
激活值   变了    ← h₁ = 0、h₂ = 1.2
结果     变了    ← 0.49
```

**这就是全部区别。** 上两类是模型的固定家当，下两类是每次跑的时候流过去的数据。

## 2. 四类数字对照表

| | 超参数 | 参数 | 输入特征 | 激活值 |
|---|---|---|---|---|
| 别名 | hyperparameter、配置 | weight、权重、模型参数 | feature、输入维度 | activation、隐层表示、中间特征 |
| 例子 | 4096、32 层、学习率、temperature | 0.0134、−0.0271 | 查表得到的 4096 个数 | h₁ = 0.6、注意力权重、logits |
| 谁定的 | **人设计时拍板** | **训练学出来** | 数据决定 | 前向计算产生 |
| 有多少个 | 几十个 | 70 亿 | 每 token 4096 个 | 每层 7×4096 |
| 换一句输入 | 不变 | 不变 | **变** | **变** |
| 存在哪 | `config.json` | `model.safetensors` | 内存（临时） | 显存（临时） |
| 跑完还在吗 | 在 | 在 | 丢弃 | 丢弃 |

**"7B 参数"数的是第二列。**

## 3. 判别法：遇到一个数字问两句

```text
问题一：换一句输入，它变吗？
   变    →  数据侧（输入特征 或 激活值）
   不变  →  模型侧，继续问第二个问题

问题二：它说的是"多大 / 几个"，还是"具体是多少"？
   多大/几个   →  超参数     （4096、32 层、32000 词表）
   具体是多少  →  参数       （0.0134、−0.0271、…）
```

按这个走一遍：

| 数字 | 换输入变吗 | 尺寸还是数值 | 结论 |
|---|---|---|---|
| 4096 | 不变 | 尺寸（有几列） | **超参数** |
| 32（层数） | 不变 | 尺寸 | **超参数** |
| 32000（词表） | 不变 | 尺寸 | **超参数** |
| 0.0134 | 不变 | 数值 | **参数** |
| 7B / 1.6T | 不变 | 参数的**个数** | 在数参数有多少 |
| 7（这次的序列长度） | **变** | — | 数据决定 |
| 查表得到的 4096 个数 | **变** | — | **输入特征** |
| h₁ = 0.6、注意力权重 64.5% | **变** | — | **激活值** |
| logits、概率分布 | **变** | — | **激活值** |

注意 `7B` 那一行：**它本身是个计数，数的对象是参数**。就像"这本书有 30 万字"——30 万是计数，字才是内容。

## 4. 落到四个文件上

这四类东西真的分装在不同地方。下载一个模型就能看到：

```text
tokenizer.json        几 MB     ← 词表：哪些字符串是 token、各自编号多少
config.json           几 KB     ← 超参数
model.safetensors     14 GB     ← 参数
（运行时的显存）        临时       ← 输入特征与激活值，跑完就释放
```

**前三个是静态文件，跑不跑都在；第四类只在跑的那一刻存在。**

`config.json` 长这样，全是超参数：

```json
{
  "hidden_size": 4096,
  "num_hidden_layers": 32,
  "num_attention_heads": 32,
  "intermediate_size": 11008,
  "vocab_size": 32000,
  "max_position_embeddings": 4096
}
```

`model.safetensors` 打开是这样，全是参数：

```text
model.embed_tokens.weight                shape (32000, 4096)
model.layers.0.self_attn.q_proj.weight   shape (4096, 4096)
   ⋮
tensor([[ 0.0134, -0.0271,  0.0089, ...,  0.0412],
        [-0.0056,  0.0198, -0.0330, ...,  0.0077],
        ...])
```

**几 KB 对 14 GB，差六个数量级**——这个体量差本身就说明两者是完全不同的东西。

同一系列的模型（7B / 13B / 70B）代码完全一样，只是 `config.json` 里几个数字不同，权重文件大小差几十倍。**改超参数改的是骨架尺寸，改参数改的是骨架里的每一块肉。**

---

## 5. 为什么超参数你改不了，采样参数却能随便改

调 API 时能传 `temperature`，却不能传 `hidden_size`——因为**超参数其实要再分三类**：

| 类别 | 例子 | 什么时候定 | 你能改吗 |
|---|---|---|---|
| **架构超参数** | 层数 32、维度 4096、词表 32000 | 训练**之前** | **不能** |
| **训练超参数** | 学习率、批量大小、训练轮数 | 训练**过程中** | **不能**（也接触不到） |
| **推理参数** | temperature、top_p、max_tokens | **每次调用** | **能** |

**架构超参数改不了，是因为权重矩阵的形状是按它们造出来的。** 把 `hidden_size` 改成 8192，加载时会去取一个 8192×8192 的矩阵，但文件里躺着的是 4096×4096——直接报错。所以 `config.json` 不是"配置项"，更像"这堆权重的说明书"，改它只会让模型加载失败。

**推理参数能随便改，是因为它们压根不碰权重。** 看介入的时机：

```text
[输入] → 查表 → 32 层 → 输出矩阵          ← 全程由权重决定
logits = [3.2, 1.8, 1.1, 0.4]             ← 到这里结果完全确定
   ↓ ÷ temperature，再 Softmax             ← temperature 从这里才开始起作用
概率  = [0.699, 0.172, 0.086, 0.043]
```

**同样的输入，不管 temperature 设多少，logits 永远是同一串数。** 改它只是改变怎么把这串数变成概率，没有任何一个权重被动过——所以一个模型可以同时服务一万个用户、各人用各人的温度。

## 6. 对号入座：token → embedding → 层

这条链路是四者最容易搅在一起的地方，逐项标一遍（例子：「我爱吃藜麦」）：

| 东西 | 类别 | 理由 |
|---|---|---|
| **词表**（32000 条 token 清单） | 分词器资产 | 分词器训练出来的，不属于模型参数 |
| 词表大小 **32000** | **超参数** | 是尺寸 |
| **token id** `3921` | 数据 | 换句就变；但只是编号，还不能算 |
| **embedding 表**里的 1.31 亿个数 | **参数** | 训练学出来的 |
| 表的尺寸 **32000、4096** | **超参数** | 是尺寸 |
| 查出来的 **7×4096 个数** | **输入特征** | 换句就变 |
| 序列长度 **7** | 数据决定 | 输入多长就多长 |
| 上下文上限 **4096 / 1M** | **超参数** | 设计时定的天花板 |
| $W_q, W_k, W_v, W_o$、前馈矩阵里的数 | **参数** | 训练学出来的 |
| **层数 32、头数 32** | **超参数** | 是尺寸 |
| $Q = XW_q$、$K$、$V$ | **激活值** | 算出来的，每次输入不同就不同 |
| 注意力权重（麦对吃 64.5%） | **激活值** | 同上 |
| 每层输出的 **7×4096** | **激活值** | 中间结果，用完就丢 |
| **logits**、**概率** | **激活值** | 最后一层的输出 |
| **temperature 0.7** | **推理参数** | 调用时人设定的 |

## 7. 三个具体的绊脚点

### 其一：$W_q$ 与 $Q$ 不是一回事

```text
W_q、W_k、W_v、W_o   ← 4 个权重矩阵，训练学出来的，换输入不变    【参数】
Q、K、V              ← 用 X 乘上面的矩阵算出来的，每次都不同      【激活值】

              Q = X W_q      K = X W_k      V = X W_v
```

**大写 $W$ 开头带下标的是权重；单独的 $Q/K/V$ 是这次算出来的东西。** 记号上就差一个 $W$，性质上隔着模型与数据的分界线。

（细节见 [[AI/Map|AI 知识地图]]：为什么要三个独立的矩阵、$W_o$ 干什么。）

### 其二：embedding 表既是参数，查出来的又是特征

```text
整张表（1.31 亿个数）   → 参数，一直不变
从表里取出的那 7 行     → 输入特征，换句就换行
```

同一张表，"整张表"和"取出来的几行"是两回事。

这里还有个微妙处：这 7×4096 到底叫"输入特征"还是"第一层的激活值"，**行业里两种说法都有**——它确实处在边界上，由参数生成，又充当后续层的输入。不必纠结叫法，记住"它每次输入都会变"就够了。

### 其三："7" 和 "4096" 都是维度，性质却不同

```text
7    ← 序列长度，由这次输入多长决定，每次都可能不同
4096 ← 隐藏维度，模型设计时定死，永远是 4096
```

这也解释了 [[向量与点积]] 里那句"句子变长，变的是向量个数，不是长度"——**行数随数据变，列数被超参数锁死**。

## 8. 参数在物理上是什么样的存在

它不是抽象概念，**就是硬盘上一个文件里的一串数字**。

一个 7B 模型下载下来是约 14 GB 的 `.safetensors`（70 亿个数 × 每个 2 字节）。里面是 226 个矩阵（[[AI/Map|AI 知识地图]] 第 1 节有完整清单），每个矩阵是一张数表，表里每个格子装一个浮点数。

它完全是静态的：不跑的时候这些数就躺在硬盘上；跑起来就加载进显存，然后拿输入去和它们做矩阵乘法。

**至于"参数"这个名字**，来自数学传统：

$$f(x) = wx + b$$

$x$ 是**变量**——每次代入不同的值；$w$、$b$ 是**参数**——在一个具体函数里固定，换一组就是另一个函数。**参数确定"是哪一个函数"，变量确定"这一次算哪个点"。** 大模型就是这个道理放大 70 亿倍。

---

## 9. 一句话收束

```text
超参数  ——  表格开多大          （几十个数，config.json，几 KB）
参数    ——  表格里填的每个数    （70 亿个数，权重文件，14 GB）
输入特征 ——  这次送进去的数据    （每次不同，用完就丢）
激活值  ——  计算过程中的中间结果（每次不同，用完就丢）
```

**上两行是模型，下两行是数据。训练动第二行，推理动第三、四行，第一行从头到尾没人碰。**
