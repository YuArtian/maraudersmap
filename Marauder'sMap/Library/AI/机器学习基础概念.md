# 机器学习基础概念

> 《动手学深度学习》第一章核心概念整理

## TL;DR

**机器学习** 是让计算机从数据中自动学习规律的方法：

- **核心流程**: `数据 → 模型 → 调参数 → 让预测越来越准`
- **基本概念**: 数据集、样本、特征、维数、标签
- **学习本质**: 反复调整参数，最小化损失函数
- **损失函数是人选的**，但常用的几个都能由极大似然推导出来；它必须光滑可导，否则梯度下降没法用
- **梯度下降**: 导数指方向、减号是下山、学习率控制步长——深度学习唯一的训练引擎
- **关键假设**: i.i.d.（独立同分布）
- **核心问题**: 过拟合（背答案 vs 学规律）
- **深度学习 vs 传统方法**: 各有适用场景，不是替代关系

---

## 1. 什么是机器学习

我们不直接编写规则，而是让程序从数据中自动学习：

```text
传统编程:  规则 + 数据 → 结果
机器学习:  数据 + 结果 → 规则（模型自动学出来的）
```

学习过程：

1. 从一个随机初始化参数的模型开始
2. 获取一些数据样本
3. 调整参数，使模型在这些样本中表现得更好
4. 重复 2 和 3，直到表现令人满意

---

## 2. 数据集、样本、特征

三者是一个**三层包含关系**：

```text
数据集（Dataset）= 整张表
┌──────────────────────────────────────────────────────┐
│  样本（Sample）    面积    卧室数    到市中心距离    价格（标签）│
│  ─────────────   ──────  ───────  ──────────────  ────────── │
│  房子 1           120㎡     3        2km           300万      │
│  房子 2           80㎡      2        5km           150万      │
│  房子 3           200㎡     4        1km           500万      │
└──────────────────────────────────────────────────────┘
                    ←────── 特征（Features）──────→   ← 标签 →
```

| 概念      | 是什么       | 对应表格中的      |
| ------- | --------- | ----------- |
| **数据集** | 所有样本的集合   | 整张表         |
| **样本**  | 一个具体的观测对象 | 一**行**      |
| **特征**  | 描述样本的属性   | 一**列**（或多列） |
| **标签**  | 要预测的目标值   | 特殊的一列       |

### 图像数据的特征

图像的**每一个像素值就是一个特征**：

```text
一张 200×200 彩色照片:

  200 × 200 × 3(RGB) = 120,000 个数值
                        ↑
                   120,000 个特征

展开成特征向量:
  [r₁, g₁, b₁, r₂, g₂, b₂, ..., r₄₀₀₀₀, g₄₀₀₀₀, b₄₀₀₀₀]
```

## 3. 维数（Dimensionality）

**维数 = 一个样本有几个特征 = 特征向量的长度。**

```text
1 个特征 → 一维：数轴上的一个点
2 个特征 → 二维：平面上的一个点
3 个特征 → 三维：空间中的一个点
N 个特征 → N 维：N 维空间中的一个点（画不出来，但算得出来）
```

N 维空间不需要能"看到"，它只是说"描述一个东西需要 N 个数字"。计算机不需要"看到"空间，只需要算数字。

比如两张图片之间的"距离"：

```text
3维空间：
  距离 = √((x₁-x₂)² + (y₁-y₂)² + (z₁-z₂)²)        3项

120,000维空间：
  距离 = √((a₁-b₁)² + (a₂-b₂)² + ... + (a₁₂₀₀₀₀-b₁₂₀₀₀₀)²)  120,000项
        （a、b 是两张图片的特征向量，下标是维度编号）

  公式结构完全一样
```

### 固定长度 vs 不固定长度

| 类型 | 示例 | 维数 |
|------|------|------|
| **固定长度** | 房价数据（每套房都有面积、卧室数、距离） | 统一维数，方便处理 |
| **不固定长度** | 文本（"好极了" vs "这个产品非常好用推荐购买"） | 长度不一，需要特殊处理 |

深度学习的一个主要优势就是可以处理不同长度的数据。

## 4. i.i.d. 假设

大多时候，我们假设样本遵循**独立同分布**（independently and identically distributed, i.i.d.）：

- **独立**: 样本之间互不影响
- **同分布**: 所有样本来自同一个概率分布

### 语音数据违反 i.i.d.

语音流数据几乎在所有层面都违反 i.i.d.：

| 层面 | 违反情况 |
|------|---------|
| **独立性** | 相邻帧之间存在极强的时序依赖（声道是惯性系统、音素按顺序排列） |
| **同分布** | 说话人不同、环境不同、设备不同，分布会漂移 |

工程实践中通过分帧、切片、数据增强和 shuffle 在**训练样本层面近似 i.i.d.**，同时用 [[序列模型]] 在推理时显式建模时序依赖。

## 5. 损失函数：给参数打分

### 先分清三个名字

这三个词日常常被混用，看论文时区分清楚会少很多困惑：

| 名称 | 指什么 |
|---|---|
| **损失函数** loss | 通常指**单个样本**的误差，如 $(\hat y_1 - y_1)^2$ |
| **代价函数** cost | 整个数据集上的**平均**，如 $\frac{1}{n}\sum_i(\hat y_i - y_i)^2$ |
| **目标函数** objective | 最终真正要优化的对象 = 代价函数 + 正则项等附加项 |

本文后面统称"损失函数"，需要精确时再区分。

另外约定一个记号：**$\hat{y}$（读作 "y hat"）表示模型的预测值，$y$ 表示真实值**。两者必须用不同记号，否则"预测减真实"就写不出来了。

### 它回答什么问题

当前模型的参数好不好？

```text
模型：房价 = w × 面积

w = 1   → 预测 100，实际 200，打分 = (100-200)² = 10000  差
w = 1.5 → 预测 150，实际 200，打分 = (150-200)² = 2500   好一些
w = 2   → 预测 200，实际 200，打分 = (200-200)² = 0      完美
```

"学习"就是沿着损失曲线往最低点走。

### 平方误差（Squared Error）

最常见的损失函数：**(预测值 - 真实值)²**

为什么用平方而不是直接算差值？

| 需求 | 平方误差 | 直接加误差 | 绝对值误差 |
|------|---------|-----------|-----------|
| 正负不抵消 | 是 | 否（+20 和 -20 相加为 0） | 是 |
| 大错误重罚 | 是（偏差 20 的惩罚远大于偏差 10） | 否 | 否（线性增长） |
| 光滑可求导 | 是（处处光滑） | 否 | 否（零点有尖角） |

### 替代目标（Surrogate Objective）

有些真正想优化的目标没法直接优化，需要换一个能算的来代替：

```text
分类任务中：

  真正目标（错误率）：猜对/猜错，阶梯形，没法求导 → 无法指导学习
  替代目标（交叉熵）：光滑曲线，处处可求导 → 可以学习

  交叉熵越小 → 正确类别的概率越高 → 猜对越多 → 错误率越低
  替代目标 ↓  ≈  真正目标 ↓   （方向一致，所以能代替）
```

### 交叉熵（Cross-Entropy）

分类任务中最常用的损失函数：**-log(模型给正确答案的概率)**

```text
一张猫图，模型输出 P(猫) = 0.7

交叉熵 = -log(0.7) = 0.36
```

| 模型给正确答案的概率 | 交叉熵 | 含义 |
|-------------------|--------|------|
| 0.01 | 4.61 | 猜得离谱，重罚 |
| 0.3 | 1.20 | 不太确定 |
| 0.7 | 0.36 | 比较自信 |
| 0.99 | 0.01 | 非常确定，几乎无惩罚 |

交叉熵比错误率更"细腻"——能区分"勉强猜对"（P=0.51）和"自信猜对"（P=0.99）。

### log 函数

log 回答的问题是"底数要乘几次才等于这个数"：

```text
2 × 2 × 2 = 8  →  log₂(8) = 3（"2 乘 3 次等于 8"）
```

**底数约定**：上面用 2 做例子便于理解，但**机器学习里的 log 默认是自然对数 ln（底数 e ≈ 2.718）**。上面交叉熵表里的数值用的都是 ln，例如 $-\ln(0.7) = 0.357$。换底只相当于整体乘一个常数，不影响"往哪个方向优化"，所以无关紧要——但看数值时要知道用的是哪个底。

ML 中用 log 的原因：

- **压缩大数字**: 概率连乘容易变成极小数（0.0000003），取 log 变成正常的加法（-15.0）
- **-log(p) 的形状天然适合当损失**: p 接近 0 惩罚极大，p 接近 1 惩罚为 0
- **光滑可求导**: log(x) 的导数 = 1/x，简单好算

### 模型为什么输出概率而不是直接给答案？

```text
模型内部流程：

  图片输入 → 一顿矩阵运算 → 原始数字 [猫: 2.5, 狗: 1.2]
                                        ↓
                              Softmax（把数字转成概率）
                                        ↓
                              概率 [P(猫)=0.79, P(狗)=0.21]
                                        ↓
                              取最大的 → "是猫"
```

原因：概率是连续数值，可以一点一点调整来逐步学习。"猫"或"狗"是离散标签，没法微调。

### 损失函数是怎么来的

**它是人选的，不是算出来的**——根据任务性质做的设计选择。但选择不是随意的，有三条硬性要求：

| 要求 | 为什么 |
|---|---|
| 预测完全正确时为 0，其余为正 | 否则"越小越好"没有基准 |
| 单调：预测越离谱值越大 | 这样"减小损失"才等同于"改善模型" |
| **光滑可导** | 梯度下降靠求导找方向，不可导就没有方向可言 |

第三条最容易被忽略，却是决定性的——正是它逼出了上面"替代目标"的存在：错误率是阶梯形的，改一点点参数要么没变化、要么突然跳一格，**导数处处为 0 或不存在，完全无法指导学习**，所以只能换光滑的交叉熵来优化。

### 但常用的那几个可以推导出来

平方误差和交叉熵不是拍脑袋定的，它们都能从同一个原则推出：**让"模型认为观测到的数据有多可能"最大化**（极大似然估计）。

**交叉熵的推导**。设模型对第 $i$ 个样本给出的"真实类别的概率"是 $p_i$。假设样本独立，模型认为这整批数据会长成这样的概率是连乘，我们希望它尽可能大：

$$\max \prod_i p_i \iff \max \sum_i \log p_i \iff \min \Big(-\sum_i \log p_i\Big)$$

取对数把乘法变加法，加负号把最大化变最小化——**最右边那个式子就是交叉熵**。所以 $-\log p$ 不是有人觉得形状好看才挑的，它是"让数据的联合概率最大"的等价改写。

```text
数值验证（三个样本，概率 0.7、0.9、0.4）：
  连乘        0.7 × 0.9 × 0.4          = 0.252
  −Σ ln p    −(ln0.7 + ln0.9 + ln0.4)  = 1.3783
  −ln(连乘)  −ln(0.252)                = 1.3783   ← 完全相同
```

这也解释了为什么必须取 log 而不能直接连乘：

```text
1000 个样本每个概率 0.9，连乘 = 0.9^1000 = 1.75e−46
单精度浮点能表示的最小正数约 1.18e−38  →  直接下溢成 0，信息全丢
取 log 后：1000 × ln(0.9) = −105.36    →  完全正常的数
```

**平方误差的推导**。假设真实值等于预测再加一点噪声，且噪声服从正态分布 $\varepsilon_i \sim N(0, \sigma^2)$。正态分布密度里有 $\exp\!\big(-\frac{(y_i - \hat y_i)^2}{2\sigma^2}\big)$ 这一项，把所有样本的密度连乘取对数，指数项掉下来变成求和，常数项与优化无关可以扔掉，剩下的正是：

$$\min \sum_i (y_i - \hat{y}_i)^2$$

**所以选平方误差不是中立的，它内含"误差服从正态分布"这个假设。** 数据里有大量离群点时这个假设不成立，换 MAE 或 Huber 往往更合适。

### 换个损失函数，学出来的参数就不一样

用第 7 节那三条房价数据实测：

```text
MSE（平方误差）: 最优 w ≈ 2.500，损失 0.5000
MAE（绝对误差）: 最优 w ≈ 2.667，损失 0.5556
```

**损失函数不是评分工具，它定义了"什么叫好"**——平方误差重罚大偏差，会更迁就离群点；绝对值误差对离群点更不敏感。

### 常见损失函数一览

| 损失函数 | 公式 | 用于 | 背后的假设 |
|---|---|---|---|
| 平方误差 MSE | $(\hat y - y)^2$ | 回归 | 噪声正态分布 |
| 绝对误差 MAE | $\lvert \hat y - y\rvert$ | 回归，数据有离群点 | 噪声拉普拉斯分布 |
| Huber | 小误差用平方、大误差用绝对值 | 回归，兼顾两者 | 折中 |
| 交叉熵 | $-\log p_{\text{正确类}}$ | 分类 | 极大似然 |

MAE 在 0 点有尖角不可导，这是它的代价；Huber 就是为修这个问题而生——小误差区域用平方（光滑），大误差区域用绝对值（抗离群），接缝处刚好接得上。

## 6. "学习"的过程

**"学"就是反复调整参数，让预测和真实答案之间的差距越来越小。**

```text
第 1 步：猜一个参数值
第 2 步：用数据算一下差多少（损失）
第 3 步：朝"差更少"的方向调一调参数
重复 2 和 3，直到差得足够小 → 学完了
```

### 训练集与测试集

| 数据集 | 作用 | 类比 |
|--------|------|------|
| **训练集** | 用于调整模型参数 | 模拟考试 |
| **测试集** | 用于评估模型在新数据上的表现 | 真正的期末考试 |

训练集上表现好不代表测试集上也好，就像模拟考考得好不一定期末考也好。

## 7. 梯度下降：参数怎么被调出来

第 6 节说"朝差更少的方向调一调参数"——这句话背后的机制就是**梯度下降**，它是深度学习的核心引擎。用最小的例子走一遍。

### 例子：一个参数的房价模型

模型 $\hat{y} = w \cdot x$，只有一个待定的数 $w$。三条数据（面积单位百平米，价格单位百万）：

```text
面积 x    真实价格 y
  1          3
  2          4
  3          8
```

损失取三条数据平方误差的平均：

$$L(w) = \frac{1}{3}\sum_{i=1}^{3} (w x_i - y_i)^2$$

先随便猜 $w = 1$：

```text
预测 ŷ: 1×1=1    1×2=2    1×3=3
真实 y:   3        4        8
误差:    −2       −2       −5
平方:     4        4       25

L(1) = (4 + 4 + 25) / 3 = 11
```

损失 11。**现在的问题是：该把 $w$ 调大还是调小？调多少？**

### 导数告诉你往哪边走

$L(w)$ 画出来是一条开口向上的抛物线，**导数就是曲线在某点的斜率**，恰好回答了方向问题：

```text
斜率为负  →  曲线正在下降  →  往右走（增大 w）损失会变小
斜率为正  →  曲线正在上升  →  往左走（减小 w）损失会变小
斜率为零  →  到底了        →  这就是最低点
```

对损失求导得：

$$\frac{dL}{dw} = \frac{2}{3}\sum_{i=1}^{3} x_i\,(w x_i - y_i)$$

在 $w=1$ 处代入（误差是 −2, −2, −5）：

$$\frac{2}{3}\big[1 \times (-2) + 2 \times (-2) + 3 \times (-5)\big] = \frac{2}{3}(-21) = -14$$

**斜率 −14，负的，所以要增大 $w$**；绝对值大，说明离最低点还远，可以迈大步。

### 更新规则

$$w \leftarrow w - \eta \cdot \frac{dL}{dw}$$

$\eta$（读作 eta）叫**学习率**，控制每次迈多大步。**减号是关键**：导数指向上坡方向，要下山就得往反方向走——"梯度下降"的名字由此而来。

取 $\eta = 0.05$ 反复执行：

```text
步  w        损失      梯度
 0  1.0000   11.0000  −14.0000
 1  1.7000    3.4867   −7.4667
 2  2.0733    1.3495   −3.9822
 3  2.2724    0.7416   −2.1239
 4  2.3786    0.5687   −1.1327
 5  2.4353    0.5196   −0.6041
 6  2.4655    0.5056   −0.3222
 7  2.4816    0.5016   −0.1718
 8  2.4902    0.5004   −0.0916
```

**这就是"训练"的全过程。** 损失从 11 降到 0.50，$w$ 逼近 2.5，梯度趋近 0——**越靠近谷底梯度越小，步子自动变小，不需要人为减速**。

注意最小损失不是 0：数据本身带噪声，没有任何一条过原点的直线能穿过全部三个点。**能做的只是让总误差最小，而不是消灭误差**——硬要穿过每个点就是第 8 节的过拟合。

### 学习率：唯一需要人来定的旋钮

```text
η = 0.005（太小）        η = 0.05（合适）      η = 0.25（太大）
步0  w=1.0000 损失11.00   w=1.000 损失11.00     w= 1.000 损失  11.0
步1  w=1.0700 损失10.04   w=1.700 损失 3.49     w= 4.500 损失  19.2
步2  w=1.1367 损失 9.17   w=2.073 损失 1.35     w=−0.167 损失  33.7
步3  w=1.2004 损失 8.38   w=2.272 损失 0.74     w= 6.056 损失  59.5
步4  w=1.2610 损失 7.66   w=2.379 损失 0.57     w=−2.241 损失 105.4
步5  w=1.3188 损失 7.01   w=2.435 损失 0.52     w= 8.821 损失 187.0
```

太小就是磨蹭，几百步还没到；**太大会冲过头，在谷底两侧来回弹且越弹越远，损失不降反升直接发散**。

学习率不是模型学出来的，是人设定的——这类量叫**超参数**，区别于模型自己学出来的**参数**（$w$）。常见超参数还有：网络层数、每层神经元数、批量大小、训练轮数。

### 从一个参数到几十亿个

真实模型不止一个参数。$n$ 个参数时，对每个参数分别求偏导，排成一个向量：

$$\nabla L = \left(\frac{\partial L}{\partial w_1},\ \frac{\partial L}{\partial w_2},\ \dots,\ \frac{\partial L}{\partial w_n}\right)$$

这个向量叫**梯度**（记号 $\nabla$ 读作 nabla）。它是一个货真价实的向量（见 [[向量与点积]]），方向指向损失上升最快的方向，所以往反方向走就是下降最快的路。更新规则一模一样，只是标量换成向量：

$$\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla L$$

[[神经网络]] 里那个 9 参数的小网络，梯度就是 9 维向量；7B 模型的梯度是 70 亿维向量。**机制完全相同，只是维度变了。**

剩下的问题是几十亿个偏导数怎么高效算出来——答案是**反向传播**，它不是另一种学习方法，只是一套让求导变快的算法（利用链式法则从后往前逐层复用中间结果），详见 [[大模型如何训练]]。

### 重要提醒：梯度下降不是唯一的训练方式

上面这个例子其实有**闭式解**，令导数为零直接解方程即可：

$$\frac{dL}{dw} = 0 \;\Longrightarrow\; w^* = \frac{\sum_i x_i y_i}{\sum_i x_i^2} = \frac{35}{14} = 2.5$$

一步到位，不用迭代九次。用梯度下降跑它纯粹是为了让机制看得见。

**深度学习之所以必须用梯度下降，是因为闭式解只在极少数简单模型上存在**——神经网络的损失是几十亿参数的高度非线性函数，套了几十层 ReLU，根本解不出来，只能迭代摸下去。梯度下降是"解不出来时的退路"，不是更高级的方法。

而且它有硬性前提：**参数连续、损失可导**。不满足的方法根本用不了它：

| 方法 | 怎么训练 | 用梯度下降吗 |
|---|---|---|
| 线性回归 | 闭式解，一个公式算出最优参数 | 不需要 |
| 朴素贝叶斯 | 直接统计频率，一遍扫完 | 不用 |
| 决策树 | 贪心搜索，每步选信息增益最大的切分 | 不用（切分离散不可导） |
| KNN | **完全没有训练过程**，存下数据，预测时现找邻居 | 不用 |
| K-means | 交替执行"分配点到簇心"和"重算簇心" | 不用 |
| GBDT | 在**函数空间**上逐棵加树 | 是梯度**提升**，不是梯度下降 |
| 神经网络 | 前向算损失 → 反向传播 → 更新参数 | **必须用** |

所以概念的通用范围是分层的：**数据集、过拟合、泛化、超参数**这些几乎所有方法都适用；**损失函数 + 梯度下降**只是其中一支，但在深度学习内部 100% 通用（见第 9 节）。

## 8. 过拟合（Overfitting）

**过拟合 = 模型把数据中的随机噪声也当成了规律。**

```text
真实规律:  一条直线（房价 = 2 × 面积）
训练数据:  直线上的几个点 + 一些随机波动（噪声）

正常学习:  找到了那条直线（忽略噪声） → 新数据也能预测
过拟合:    画了一条扭曲的曲线穿过每个点  → 训练集完美，新数据崩溃
```

### 为什么会过拟合？

参数太多 + 数据太少 → 满足数据的答案太多 → 模型随便挑了一个（大概率不是真正的规律）

```text
3 个数据点，1 个参数 → 解几乎唯一 → 被迫找到规律
3 个数据点，6 个参数 → 无穷多解 → 随机选到一个扭曲的曲线
```

### 怎么解决

| 方法 | 原理 |
|------|------|
| 加数据 | 数据越多，噪声影响越小，规律越明显 |
| 简化模型 | 减少参数，逼模型只学大趋势 |
| 正则化 | 人为惩罚过大的参数，限制模型的"自由度" |
| 早停 | 训练到"差不多"就停，别继续钻研噪声 |

## 9. 深度学习 vs 传统机器学习

**不是替代关系，各有各的地盘。**

| 场景 | 谁更合适 | 原因 |
|------|---------|------|
| 100 条数据预测房价 | 传统（线性回归、决策树） | 数据太少，深度学习过拟合 |
| 表格数据（Excel） | 传统（XGBoost） | 特征含义明确，不需要自动提取 |
| 图像分类 | 深度学习（CNN） | 像素级特征人工提不好 |
| 语音识别 | 深度学习（Transformer） | 变长序列、复杂模式 |

### 为什么深度学习能处理变长数据？

**参数共享**：同一组参数在输入的每个位置上复用。

```text
传统方法：每个位置一套专属参数 → 长度变了参数就对不上 → 必须固定长度
深度学习：同一组参数在每个位置复用 → 输入变长只是多复用几次 → 任意长度
```

以 RNN 为例，只有一个"员工"，从第一个字读到最后一个字：

```text
每一步做的事（永远同一个公式）：
  新的理解 = f(上一步的理解, 当前这个字)

3 个字 → 执行 3 次 f
10000 个字 → 执行 10000 次 f
同一个 f，参数不变
```

### 为什么深度学习在小数据上反而更差？

参数太多 + 数据太少 = 过拟合

```text
100 条数据，3 个特征

线性回归：学 3 个参数 → 100 条数据绰绰有余
深度学习：学几万个参数 → 100 条数据远远不够
```

## 10. 三种学习方式

```text
监督学习：  有标准答案   "这张是猫，这张是狗"     ← 用得最多
无监督学习：没有答案     "这里有一堆图片，你自己找规律"
强化学习：  只有奖惩     "做对了给奖励，做错了扣分，自己摸索"
```

监督学习依然是主力——只要有标准答案，它就是最简单高效的方法。现代大模型（如 ChatGPT）是先用监督学习打基础（90%），再用强化学习（RLHF）微调回答风格（10%），两者配合而非替代。

详细的监督学习任务类型见 [[监督学习任务]]。
