# 大语言模型（LLM）

> 一个只会做一件事的神经网络：给定前面的文字，输出下一个 token 的概率分布

> [!note] 定位
> 本文是 LLM 这一层的**总览**，讲它是什么、怎么训出来的。
> 想看一次调用具体怎么一步步走（各步数据形状、采样、KV 缓存），见 [[AI/Map|AI 知识地图]]。
> 单点细节分别在 [[Transformer]]（层内怎么连）、[[Token 与 Embedding 表]]（文字怎么变向量）、[[大模型如何训练]]（参数怎么练出来）。

## TL;DR

- **一句话定义**：一个参数极多的神经网络，输入一段文字，输出**下一个 token 的概率分布**（不是一个词）
- **生成 = 自回归循环**：采样一个 token → 接回输入末尾 → 再算一次，你看到的流式输出就是这个循环
- **每层还是"矩阵乘法 + 非线性"**，和 9 参数的小网络同构，只是矩阵大、层数多
- **"7B 参数"是实数**：权重矩阵里真的有 70 亿个数，全部由梯度下降调出来
- **训练目标就是交叉熵**，且数据**不需要人标注**——每个位置的下一个词天然是标签，这叫自监督
- **智能是副产品**：要把下一个词猜准，就不得不学会语法、事实、推理、文体
- **三阶段**：预训练（学知识）→ 指令微调（学会被问就答）→ 对齐 RLHF（学会符合人类偏好）
- **base model 只会续写**，不会回答；带 -Instruct / -Chat 后缀的才是日常用的那种
- **它优化的目标里没有"说真话"这一项**——幻觉是机制的直接后果，不是 bug

## 1. 它到底输出什么

**输出的不是一个词，是一个概率分布。** 这是最关键也最常被误解的一点。

假设词表有 32000 个 token，模型最后一层输出的是一个 **32000 维的向量**，每一维对应词表里的一个 token：

```text
输入："今天天气真"

输出（32000 维向量，经 Softmax 变成概率）：
   "好"    → 0.42
   "不错"  → 0.15
   "热"    → 0.09
   "冷"    → 0.06
   ...
   "香蕉"  → 0.000001
   （全部 32000 个数加起来等于 1）
```

然后按这个分布**采样**一个 token。**温度**（temperature）调的就是采样的随意程度：温度低总挑概率最高的，温度高允许挑到冷门选项。

生成一整段话是把这个过程**循环**：把刚生成的 token 接到输入末尾，再算一次，再采样……这叫**自回归**（autoregressive）。流式输出一个字一个字往外蹦，就是这个循环在转。

## 2. 完整链路

```text
文字  "今天天气真"
  ↓  分词器                                  ← [[Token 与 Embedding 表]]
token [今天][天气][真]
  ↓  查 embedding 表（取出对应行，零计算）
3 个 4096 维向量                             ← [[向量与点积]]
  ↓  第 1 层：矩阵乘法 + 非线性               ← [[矩阵与线性变换]]、[[神经网络]]
3 个 4096 维向量
  ↓  第 2 层：同样的操作
  ⋮   （重复 32 层）                          ← 层内怎么连见 [[Transformer]]
  ↓  第 32 层输出
  ↓  最后乘一个 4096×32000 的矩阵
32000 维向量（logits，还不是概率）
  ↓  Softmax
32000 个概率，加起来 = 1
  ↓  采样
下一个 token
```

**每一层就是一次矩阵乘法加一次非线性**，和 [[神经网络]] 里那个 9 参数的小网络结构同构。Transformer 的特殊之处在于层内怎么连（注意力机制），但"线性变换 → 掰弯 → 线性变换"这个骨架完全没变。

## 3. "7B 参数"具体是怎么凑出来的

参数就是那些矩阵里的每一个数。粗算一个 7B 级别的模型（以 LLaMA-2 的经典配置为例）：

```text
隐藏维度 d = 4096，层数 32，词表 32000

一个 4096×4096 矩阵          = 1678 万个参数
每层注意力有 4 个这样的矩阵    ≈ 6700 万        （Q、K、V、O 四个投影）
每层前馈有 2 个 4096×16384    ≈ 1.34 亿
──────────────────────────────────────
每层合计                      ≈ 2 亿
× 32 层                       ≈ 64.4 亿
+ embedding 表 32000×4096     ≈ 1.3 亿
──────────────────────────────────────
总计                          ≈ 65.7 亿  →  这就是"7B"
```

（现代模型的前馈层结构略有不同，此处是量级估算。）

**"70 亿参数"不是修辞，是真的有 70 亿个待定的数**，每一个都由梯度下降调出来。

## 4. 它是怎么学会的

训练目标就是**交叉熵**，和 [[机器学习基础概念]] 里的极大似然推导严丝合缝。

拿一句真实语料"今天天气真好"，在"今天天气真"这个位置上正确答案是"好"。若模型给"好"的概率是 0.42，这一步的损失是 $-\ln(0.42) = 0.868$：

```text
模型给正确词的概率    损失
      0.9            0.105    ← 猜得准，几乎不罚
      0.42           0.868
      0.05           2.996    ← 猜得离谱，重罚
```

整段语料的损失是各位置的平均。然后**反向传播求出这 70 亿个参数各自的梯度，沿反方向更新**——和一参数房价模型的机制完全一致，只是梯度从一个数变成 70 亿维的向量。

### 关键：训练数据不需要人标注

这是大模型能做大的**根本原因**。任何一段文字本身就自带答案——每个位置的"下一个词"就是标签：

```text
"今天天气真好" 这一句，自动拆成 5 条训练样本：

  输入 "今"          → 答案 "天"
  输入 "今天"        → 答案 "天气"
  输入 "今天天气"    → 答案 "真"
  输入 "今天天气真"  → 答案 "好"
```

这叫**自监督学习**（self-supervised）。正因为标签是白来的，才能拿整个互联网的文本去训练。传统监督学习要人一条条标注，规模天然受限——**这条界限被跨过去，是大模型出现的前提**。

## 5. 为什么"猜下一个词"能产生像智能的行为

这是最反直觉的地方，但道理不神秘：**要把下一个词猜准，就不得不学会一大堆东西。**

```text
要猜对 "法国的首都是___"              →  必须记住事实
要猜对 "他把书放在桌上，然后拿起了__"  →  必须追踪指代和状态
要猜对 "3 + 5 = __"                   →  必须会做加法
要猜对代码的下一行                     →  必须懂语法和逻辑
要猜对 "尊敬的领导：___"               →  必须掌握文体和语域
```

**这些能力不是被单独训练出来的，是"把下一个词的损失压到最低"这个单一目标的副产品。** 模型没被教过语法规则、没被给过事实数据库，它只是在几万亿 token 上被反复惩罚"猜错"，最后不得不把这些规律压进那 70 亿个参数里。

**"大"体现在三处**：参数量（几十亿到上万亿）、训练数据量（万亿级 token）、算力（千卡集群跑数月）。三者缺一不可。

## 6. 三个训练阶段

第 1~5 节描述的其实只是**第一阶段**的产物。

```text
① 预训练 Pretraining
   数据：万亿级 token 的互联网文本，无需标注（自监督）
   目标：猜下一个词，交叉熵损失
   代价：千卡集群跑数月
   产出：base model —— 有知识，但只会续写
        ↓
② 指令微调 SFT（Supervised Fine-Tuning）
   数据：人工编写的「指令 → 理想回答」配对，几万到几十万条
   目标：还是猜下一个词，只是语料换成了对话格式
   代价：几小时到几天
   产出：学会「被问就答」这个行为模式
        ↓
③ 对齐 RLHF / DPO
   数据：人对同一问题的多个回答做排序打分
   目标：最大化人类偏好（有用、无害、诚实）
   方法：训练一个奖励模型，再用强化学习优化
   产出：chat model / instruct model —— 日常用的那个
```

第 ③ 步正是**强化学习**（见 [[机器学习基础概念]] 第 10 节）在大模型里最主流的应用：没有标准答案，只有奖励信号，目标是最大化累积回报。

### base model 只会续写，不会回答

这一点很反直觉，值得单独看：

```text
你输入： "中国的首都是哪里？"

base model 可能续写：
   "2. 日本的首都是哪里？
    3. 法国的首都是哪里？
    4. 德国的首都是哪里？"

← 因为它在互联网上见过大量习题列表，
   "一个问句后跟着更多问句" 是很常见的模式
```

它没有任何"我应该回答用户"的概念。**它优化的目标从头到尾只有"下一个 token 的概率"，从来没人告诉过它要当助手。**

### 后两步几乎不教新知识

看数据量的对比：

```text
预训练： 万亿级 token       （10¹² 量级）
SFT：    几万条对话         （10⁷ token 量级）
```

**差了五六个数量级。** 几万条数据不可能往 70 亿参数里塞进新知识，它能做的只是**把已有能力往某个方向轻轻掰一下**。

概括成一句：**预训练学知识，微调学格式。** 模型知道的事实、掌握的语言、会的推理，绝大部分在第 ① 步就定型；后两步改变的是它**怎么表达**，不是它**知道什么**。

这解释了几个现象：微调没法让模型学会它本来不知道的领域知识（得靠 RAG 或继续预训练）；"越狱"之所以可能，是因为底下那个只会续写的 base model 一直都在，对齐只是加了一层行为倾向，没有把知识删掉。

### 怎么分辨拿到的是哪一种

```text
Llama-3-8B              ← base model，只会续写
Llama-3-8B-Instruct     ← 微调对齐过的，会对话

后缀 -Instruct / -Chat / -it 都表示"已微调"
没有后缀的通常是 base
```

**base model 并非没用**：它是所有微调的起点，做纯文本续写（如代码补全）时反而更好使，研究模型能力时也需要它——因为它没被对齐层遮住。

## 7. 它不是什么

这几条直接解释了大模型的典型失败。

**不是数据库检索。** 参数里存的不是原文，是被压缩过的统计规律。所以它会"记错"——生成语法通顺、看起来合理但事实错误的答案，这就是**幻觉**。注意：**它的优化目标里没有任何一项是"说真话"**，只有"下一个 token 的概率高"。幻觉是机制的直接后果，不是实现上的 bug。

**不是符号推理引擎。** 它做算术靠的是见过大量算式后的模式匹配，不是执行加法，所以位数一多就容易出错。

**不是有记忆的实体。** 每次调用都是把整段上下文重新算一遍，模型本身不保存状态；"记住上文"是因为上文被完整地重新喂了进去，这也是上下文窗口有长度上限的原因。
