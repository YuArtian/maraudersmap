# Transformer

> 完全靠注意力机制处理序列的神经网络架构，GPT、BERT、Claude 等一切大模型的地基

> [!note] 定位
> 本文讲**层内怎么连**：注意力是什么、一层由哪些部件组成、为什么这样组。
> 想看一次调用从文字到文字的完整机械过程（各步形状、KV 缓存、采样），见 [[AI/Map|AI 知识地图]]。
> 想看 LLM 这一层的总览（训练三阶段、幻觉的由来），见 [[大语言模型]]。
> 分不清 W_q 和 Q、参数和激活值，见 [[模型里的四类数字]]。

## TL;DR

- **注意力 = 加权求和**，特殊之处只有一点：**权重不是训练出来的参数，是当场按数据算出来的激活值**——同一组权重矩阵，换一句话，权重就全变了
- **它原本是 RNN 的补丁**（2014 年，为修机器翻译的信息瓶颈），2017 年才被证明"补丁本身就够了，主体可以扔掉"
- **公式**：$\mathrm{softmax}(QK^\top/\sqrt{d_k})\,V$——四步：算分、缩放、归一化、加权求和
- **除 $\sqrt{d_k}$ 不是玄学**：点积的标准差随维度按 $\sqrt{d}$ 增长，$d_k{=}64$ 时分数散布在 ±8，不缩放 softmax 直接饱和成 `[0,1,0,0,0]`，梯度掉到 $10^{-6}$ 量级，训不动
- **Transformer 真正的胜因是并行**，不是"长距离依赖"。RNN 必须一个词一个词算，注意力一次算完整句，GPU 才喂得饱
- **一层 = 多头自注意力 + 前馈网络**，各配一次残差连接和层归一化
- **三大流派**：BERT（只编码器）、GPT（只解码器，当今绝对主流）、T5（完整编码-解码）
- 前置：[[向量与点积]]、[[矩阵与线性变换]]、[[神经网络]]、[[序列模型]]

## 0. 先把层级摆清楚

"注意力"和"Transformer"经常被混着说，其实是六个不同粒度的东西，一层套一层：

| 层级 | 名字 | 是什么 |
|---|---|---|
| ① 运算 | 加权求和 | $\sum_i w_i v_i$，最基础的线性运算，见 [[向量与点积]] |
| ② 机制 | 注意力 Attention | 加权求和，但**权重由数据当场算出**，不是固定参数 |
| ③ 用法 | 自注意力 Self-Attention | 注意力的一种用法：Q、K、V 全来自同一个序列 |
| ④ 工程改良 | 多头注意力 | 把自注意力拆成 h 份并行做，再拼回来 |
| ⑤ 架构 | Transformer | 多头注意力 + 前馈网络 + 残差 + 层归一化，堆 N 层 |
| ⑥ 具体模型 | GPT / BERT / LLaMA | 选 Transformer 的哪半边 + 怎么训练 + 具体超参 |

**一句话记住关系**：注意力是**机制**，Transformer 是**架构**。机制可以脱离架构存在（2014–2016 年的注意力长在 RNN 身上），架构不能脱离机制（把注意力抽走，Transformer 什么都不剩）。

## 1. 注意力到底是什么

### 一句话定义

> **注意力 = 一次加权求和，其中权重是根据当前输入现场算出来的。**

先看它不特殊的那一半。[[神经网络]] 里一个神经元做的事就是加权求和：

$$y = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b$$

注意力做的也是加权求和：

$$\text{输出} = a_1 v_1 + a_2 v_2 + \dots + a_n v_n$$

形式一模一样。**唯一的区别在 $w$ 和 $a$ 的来历**：

```text
普通神经元的 w：  训练时由梯度下降定死，存在 safetensors 文件里
                  推理时是常数,任何输入都用同一组 w

注意力的 a：      文件里根本没有这个数
                  每次前向传播,按当前这句话现场算出来
                  换一句话 → a 全变
```

用 [[模型里的四类数字]] 的分类说：**普通权重是「参数」，注意力权重是「激活值」**。这是注意力全部威力的来源——模型不再对所有输入用同一种混合比例，而是「看情况」。

### 参数在哪

那注意力里有没有参数？有，但不是 $a$，而是**算出 $a$ 的那套矩阵**：

```text
参数（存在文件里,固定）:   W_q  W_k  W_v  W_o
激活值（现场算出,一次性）: Q  K  V  分数  a  输出
```

这条界线是本篇最容易绊人的地方，[[模型里的四类数字]] 里有专门一节。记法：**大写单字母（Q/K/V）是数据，带 W 的（W_q/W_k/W_v）是参数**。

### 为什么"权重随数据变"这件事这么重要

看这句：

```text
"我把杯子放在桌上，然后拿起了它"
```

要理解「它」，模型必须把「杯子」的信息混进「它」的向量里。但换一句：

```text
"我把书放在桌上，然后拿起了它"
```

同样的位置、同样的词「它」，要混进来的却是「书」。

**固定权重做不到这件事**——参数是训练完就冻住的，没法针对每句话换一套混合比例。注意力能做到，因为它的权重是当场从这句话本身算出来的。

## 2. 它从哪来：先有病，后有药

注意力不是凭空设计出来的，它是 2014 年为了修一个具体的病。

### 病：encoder-decoder 的信息瓶颈

2014 年做机器翻译的标准做法是 RNN 编码器-解码器（[[序列模型]]）：

```text
中文句子 → RNN 编码器逐词读 → 一个固定长度的向量（比如 512 维）→ RNN 解码器逐词写 → 英文句子
                                       ↑
                              整句话被压进这一个向量
```

问题一眼可见：**不管原句是 5 个词还是 50 个词，都要压进同一个 512 维向量**。句子一长，前面的信息就被后面的覆盖掉了。实测表现是：句子超过约 30 个词，翻译质量断崖下跌。

### 药：让解码器回头看

Bahdanau 等人 2014 年的想法：既然一个向量装不下，那就**别压了**——把编码器每一步的隐状态全都留着，解码器每写一个词，就现场算一遍「这一步该看原句的哪几个词」，按算出的权重把那些隐状态加权求和。

```text
写英文第 3 个词时:
   算权重 → 中文第1词 0.05  第2词 0.71  第3词 0.18  第4词 0.06
   上下文 = 0.05×h₁ + 0.71×h₂ + 0.18×h₃ + 0.06×h₄
```

**这就是注意力的原型。** 注意它当时的身份：RNN 的一个附加模块，主体还是 RNN。

### 2017：发现主体可以扔掉

三年里大家不断发现：模型的表现提升几乎都来自注意力那一块，RNN 那一块又慢又难训。Vaswani 等人 2017 年做了一件很激进的事——**把 RNN 整个删掉，只留注意力**，论文标题就叫 *Attention Is All You Need*（注意力就是你需要的全部）。

这个标题不是修辞，是字面意思：**除了注意力，其他都不需要**。删掉之后模型不但没变差，还因为能并行而训得更快、更大。

> 记住这条脉络：**加权求和（一直都有）→ 注意力（2014，RNN 的补丁）→ Transformer（2017，扔掉 RNN，只留补丁）**。

## 3. 自注意力：QKV 与完整数值演算

### Q、K、V 的分工

自注意力里，每个 token 同时扮演三个角色，各自由一个权重矩阵从它的向量变换出来：

```text
Q (Query,  查询)  = X @ W_q     ← 我在找什么
K (Key,    键)    = X @ W_k     ← 我可以被什么找到
V (Value,  值)    = X @ W_v     ← 被找到之后,我交出什么
```

**"自"的意思是 Q、K、V 全部来自同一个序列**（同一句话）。后面 §12 会讲不同序列的情形（交叉注意力）。

一个必答的问题：**为什么要三个矩阵？直接拿 X 和 X 自己算分不行吗？**

不行，因为 $X X^\top$ **一定是对称矩阵**——「猫看追」的分数会永远等于「追看猫」的分数。但语言里这两件事完全不对等：动词「追」非常需要知道主语是谁，名词「猫」却不一定要盯着「追」。下面的数值演算会亲眼看到这个不对称。

### 完整演算

为了能手算，把维度缩到极小：3 个 token、$d_{model}=4$、$d_k=2$。真实的 LLaMA-2 是 $d_{model}=4096$、$d_k=128$，运算完全一样，只是数大。

**输入**（经 [[Token 与 Embedding 表]] 查表 + 位置编码后得到的 $X$，$3\times4$）：

```text
        维度1 维度2 维度3 维度4
猫    [   1     0     1     0  ]
追    [   0     2     0     1  ]
老鼠  [   1     1     0     1  ]
```

**参数**（三个 $4\times2$ 的矩阵，训练学出来的）：

```text
W_q = [1 0]      W_k = [2 2]      W_v = [1 2]
      [0 1]            [0 0]            [0 1]
      [1 0]            [0 0]            [2 0]
      [1 1]            [1 0]            [1 1]
```

**第 ① 步：算出 Q、K、V**（每个都是 $3\times2$）

```text
Q = X @ W_q          K = X @ W_k          V = X @ W_v
猫   [2, 0]          猫   [2, 2]          猫   [3, 2]
追   [1, 3]          追   [1, 0]          追   [1, 3]
老鼠 [2, 2]          老鼠 [3, 2]          老鼠 [2, 4]

【得到】每个 token 的三个身份向量。注意 Q、K、V 三张表互不相同——
        这正是三个矩阵存在的意义。
```

**第 ② 步：算匹配分** $S = QK^\top$（$3\times2$ 乘 $2\times3$ → $3\times3$）

```text
S[i][j] = Q(第i个词) · K(第j个词)

           K:猫   K:追   K:老鼠
Q:猫    [   4      2      6   ]
Q:追    [   8      1      9   ]
Q:老鼠  [   8      2     10   ]

【得到】一张「谁该看谁」的原始分数表。3 个词 → 3×3 = 9 个分数。

★ 亲眼看不对称:
   S[追][猫] = 8   ← 「追」很在意「猫」（动词找主语）
   S[猫][追] = 2   ← 「猫」不太在意「追」
   同一对词,两个方向差 4 倍。若不分 W_q/W_k,这两个数将永远相等。
```

其中 $S[追][猫]$ 的手算过程：$Q(追)\cdot K(猫) = 1\times2 + 3\times2 = 8$。

**第 ③ 步：缩放并 softmax**（除以 $\sqrt{d_k}=\sqrt2\approx1.4142$，然后逐行归一化）

```text
除 √2 后:
Q:追  [ 5.6569,  0.7071,  6.3640 ]

softmax 后（这一行加起来 = 1）:
        看猫      看追      看老鼠
Q:猫  [ 0.1867   0.0454   0.7679 ]
Q:追  [ 0.3295   0.0023   0.6682 ]   ← 重点看这行
Q:老鼠[ 0.1950   0.0028   0.8022 ]

【得到】注意力权重矩阵 a。这 9 个数就是「激活值」——
        文件里没有它们,换一句话就全变。

★ 读「追」这一行:「追」把 66.8% 的注意力给了「老鼠」、
  33.0% 给了「猫」、只有 0.2% 给自己。
  一个动词几乎把全部注意力分给了它的主语和宾语——
  这正是我们希望它学会的事。
```

**第 ④ 步：按权重把 V 加权求和**（$a$ 是 $3\times3$，$V$ 是 $3\times2$ → $3\times2$）

```text
「追」的新向量
 = 0.3295 × V(猫)  + 0.0023 × V(追) + 0.6682 × V(老鼠)
 = 0.3295 × [3,2]  + 0.0023 × [1,3] + 0.6682 × [2,4]
 = [2.3271, 3.3387]

【得到】「追」进来时是 V(追)=[1,3],出去时是 [2.3271, 3.3387]——
        它的向量已经被「猫」和「老鼠」的内容重写了大半。
        这就是「上下文相融」的字面含义:一个词的向量里,
        真的物理地混进了别的词的数值。
```

三个词各做一遍，就得到一个 $3\times2$ 的新表示，形状和输入一样，但每一行都携带了全句信息。**这就是一层自注意力的全部**。

### 公式对照

$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

```text
QKᵀ        第②步  算匹配分         → n×n
÷√dₖ       第③步a 缩放             → n×n
softmax    第③步b 分数变成百分比    → n×n,每行和为 1
·V         第④步  按百分比加权求和  → n×d
```

$n$ 是 token 数，$d$ 是维度。**注意 $QK^\top$ 和 $aV$ 这两步是「数据×数据」，不涉及任何参数**——这是整个模型里少见的、形状随句子长短变化的运算，也是 $O(n^2)$ 开销的来源（见 [[AI/Map|AI 知识地图]] 第 11.3 节）。

## 4. 为什么要除以 $\sqrt{d_k}$

这一步看着像随手加的常数，其实不加就训不动。

### 病因：点积的散布随维度按 $\sqrt{d}$ 增长

两个 $d$ 维向量做点积，是 $d$ 项乘积相加。若各分量近似独立、均值 0 方差 1，则和的方差是 $d$，**标准差是 $\sqrt{d}$**。实测（每档 2 万对随机向量）：

| $d$ | 点积实测标准差 | $\sqrt{d}$ |
|---:|---:|---:|
| 4 | 2.00 | 2.00 |
| 16 | 3.99 | 4.00 |
| 64 | 8.00 | 8.00 |
| 128 | 11.33 | 11.31 |
| 4096 | 64.12 | 64.00 |

维度越高，分数散得越开。LLaMA-2 每个头 $d_k=128$，分数会散布在 ±11 甚至 ±30 的范围。

### 后果：softmax 饱和，梯度归零

取 $d_k=64$ 时一组典型的原始分数，看加不加缩放的差别：

```text
原始分数:        [ -3,      21,        9,        8,       -5    ]

直接 softmax:    [ 0.0000,  0.999992,  0.0000061, 0.0000023, 0.0000 ]
                 → 实际就是 [0, 1, 0, 0, 0],只看一个词,其他全不看

除 √64 = 8:      [ -0.375,  2.625,     1.125,    1.000,   -0.625 ]
再 softmax:      [ 0.0330,  0.6629,    0.1479,   0.1305,   0.0257 ]
                 → 主看第 2 个,同时保留对第 3、4 个的关注
```

**光是"太极端"还不致命，致命的是梯度。** softmax 输出 $p$ 对输入的敏感度正比于 $p(1-p)$：

```text
未缩放:  p(1-p) = [3.8e-11,  8.4e-06,  6.1e-06,  2.3e-06,  5.1e-12]
缩放后:  p(1-p) = [0.0319,   0.2235,   0.1260,   0.1135,   0.0250]
                                                    ↑ 差了 4~10 个数量级
```

梯度小到 $10^{-6}$ 量级，反向传播传回来的信号约等于 0，**这一层的 W_q、W_k 基本停止学习**。除以 $\sqrt{d_k}$ 就是把分数的标准差从 $\sqrt{d_k}$ 拉回 1 左右，让 softmax 工作在梯度健康的区间。

> 顺带回答一个常见疑问：为什么是 $\sqrt{d_k}$ 而不是 $d_k$？因为要抵消的是**标准差**（$\propto\sqrt{d}$），不是方差（$\propto d$）。除以 $d_k$ 会矫枉过正，把分布压得过平。

## 5. softmax：从任意分数到概率表

**任务**：把一排任意大小的分数改造成合法的概率表——每项非负、总和为 1。

**天真方案为什么不行**：直接除以总和？`[8, 4, -2]` 总和是 10，$-2$ 变成 **$-20\%$**，负概率毫无意义；分数正负抵消时总和为 0，除法直接爆炸。问题根源：分数里有负数。

**softmax 两步**：

```text
第1步: 每个分数 x 换成 eˣ    ← 全员变正（e⁻²≈0.1353）,大小顺序不变
第2步: 每个除以总和          ← 变成加起来等于 1 的百分比

分数:      [ 8,          4,         -2      ]
eˣ:        [ 2980.958,   54.598,     0.1353 ]    总和 = 3035.691
softmax:   [ 0.9820,     0.0180,     0.0000 ]
```

**名字由来**：soft + max，"软化版的取最大值"：

```text
hardmax:  [1, 0, 0]                ← 只认第一名,赢家通吃
softmax:  [0.9820, 0.0180, 0.0000] ← 第一名拿大头,其他按实力分残羹
```

**脾气：指数急剧放大差距**。分数 8 和 4 只差 4，但 $e^8$ 是 $e^4$ 的 **54.6 倍**——差距越大越接近赢家通吃。两个著名的"调软"手段，本质都是进 softmax 前先把分数除以一个数：

```text
[8, 4, -2] 直接 softmax     → [0.9820, 0.0180, 0.0000]   一边倒
[8, 4, -2] 先除 2 再 softmax → [0.8756, 0.1185, 0.0059]   立刻温和
```

| 手段 | 在哪 | 作用 |
|---|---|---|
| $\div\sqrt{d_k}$ | 注意力公式里 | 见上一节：维度高时点积分数大，不除就一边倒，且梯度归零 |
| temperature | LLM 采样时 | 词表打分先除以 $T$ 再 softmax。$T$ 小→分布尖→输出稳定可复现；$T$ 大→分布平→冷门词也有机会 |

调 API 时拧的 temperature，底层就是在拧 softmax 的"软硬度"。注意二者位置完全不同：$\sqrt{d_k}$ 在**每一层的注意力内部**、是写死的常数；temperature 在**最后输出头之后**、是调用时可传的参数。

**三个主场**：注意力权重（$QK^\top$ 分数 → 百分比）、生成下一个词（词表打分 → 概率表，见 [[AI/Map|AI 知识地图]] 第 10 节）、一切分类任务的最后一层。

## 6. 因果掩码：让模型不能偷看答案

GPT 这类只解码器模型在训练时整句话一起进网络，但训练目标是「用前面的词猜下一个词」。如果第 1 个位置能看到第 5 个位置，它就直接把答案抄过来了，什么也学不到。

做法：**在 softmax 之前，把分数表右上三角全部置为 $-\infty$**。$e^{-\infty}=0$，softmax 之后这些位置的权重精确等于 0。

用 §3 的分数表演示（缩放后）：

```text
掩码前:                          掩码后:
[ 2.83   1.41   4.24 ]           [ 2.83   -∞     -∞   ]
[ 5.66   0.71   6.36 ]     →     [ 5.66   0.71   -∞   ]
[ 5.66   1.41   7.07 ]           [ 5.66   1.41   7.07 ]

softmax 后:
猫   [ 1.0000  0       0      ]   ← 第一个词只能看自己
追   [ 0.9930  0.0070  0      ]   ← 只能看「猫」和自己
老鼠 [ 0.1950  0.0028  0.8022 ]   ← 全都能看

【得到】一个下三角的权重矩阵。「猫」这一行的输出等于 V(猫) 原封不动,
        因为它没有任何上文可看。
```

对比 §3 未掩码时「追」看「老鼠」有 66.8% 的权重——掩码后这条路被彻底切断。BERT 不加这个掩码（它做完形填空，前后文都该看），GPT 加，这是两大流派最根本的差别。

## 7. 多头注意力

一组 $W_q/W_k/W_v$ 只能算出一张权重表，也就是**一种关注模式**。但一句话里同时存在很多种关系：指代、主谓、修饰、短语边界……一张表装不下。

**多头 = 把 $d_{model}$ 切成 $h$ 段，每段配一套独立的 $W_q/W_k/W_v$，各自算一遍注意力，最后拼回来。**

以 LLaMA-2 7B 为例：

```text
d_model = 4096,  头数 h = 32,  每头维度 d_k = 4096 / 32 = 128

每个头:  X(n×4096) → Q_i,K_i,V_i 各 (n×128) → 注意力 → 输出 (n×128)
32 个头: 输出拼接 → n × (32×128) = n × 4096   ← 形状回到原样
最后:    再乘一个 W_o (4096×4096) 把 32 份混合起来 → n × 4096
```

三个容易问的点：

**① 多头是不是变贵了 32 倍？** 不是。总计算量几乎不变——单头要做 $4096$ 维的点积，多头是 32 次 $128$ 维的点积，$32\times128=4096$。**切的是同一块蛋糕，不是多买了 32 块。**

**② W_o 是干什么的？** 32 个头各干各的，拼起来只是把 32 段数字并排放着，彼此还没交流过。$W_o$ 是唯一一次让各头的结论互相混合的机会。少了它，多头就只是 32 个互不通气的小注意力。

**③ 每个头关注什么是人指定的吗？** 不是。$W_q/W_k/W_v$ 全部随机初始化、由梯度下降自己学。可解释性研究事后发现有的头确实专门追踪指代、有的追踪句法依存，但那是训练涌现的结果，没人写过一行规则。

> 单头 vs 多头，一句话：单头是让全班用同一个标准评一次分；多头是分 32 个小组，各按各的标准评一次，最后汇总。总工作量一样，得到的信息维度多得多。

## 8. 位置编码

注意力的盲点：$QK^\top$ 只算词与词的匹配度，**完全不管谁在前谁在后**。把句子里的词顺序打乱，算出来的权重表只是行列换了位置，内容一模一样——「狗咬人」和「人咬狗」在纯注意力眼里没有区别。

RNN 不需要位置编码，因为它本来就是按顺序逐个读的；Transformer 把顺序性一起扔掉了，必须补回来。

**基本解法**：给每个位置的向量**加上一个代表位置的向量**。

```text
进注意力的 X = embedding 查表结果 + 位置向量
第 0 个位置加 pos₀,第 1 个位置加 pos₁,……
词向量里就掺进了「我在第几个」这个信息
```

三代做法的演进：

| 做法 | 怎么产生位置向量 | 用在哪 |
|---|---|---|
| 正弦位置编码 | 用不同频率的 sin/cos 直接算出来，无参数 | 原始 Transformer 论文 |
| 可学习位置嵌入 | 当成一张 `最大长度 × d` 的表，训练学出来 | BERT、GPT-2 |
| **RoPE（旋转位置编码）** | 不做加法，而是按位置把 Q、K 向量**旋转**一个角度 | LLaMA、Qwen、DeepSeek 等当代主流 |

RoPE 之所以取代前两者，关键在于旋转后两个向量的点积只依赖**它们的相对距离**，不依赖绝对位置。这让模型天然懂「隔了 3 个词」这种关系，也让外推到比训练时更长的上下文成为可能——今天动辄 128K 的上下文窗口，很大程度上靠的是 RoPE 及其各种插值改造。

## 9. 前馈网络、残差连接、层归一化

### 前馈网络（FFN）

就是 [[神经网络]] 里的普通全连接层，没有任何新东西。分工很清楚：**注意力负责在词与词之间搬运信息，前馈网络负责对每个词单独做加工**——它逐位置独立运算，不同位置之间在这一步毫无交流。

结构是「先升维、再降维」：

```text
LLaMA-2 7B:  4096 → 11008 → 4096
             升维 2.7 倍,在高维空间里过一次非线性,再压回来
```

参数量上，FFN 其实是大头：LLaMA-2 7B 里注意力约 21.5 亿参数，前馈约 43.3 亿——**前馈是注意力的两倍**（明细见 [[AI/Map|AI 知识地图]] 第 1.3 节）。一个常见的误解是"Transformer 主要靠注意力"，从参数量看恰恰相反。

现代模型的 FFN 多用 SwiGLU，即三个矩阵（gate/up/down）而不是两个，这也是 7B 模型里 $11008$ 这个看着奇怪的数字的由来。

### 残差连接

一行式子：$\text{输出} = x + F(x)$。

给数据修一条**直通旁路**——就算这一层什么都没学会（$F(x)\approx0$），输入至少原样传下去，不会被搞坏。反向传播时梯度也能沿旁路直达底层，这是深层网络能训得动的关键。**没有残差连接，32 层的模型根本收敛不了。**

### 层归一化

数据穿过一层又一层，数值容易越滚越大或越缩越小。层归一化在每个位置上，把该位置的 4096 个数**重新缩放到均值 0、方差 1 附近**，再乘一个可学习的缩放向量。

注意它归一化的方向：**是同一个 token 的 4096 个维度之间**，不是不同 token 之间。这正是它叫 Layer Norm 而不是 Batch Norm 的原因——它不需要看 batch 里的其他样本，所以推理时一次只处理一句话也照常工作。

现代模型（LLaMA 系）用的是简化版 RMSNorm：只除以均方根，不减均值，效果相当而更快。

## 10. 一层 Transformer 的完整流水线

```text
输入 X （n × 4096,来自上一层或 embedding+位置编码）
  │
  ├─────────────────────────────┐  ← 残差旁路,原样存着
  ↓                             │
层归一化                         │
  ↓                             │
多头自注意力                     │   ← 词与词之间搬运信息
  （W_q W_k W_v W_o,4 个矩阵）   │      这是唯一一处位置之间有交流的地方
  ↓                             │
  +  ←──────────────────────────┘  ← 残差相加
  │
  ├─────────────────────────────┐
  ↓                             │
层归一化                         │
  ↓                             │
前馈网络                         │   ← 每个位置单独加工
  （W_gate W_up W_down,3 个矩阵）│      位置之间零交流
  ↓                             │
  +  ←──────────────────────────┘
  │
  ↓
输出 （n × 4096,形状和输入完全一样）
```

**形状不变是关键设计**：进去 $n\times4096$，出来还是 $n\times4096$，所以同样的积木可以无脑往上叠。LLaMA-2 7B 叠 32 层，GPT-3 叠 96 层。

一层用 7 个大矩阵（注意力 4 个 + 前馈 3 个），32 层就是 224 个，加上首尾的 embedding 表和输出头共 226 个——完整清单和参数量核算见 [[AI/Map|AI 知识地图]] 第 1.2 节。

进模型之前的部分（文字 → token → 向量）见 [[Token 与 Embedding 表]]。

## 11. Attention Is All You Need：并行才是真正的胜因

流行说法是「Transformer 赢在能处理长距离依赖」。这是对的，但不是主要原因——**主要原因是它能并行**。

### RNN 的死结

```text
RNN:  h₁ = f(x₁, h₀)
      h₂ = f(x₂, h₁)   ← 必须等 h₁ 算完
      h₃ = f(x₃, h₂)   ← 必须等 h₂ 算完
      ...
      1000 个词 = 1000 步串行,前后咬死
```

GPU 有上万个计算核心，但 RNN 每一步只能喂给它一个词的运算量。**硬件在等软件**，卡的不是算力，是依赖链。

### 注意力没有这个依赖

```text
注意力:  Q = X @ W_q     ← 1000 个词一次矩阵乘法全算完
        S = Q @ Kᵀ      ← 1000×1000 的分数一次算完
        ...
        整句话的深度只有常数步,和句子多长无关
```

矩阵乘法是 GPU 最擅长的事。**Transformer 把序列建模改写成了一连串大矩阵乘法**，这才是它能在同样的钱和时间里训出百倍大模型的原因。规模上去之后，能力才涌现出来。

### 代价：$O(n^2)$

天下没有白拿的并行。分数矩阵 $S$ 是 $n\times n$：

| 序列长度 | 分数矩阵元素数 | 相对 1K 的倍数 |
|---:|---:|---:|
| 1,000 | 100 万 | 1× |
| 10,000 | 1 亿 | 100× |
| 100,000 | 100 亿 | 10000× |

RNN 是 $O(n)$，Transformer 是 $O(n^2)$。**长上下文贵，贵在这里。** 这也是 FlashAttention、稀疏注意力、滑动窗口注意力、线性注意力这一整个研究方向存在的理由。

一句话总结这笔交易：**用平方的计算量，换掉了串行的依赖链。** 在 GPU 时代，这笔买卖极其划算。

## 12. 自注意力 vs 交叉注意力

同一个注意力公式，看 Q 和 K/V 从哪来，就分成两种：

| | 自注意力 Self-Attention | 交叉注意力 Cross-Attention |
|---|---|---|
| Q 来自 | 序列 A | 序列 A |
| K、V 来自 | **序列 A（同一个）** | **序列 B（另一个）** |
| 干什么 | 一句话内部各词互相理解 | 让 A 去查阅 B 的内容 |
| 典型场景 | GPT/BERT 的每一层 | 翻译时英文侧查阅中文侧；文生图时图像侧查阅文本侧 |

```text
自注意力:   Q = X_A @ W_q     K = X_A @ W_k     V = X_A @ W_v
交叉注意力: Q = X_A @ W_q     K = X_B @ W_k     V = X_B @ W_v
                  ↑ 只有这一处不同
```

decoder-only 的 GPT/LLaMA **只有自注意力**，没有交叉注意力——因为它压根没有第二个序列，提示词和生成的内容拼在同一条序列里。交叉注意力今天主要活在编码器-解码器模型和多模态模型里（Stable Diffusion 的 U-Net 就是靠交叉注意力把文本条件注入图像的）。

## 13. 编码器-解码器

原始论文的结构，为机器翻译设计：

```text
编码器：把整句中文通读一遍（自注意力,无掩码,全员互看）→ 一组理解向量
解码器：根据这组向量逐词写出英文
         每写一个词:
           ① 自注意力（带因果掩码）：回看自己已写的部分
           ② 交叉注意力：Q 来自英文侧,K/V 来自编码器的输出
           ③ 前馈网络
```

编码器和解码器的差别只有两处：解码器多一层交叉注意力，且自注意力带因果掩码。**积木完全一样，只是搭法不同。**

## 14. 三大流派：BERT / GPT / T5

都用同一套积木，区别在保留哪部分结构 + 用什么方式训练：

| | BERT | GPT | T5 |
|---|---|---|---|
| 全称 | Bidirectional Encoder Representations from Transformers | Generative Pre-trained Transformer | Text-to-Text Transfer Transformer |
| 出品 | Google 2018 | OpenAI 2018 起 | Google 2019 |
| 保留结构 | 只有编码器 | 只有解码器 | 编码器 + 解码器 |
| 因果掩码 | 无（前后文都能看） | 有（只能看前文） | 编码器无、解码器有 |
| 训练方式 | 完形填空（挖词） | 词语接龙（猜下一个词） | 指令式文本进文本出 |
| 天赋 | 读得懂，不会写 | 又读又写 | 先读懂再输出 |
| 今天的地位 | 活在幕后 | 绝对主流 | 相对小众 |

**历史走向**：GPT 路线赢了。原因不是它结构更聪明，而是「猜下一个词」这个训练目标**不需要任何人工标注**——整个互联网都是现成的训练数据（自监督，见 [[大语言模型]] 第 4 节）。BERT 的完形填空也自监督，但它天生不会生成；T5 要成对的输入输出，规模上不去。**最容易堆规模的那条路赢了。** ChatGPT、Claude、LLaMA、DeepSeek 全是 decoder-only。

**BERT 没有死**：它退居幕后成了 embedding 模型的祖先。RAG 系统里负责"检索"的那半边（[[Embedding Service]]、[[Vector Database]]）血统基本是 BERT，负责"生成回答"的那半边才是 GPT——做 [[RAG]] 等于同时在用两个流派。

## 15. 优缺点

| 优点 | 缺点 |
|------|------|
| 任意距离的依赖一步直达（RNN 要传 $n$ 步） | 计算与显存随序列长度平方增长 |
| 整句并行，训练快，能堆超大规模 | 长文本推理时 KV 缓存吃显存 |
| 同一套积木通吃文本/图像/语音/视频 | 天生不懂顺序，必须外挂位置编码 |
| 每层的中间结果形状不变，可无脑叠层 | 参数量巨大，小数据上极易过拟合 |
