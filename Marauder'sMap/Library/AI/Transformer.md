# Transformer

> 完全靠注意力机制处理序列的神经网络架构，GPT、BERT、Claude 等一切大模型的地基

## TL;DR

- **出身**：2017 年 Google 论文《Attention Is All You Need》
- **核心创新**：抛弃 RNN 的逐步处理，整句话同时进网络 → 可并行训练、任意距离的依赖一步直达
- **自注意力**：句子里每个词同时扮演 Q（搜索词）、K（标签）、V（内容），全员互搜一轮
- **一层 = 多头自注意力（到处打听）+ 前馈网络（关门消化）**，残差连接 + 层归一化保证几十层还训得动
- **三大流派**：BERT（只编码器，完形填空）、GPT（只解码器，词语接龙，当今绝对主流）、T5（完整编码-解码）
- 前置知识：[[向量与点积]]、[[序列模型]]、[[神经网络]]

---

## 1. 解决什么问题

RNN 的两大痛点（来龙去脉见 [[序列模型]]）：

| 痛点 | 原因 |
|------|------|
| 长距离信息丢失 | 记忆逐步传递，传远了就淡了（梯度消失） |
| 无法并行 | 必须算完第 1 个词才能算第 2 个，GPU 干等 |

Transformer 的答案：**去掉逐步传递，让每个词直接和句中所有词建立联系**。整句话同时计算，训练速度和依赖距离两个问题一起解决。代价是计算量随序列长度平方增长。

## 2. 自注意力（Self-Attention）：QKV

### 搜索引擎类比

在搜索框输入"附近的火锅店"：

```text
Query（查询）= 你的搜索词："附近的火锅店"     ← 我想找什么
Key（键）   = 每个网页的标题                 ← 我是干什么的（用来被匹配）
Value（值） = 每个网页的正文                 ← 我实际装着什么（匹配后拿走的）
```

注意 K 和 V 的分工：**匹配的是标题，拿走的是正文**。

### 四步计算

```text
① 算匹配分（点积，见 [[向量与点积]]）
     Q · K(海底捞门店)   = 8    ← 火锅找火锅，非常匹配
     Q · K(川菜馆推荐)   = 4    ← 都是吃的，沾点边
     Q · K(Python教程)  = -2   ← 毫不相干

② softmax 把分数压成加起来等于 1 的百分比
     [8, 4, -2] → [0.87, 0.12, 0.01]

③ 按百分比把所有 Value 混合（加权求和）
     结果 = 0.87×V(海底捞) + 0.12×V(川菜馆) + 0.01×V(Python)
```

和真实搜索引擎的唯一区别：搜索引擎只返回第一名，**注意力是把所有结果按匹配度混合成一份**。

### 公式整句翻译

$$Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$

```text
QKᵀ       拿 Q 和所有 K 做点积，算匹配分
÷√dₖ      防止向量太长时分数爆炸、softmax 过于极端（调低音量）
softmax   分数 → 百分比权重
·V        按权重把所有 V 加权求和
```

整个注意力 = 一次查表 + 一次加权平均，没有更多了。

### 回到句子：每个词都是一个搜索框

"自"注意力的意思：Q、K、V 全部来自**同一个句子**，每个词同时身兼三职——发出搜索词（Q）、挂出标题（K）、备好内容（V）。三者都是词向量分别乘三个权重矩阵 W_Q、W_K、W_V 变换出来的（矩阵是训练学出来的参数，见 [[大模型如何训练]]）。

```text
"The animal didn't cross the street because it was too tired"

轮到 "it" 开搜索框：
  Q(it) ≈ "我是代词，我指代谁？"
  和每个词的 Key 算分，softmax 后：
     animal: 0.75   street: 0.15   cross: 0.04  ...
  it 的新表示 = 0.75×V(animal) + 0.15×V(street) + ...
  → "it" 的向量里被大量注入 animal 的信息，模型知道 it = 那只动物
```

句子里每个词都做一遍这个搜索，全员互搜一轮 = 一层自注意力。

## 3. 多头注意力（Multi-Head Attention）

一组 Q/K/V 只能学到一种"关注模式"。多头 = **同一句话派 8 个人（8 组独立的 W_Q/W_K/W_V）各看一遍**，每人关注点不同：有的头盯"代词指谁"，有的盯"动词的宾语"，有的盯"哪些词是一个短语"，最后把 8 份读后感拼接起来。

> 类比：同一份合同，律师、会计、工程师各画各的重点，汇总后理解最全面。

---

## 4. 位置编码（Positional Encoding）

注意力的盲点：它只算词与词的匹配度，**完全不管先后顺序**——"狗咬人"和"人咬狗"在它眼里一样。

解法简单粗暴：给每个词的向量**加上一个代表座位号的向量**。第 1 个位置加"1 号座"编码，第 2 个位置加"2 号座"编码，词向量里就掺进了位置信息。

## 5. 前馈网络、残差连接、层归一化

### 前馈网络（Feed-Forward Network）

就是 [[神经网络]] 里的普通全连接层（加权求和 + 激活函数），没有任何新东西。分工：**注意力负责到处打听、收集信息；前馈网络负责关起门来消化**。每个词各自过一遍。

### 残差连接（Residual Connection）

一行代码：`输出 = 输入 + 本层算出的东西`，即 x + F(x)。

给数据修一条**直通近道**——就算这层什么都没学会（F(x)≈0），输入至少原样传下去。梯度也能沿近道一路畅通传回去，解决了深层网络的梯度消失，网络叠几十上百层还训得动。

> 类比：编辑改稿不重写，在原稿上贴批注——原稿永远还在。

### 层归一化（Layer Normalization）

数据穿过一层又一层，数值容易越来越大或越来越小（复印件再复印，越来越失真）。层归一化**每过一层就把数值拉回标准范围**（均值 0、方差 1 附近），像流水线每道工序后重新校准仪器。和残差连接搭档保证深层训练稳定。

## 6. 一层 Transformer 的完整流水线

```text
词向量 + 位置编码（发座位号）
   ↓
多头自注意力（8 个人帮它到处打听："句子里谁和我有关？"）
   ↓  ← 残差连接（贴批注不改原稿）+ 层归一化（校准仪器）
前馈网络（关门消化打听来的信息）
   ↓  ← 残差连接 + 层归一化
…同样的积木叠 N 层（GPT-3 有 96 层）…
```

进模型之前的部分（文字 → token → 向量）见 [[Token 与 Embedding 表]]。

## 7. 编码器-解码器（Encoder-Decoder）

原始论文的结构，为机器翻译设计：

```text
编码器：先把整句中文通读一遍、完全理解（自注意力，全员互看）
解码器：根据这份理解逐词写出英文
         每写一个词：① 回看自己已写的部分（自注意力）
                    ② 回看编码器的理解（交叉注意力：Q 来自英文侧，K/V 来自中文侧）
```

交叉注意力不再是"自"注意力——查询方和被查方来自两个序列。

## 8. 三大流派：BERT / GPT / T5

都用同一套积木，区别在保留哪部分结构 + 用什么方式训练：

| | BERT | GPT | T5 |
|---|---|---|---|
| 全称 | Bidirectional Encoder Representations from Transformers | Generative Pre-trained Transformer | Text-to-Text Transfer Transformer |
| 出品 | Google 2018 | OpenAI 2018 起 | Google 2019 |
| 保留结构 | 只有编码器 | 只有解码器 | 编码器 + 解码器 |
| 训练方式 | 完形填空（挖词，前后文都能看） | 词语接龙（只看前文猜下一个词） | 指令式文本进文本出 |
| 天赋 | 读得懂，不会写 | 又读又写 | 先读懂再输出 |
| 今天的地位 | 活在幕后 | 绝对主流 | 相对小众 |

**历史走向**：GPT 路线赢了——"接龙"训练最简单、最容易堆规模，规模一大理解/翻译/推理全面涌现。ChatGPT、Claude、LLaMA、DeepSeek 全是 decoder-only。

**BERT 没有死**：它退居幕后成了 embedding 模型的祖先。RAG 系统里负责"检索"的那半边（[[Embedding Service]]、[[Vector Database]]）血统基本是 BERT，负责"生成回答"的那半边才是 GPT——做 RAG 等于同时在用两个流派。

## 9. 优缺点

| 优点 | 缺点 |
|------|------|
| 任意距离的依赖一步直达 | 计算量随序列长度平方增长 |
| 整句并行，训练快，能堆超大规模 | 内存占用大，长文本是痛点 |
| 同一套积木通吃文本/图像/语音 | 天生不懂顺序，需要位置编码补丁 |
