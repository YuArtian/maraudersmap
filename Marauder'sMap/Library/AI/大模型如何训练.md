# 大模型如何训练：猜下一个词

> 亿万个参数从随机数到智能：自动生成的填空题库 + 打分 + 亿万次微调

> [!note] 定位
> **这篇讲**：几十亿个参数怎么从随机数变成语言能力——训练题目从哪来（语料自己就是题库）、模型怎么「猜」、怎么打分、参数怎么被挪动。是 [[神经网络的训练过程]] 那套循环在语言模型上的具体展开。
> **这篇不讲**：前向 / 损失 / 反向 / 更新四个环节各自在干什么（去 [[神经网络的训练过程]]）；求导与梯度（去 [[导数、偏导与链式法则]]）；预训练之后的 SFT 与 RLHF（去 [[大语言模型]] 第 6 节）；只重训一部分参数（去 [[微调与 LoRA]]）。
> **前置**：[[机器学习基础概念]]、[[神经网络的训练过程]]。

## TL;DR

把海量文本自动切成"给前文、猜下一个 token"的题目，模型每次输出一张覆盖整个词表的概率分布，用正确答案分到的概率算出损失，再靠反向传播让亿万个参数各朝减小损失的方向挪一小步——这个循环重复上亿次，参数就从随机数变成了语言能力，也就是 [[机器学习基础概念]] 里"学习 = 调整所有权重让损失函数最小"在语言上的具体展开。

---

## 1. 题库自造：文本本身就是题

"猜下一个词"最妙的地方是**不需要人出题**：

```text
原文: "我 今天 去 超市 买了 菜"

题1: "我"             → 猜: 今天
题2: "我 今天"         → 猜: 去
题3: "我 今天 去"      → 猜: 超市
题4: "我 今天 去 超市"  → 猜: 买了
...
```

一句话出好几道题，每道题自带标准答案。这就是大模型能"吃"下万亿级数据的原因——没有人工标注的瓶颈。

---

## 2. "猜"是怎么猜的：一张概率表

模型不是吐出一个词，而是**对词表里全部几万个 token 各打一个分**，再用 softmax（把一组任意大小的分数按指数比例归一化，使它们加起来等于 1）压成概率：

```text
做题 "我 今天 去 →？"

模型输出:
  超市: 21%   学校: 15%   公司: 12%   医院: 6%   ...
  火锅: 0.3%  ...  函数: 0.001%  ...
```

这张表是整条流水线算出来的：查 embedding 表 → 注意力层 → 前馈层 → … → 输出打分（见 [[Transformer]]、[[Token 与 Embedding 表]]）。

流水线里所有数字——embedding 表、W_Q/W_K/W_V、前馈层权重——统称**参数**。所谓 7B、70B 模型，就是 70 亿、700 亿个这样的数字。

---

## 3. 打分：损失函数

看**正确答案分到了多少概率**。标准答案"超市"拿了 21%——不算差但不完美（理想 100%）。损失函数把它换算成罚分——这里用的是交叉熵，即取正确答案那个概率的负对数：概率越接近 1 罚分越接近 0，概率越小罚分越大（趋于无穷）。

训练前参数全是随机数，正确答案只能分到几万分之一的概率，损失巨大。

---

## 4. 改进：700 亿个参数，每个都问同一个问题

每做完一道题，对**每一个参数**问同一句话：

> 「把你调大一点点，罚分会变大还是变小？变多少？」

这个「变多少」就是该参数的**偏导数**；全部参数的偏导数排成一个向量，叫**梯度**（读法与算法见 [[导数、偏导与链式法则]]）。**反向传播**能一次性把 700 亿个答案全部算出来，代价只相当于两次前向计算。

拿到答案后，每个参数朝罚分变小的方向挪一小步：

$$w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$$

这就是**梯度下降**。$\eta$ 是**学习率**，控制每步迈多大，是这里唯一需要人来定的旋钮。

> 蒙眼下山：看不见全景，但脚能感觉到坡度（梯度），每次朝下坡方向迈一小步，迈几万亿步就走到了很低的地方。

```text
一次训练步骤的完整循环:

  出题 "我 今天 去 →?"
    → 模型猜（前向计算，得概率表）
    → 对答案算损失（"超市"只有 21%，罚分）
    → 反向传播（算出每个参数该往哪调、调多少）
    → 所有参数各挪一小步
    → 下一道题，重复亿万次
```

四个环节各自在干什么、为什么反向传播能这么快，见 [[神经网络的训练过程]]。

---

## 5. 副产品：意思相近的词，向量被逼得相近

没有任何代码规定这一点，它是**被逼出来的**："猫"和"狗"出现的语境高度相似（"我家的__很可爱"、"带__去打疫苗"），模型要在相同语境里都猜得准，最省力的方案就是把两者的向量调得很像。亿万道题下来，语境相似的词被推到向量空间的同一片区域——embedding 表里数字的"含义"就是这么长出来的。

---

## 6. 训练和使用的关系

GPT 生成文字 = 把训练时做的事原样重放：猜一个词 → 写下来 → 拼回输入 → 再猜下一个。训练任务和使用方式完全同构，这是 GPT 流派（见 [[Transformer]] 三大流派）能靠堆规模取胜的原因之一。

> 注：以上是**预训练**（pre-training）。实际产品还有后续阶段（指令微调、人类反馈强化学习等），让模型从"会接龙"变成"会对话、听指挥"。**关键是这些阶段用的还是本文这一套动作**（猜下一个词 + 梯度下降），只是换了喂进去的数据——具体在动哪批参数、LoRA 怎么只训 0.1% 就够，见 [[微调与 LoRA]]。
