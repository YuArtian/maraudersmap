## TL;DR

**素材源：《Agents 底层逻辑》（袁进），共 34 章。** 每章一个 `课件.md`（Jupyter Notebook 风格）加示例代码，部分章节带 xmind 与配图。

这门课与本库 Library/AI 现有笔记（主要出自《动手学深度学习》第一章与自行整理）的关系：

- **前半程（01-14 神经元 → 训练阶段）重叠度高**，价值在补细节与补视角，整理方式以**并入已有文章**为主
- **后半程（15-34 Ollama → Graph Engineering）是本库空白**：本地部署、Tool Calling、ReAct、Agent、Skill、MCP、子代理、五种 Engineering，Library/AI 现有 16 篇一篇都没覆盖，**整理方式以新建为主**

**本批次相对课件的增补**（课件未提及、整理时补上的）：

- 三个哲学流派**今天共存**的结构——课件只列三派主张，未说它们在一个现代大模型系统里分别对应主干（连接主义）、后训练（行为主义）、工具调用与知识检索（符号主义）；这一点直接解释了后半程课程里 Agent 为什么要接工具
- 符号主义撞上的「知识获取瓶颈」与第二次 AI 寒冬；连接主义 1943 → 1958 → 1986 → 2012 → 2017 的时间轴
- 演化计算**为什么在神经网络场景被梯度下降取代**（梯度给方向，随机搜索只能试探），以及它今天还剩什么地盘（不可导、离散的优化问题）
- 大模型把大量 NLP 子任务收敛成「换提示词」，以及语音与视觉的收敛程度低于文本
- T/E/P 定义中 **P 常常不等于损失函数**（P 是业务指标，损失是可导的替代目标），与本库已有的「替代目标」一节呼应
- 自监督**形式上仍属监督**、差别只在标签来源，以及三个训练阶段（预训练 / 指令微调 / 偏好对齐）恰好对应三种学习方式
- 岗位表的星级是课程给出的国内市场判断，已在正文标注为非普适结论；并补了「应用开发难度低是相对的，不等于不用懂原理」的澄清

**课件强于本库、已吸收的表述**：单个神经元「吃一个向量、吐一个标量」的说法比本库原有的散述更利落；「激活函数是固定的，参数唯一决定该神经元的输出是否正确」一句把超参数与参数的分界点得很准。

**本批次顺带改写**（不属于 04-06 章，但同一话题下一并做掉）：[[神经网络]] 第 3、4 节整体重写。原文讲激活函数只有「叠多层等价于一层」这一段代数论证，抽象且没有可验算的例子，读完仍不知道它具体在干什么。改为：三神经元数值例子（有 ReLU 得到三角形 / 去掉后输出恒等于 0）→ 折点公式 $x = -b/w$ → 「开关」与「折线」是同一件事的区间对照表 → $n$ 个 ReLU 最多切出 $2^n$ 段直线（万能逼近的机制）→ 为什么默认 ReLU 而不是 Sigmoid（梯度消失）。原代数论证保留，但降为佐证而非主线。

**本批次淘汰**：05 章的 `2d梯度下降.gcx`、`3d梯度下降.gcx`（GeoGebra 交互演示文件，无法转写为文字）；06 章的 MNIST 手写数字配图（外链图片，纯示意）。

**本批次相对课件的增补**：

- **四个词的类别分界**（计算过程 / 打分函数 / 求导算法 / 更新规则）与「**反向传播 ≠ 梯度下降**」——这是整理的起点，课件 05 章只给了梯度下降与学习率的定义，「反向传播」四个字在三章课件里一次都没出现过
- 反向传播存在的理由：笨办法要为每个参数各跑一次前向（70 亿参数 = 一步训练跑 70 亿次前向），链式法则复用把代价压到约两次前向
- 训练时必须缓存每层中间结果 → 训练比推理吃显存的直接原因
- 损失为什么必须压缩成一个标量（否则「下山」没有定义）
- **推理阶段只走前向**，及其三个推论：训练贵推理便宜、模型不会从聊天里学到东西、微调必须重跑完整循环
- 术语提醒：现在文献与代码里的 "SGD" 几乎都指 mini-batch 版本，严格的「每步 1 条样本」已无人使用
- Momentum / Adam / AdamW 是梯度下降的**改良而非替代**
- 权重矩阵尺寸 $n \times m$ 的自洽性（行数 = 本层神经元数、列数 = 上一层神经元数），可用来反推任意网络各矩阵的大小
- 框架一节补了 JAX，并把 TensorFlow 的现状写成「已退出主流训练场景，留在部署与边缘计算」

**课件强于本库、已吸收的**：$a^{(l)}_j$ 的层/神经元编号记号与总参数量公式——本库此前只有具体数字的演算，没有通用式，读论文时接不上。

**批次 2 补充（同日）**：新建 [[导数、偏导与链式法则]]，挂进数学地基分支成为 Index 的 ④。

起因是整理完 [[神经网络的训练过程]] 后发现一个断层：第 5 节直接使用了「链式法则」「梯度」「偏导数」，而数学地基原有三篇（[[向量与点积]]、[[线性代数入门]]、[[矩阵与线性变换]]）全部服务前向传播，**没有一篇讲变化率**。这一篇补的就是这个缺口——导数读作「灵敏度」、四条求导公式、ReLU 的导数与 dead ReLU、偏导、梯度、链式法则、梯度消失与爆炸，全篇每条结论都附「加 0.001 硬算一遍」的验算，文末六道自测题带答案。

同时把 [[神经网络的训练过程]] 第 5 节从「说明反向传播为什么快」扩写为**一次可手算完的完整演算**（两个权重的最小网络：前向得 L=196 → 四步回推得两个梯度 → 硬算验证 ∂L/∂w₁=224 → 梯度下降一步把 L 降到 127），并抽出「每层只做两件事」的算法模板。

**数学地基四篇的分工现在是**：①②③ 服务前向传播（向量、线性、矩阵乘法），④ 服务反向传播（导数、梯度、链式法则）。

**目录调整（同日）**：四篇数学笔记已从 `Library/AI/` 迁往新建的 `Library/数学地基/`，该目录有自己的索引页 [[数学地基/Index|数学地基索引]]（含分工图、概念速查、缺口清单）。原因是它们不属于 AI 本身，而 AI/ 目录本身也在因这门课持续变厚。全库对这四篇的引用都是无路径的 `[[名称]]` 形式，按文件名解析，迁移后一处未断；[[AI/Index|AI 知识索引]] 继续把它们挂在知识树上，编号 ①~④ 不变，只是标注了所在目录。

**仍未填的数学缺口**：概率与对数。[[机器学习基础概念]] 第 5 节已经在用交叉熵、softmax、极大似然、log，但全库没有一篇讲这些的地基。位置应排在 ④ 之后，等遇到卡点时再补。
