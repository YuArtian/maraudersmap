# 线性代数入门

> 什么是线性函数，怎么判断，以及矩阵为什么长成那个样子——读《矩阵与线性变换》之前先读这篇

## TL;DR

- **线性函数**：满足**可加性** $f(u+v)=f(u)+f(v)$ 与**齐次性** $f(ku)=k f(u)$ 的函数；一句话是**先组合再变换 = 先变换再组合**
- **加了常数项就不是线性**，叫**仿射**（affine）；$Wx+b$ 是仿射不是线性
- **判定捷径**：先看 $f(0)$ 是否为 0（不为 0 直接出局），再看每个输出是否为"变量×常数相加"的齐次一次式
- **证否只需一个反例，证是必须对所有输入成立**——试几组数字对上不算证明
- **核心事实**：线性函数被它在**基向量**上的取值完全决定，$n$ 维只需记 $n$ 个输出向量
- **矩阵就是这批输出向量排成的表**：第 j 列 = 第 j 个基向量的去处。矩阵乘法规则是由此**推出来**的，不是规定的
- **多进多出的函数**：输出是一组数，每个分量各有一条计算规则；每个分量都是输入的加权求和 = 一个神经元
- **神经网络** = 线性变换 → 掰弯 → 线性变换 → 掰弯 …… 的交替堆叠

## 1. 三个最基本的词

**标量**（scalar）：一个普通的数，如 3、−1.5。

**向量**（vector）：一次装好几个数，如 (3, 4)。装 n 个数就叫 n 维。它可以代表任何"需要多个数才说得清"的东西：一个点的位置、一个学生的(复习时长, 睡眠时长)、一张图片的全部像素。详见 [[向量与点积]]。

**函数**（function）：一条输入输出规则。$f(x)=3x$ 的意思是"给我一个数，我还你三倍"。就是一台机器：进去什么，出来什么。

## 2. 什么是线性函数

### 两条性质

先看最简单的 $f(x)=3x$：

```text
性质一（可加性）：分开算再相加 = 合起来算
    f(2) + f(5) = 6 + 15 = 21
    f(2 + 5)    = f(7)   = 21        ← 相同

性质二（齐次性）：先放大再算 = 先算再放大
    f(10 × 2) = f(20)   = 60
    10 × f(2) = 10 × 6  = 60         ← 相同
```

**满足这两条的函数就叫线性函数**（也叫线性变换、线性映射）：

$$f(u + v) = f(u) + f(v) \qquad\qquad f(k u) = k\, f(u)$$

通俗含义：这台机器不会额外制造或损耗东西，输入翻倍输出就翻倍，拆开算再合并与直接算是一回事。**一句话概括：先组合再变换 = 先变换再组合。**

### 反例才能看清边界

```text
g(x) = x²      g(1+1) = g(2) = 4
               g(1) + g(1)   = 1 + 1 = 2      ← 不相等，不是线性

h(x) = 3x + 2  h(1+1) = h(2) = 8
               h(1) + h(1)   = 5 + 5 = 10     ← 不相等，不是线性
```

第二个例子要特别注意：$h(x)=3x+2$ 画出来明明是一条直线，却**不是**线性函数，**因为那个 +2 让它不过原点**。这种"线性函数 + 常数"有专门的名字，叫**仿射函数**（affine）。这个区别在第 8 节会派上大用场。

### 为什么叫"线性"

一维的 $f(x)=kx$ 画出来是**过原点的直线**，名字由此而来。推广到高维后它保持三件事：直线仍是直线、原点仍是原点、平行线仍平行。它可以旋转、拉伸、压扁整个空间，但不会把空间弄弯。

## 3. 怎么判断一个函数是不是线性

不必每次都逐条验证两条性质，实操上有更快的办法。

### 两条可以合并成一条

$$f(a u + b v) = a f(u) + b f(v)$$

与原来两条**完全等价**（取 $a=b=1$ 得可加性，取 $b=0$ 得齐次性）。推广形式见第 4 节的求和记号版本。

### 最快的筛子：先看 $f(0)$

线性函数必然满足 $f(0)=0$，证明只要一行：

$$f(0) = f(0 \cdot v) = 0 \cdot f(v) = 0$$

所以**只要 $f(0) \neq 0$，立刻判定不是线性**。$h(x)=3x+2$ 里 $h(0)=2$，一眼出局；$Wx+b$ 只要 $b \neq 0$ 同理出局。

注意方向：这是**必要条件，不是充分条件**。$g(x)=x^2$ 满足 $g(0)=0$ 却不线性。此筛子只能否决，不能肯定。

### 最实用的：看式子的形状

**$f$ 线性 ⟺ 每个输出分量都是各输入变量的齐次一次式**——只允许"变量 × 常数"然后相加，不许有别的任何东西。

```text
是线性的：
   2x + 3y          ← 变量各乘常数再相加
   x                ← 系数为 1
   0                ← 系数全为 0，零函数也是线性的
   0.5x − 7y + 2z

不是线性的：
   2x + 1           ← 有常数项（仿射）
   x²               ← 变量的幂
   xy               ← 两个变量相乘
   sin x, eˣ, √x    ← 非线性函数
   |x|              ← 绝对值
   max(0, x)        ← 也就是 ReLU
```

口诀：**变量只能出现一次，前面只能挂常数，末尾不能有常数项。**

### 等价说法：能否写成矩阵乘法

$$f \text{ 线性} \iff \text{存在矩阵 } M \text{ 使 } f(x) = Mx$$

写得出来就是线性，凑不出常数矩阵就不是。

### 方法论：证否与证是不对称

**要说明"不是"线性，找到一个反例就够了**；**要说明"是"线性，必须对所有输入成立**，试几组数字凑巧对上不能作为依据。正向证明要么代一般式做代数推导，要么用上面的形式判据。

### 两条性质互相独立（进阶，了解即可）

满足其一推不出另一。

**齐次但不可加**：$f(x,y) = \dfrac{x^3}{x^2+y^2}$（原点处取 0）

```text
齐次 ✓：f(2,0) = 2 = 2×f(1,0)      f(2,2) = 1 = 2×f(1,1)
可加 ✗：f(1,0) + f(0,1) = 1 + 0 = 1，但 f(1,1) = 0.5
```

**可加但不齐次**：复数取共轭 $f(z)=\bar z$。共轭显然可加，但取 $k=i$：$\overline{iz} = -i\bar z$，而 $i\bar z$ 是它的相反数，不相等。

### 顺带看 ReLU

```text
可加 ✗：ReLU(−3+5) = 2，但 ReLU(−3) + ReLU(5) = 0 + 5 = 5
齐次 ✗：k = −1 时 ReLU(−1×5) = 0，但 −1 × ReLU(5) = −5
        不过 k = 3 时 ReLU(3×5) = 15 = 3 × ReLU(5)   ← 正数倍成立
```

ReLU 只在正数倍下满足齐次性，数学上叫**正齐次**。两条都不完全满足，确实是非线性函数——这正是它能让深度不坍缩的原因（第 8 节）。

## 4. 数学记号扫盲

### 求和符号 $\sum$

$\sum$ 是希腊字母大写 sigma，对应拉丁字母 S，取 Sum 的首字母。**意思就是"把后面的东西按编号一个个加起来"。**

```text
        n           ← 终点：数到几为止
       ___
       ╲
       ╱   aᵢ       ← 通项：每一项长什么样
       ‾‾‾
       i = 1        ← 起点：从几开始数，i 是计数器的名字
```

$$\sum_{i=1}^{n} a_i = a_1 + a_2 + a_3 + \cdots + a_n$$

它和右边的写法**完全是一回事**，好处只是不用打省略号、项数可以任意。设 $a_1=5,\ a_2=3,\ a_3=8$，则 $\sum_{i=1}^{3} a_i = 5+3+8 = 16$。

**本质上就是一个 for 循环加累加器**：

```text
数学:  ∑ᵢ₌₁ⁿ aᵢ          代码:  s = 0
                                for i in range(n):
                                    s += a[i]
```

### 下标不是乘法

$a_i$ 里的小 $i$ 是**编号**。$a_1$ 读作"a 一"，$a_2$ 读作"a 二"，它们是不同的数，只是共用名字 $a$ 加不同编号，相当于代码里的数组 `a[0], a[1], ...`（数学习惯从 1 数起，代码从 0 数起）。

另外注意：$\sum_{i=1}^{n}$ 头上那个 $n$ 是"数到 n 为止"，**不是 n 次方**，这是初学最常见的误读。

| 符号 | 名字 | 含义 |
|---|---|---|
| $\sum$ | 求和符号 | 把各项**加**起来 |
| $\prod$ | 连乘符号 | 把各项**乘**起来（大写 pi） |
| $a_i$ | 下标 | 编号，第 i 个，不是乘法 |
| $a^n$ | 上标 | 通常是幂次；但 $\sum$ 头上的是终点 |
| $\in$ | 属于 | $a \in F$ 读作"a 属于集合 F" |

### 字母的分工是约定，角色的分工是必然

第 3 节那条性质写成求和形式是：

$$f\left(\sum_{i} a_i u_i\right) = \sum_{i} a_i\, f(u_i)$$

其中 $a_i$ 是标量、$u_i$ 是向量。**为什么必须一个是标量一个是向量**——这不是习惯，是被公理锁死的。向量空间只规定了两种运算（见 [[向量与点积]] 第 3 节）：

```text
向量 + 向量  →  向量        （加法）
标量 × 向量  →  向量        （数乘）
```

**没有"向量 × 向量"这一条。** 所以 $a_i u_i$ 只能是"标量乘向量"，若 $a_i$ 也是向量，这个式子在向量空间里根本没有定义。（点积不是反例：它是额外附加的内积结构，且结果是标量。）

至于为什么偏偏用字母 $a$ 和 $u$，那才是纯粹的习惯：

| 角色 | 常用字母 | 来源 |
|---|---|---|
| 标量、系数 | $a,b,c$；$k$；$\lambda$ | $ax^2+bx+c$ 的系数传统；$k$ 来自德语 Koeffizient |
| 向量 | $u,v,w$ | 字母表末尾，传统上留给未知对象 |
| 坐标、变量 | $x,y,z$ | 笛卡尔的习惯 |
| 整数下标 | $i,j,k,m,n$ | index、number 的首字母 |
| 矩阵 | 大写 $A,B,M,W$ | 大写以区别于向量 |

更可靠的判别有两道保险。**一是排版**：标量用普通斜体 $a$，向量用粗体 $\mathbf{a}$ 或加箭头 $\vec a$，矩阵用大写粗体。**二是定义句**，这才是决定性的：

> 设 $V$、$W$ 是域 $F$ 上的向量空间，$f: V \to W$ 线性。则对任意 $a_1,\dots,a_n \in F$ 与 $u_1,\dots,u_n \in V$ 有 $f\left(\sum_i a_i u_i\right) = \sum_i a_i f(u_i)$。

**读数学材料的正确习惯：遇到不认识的符号，往前找定义句，而不是猜字母含义。**

## 5. 多进多出的函数

前面的例子都是一个数进、一个数出。真实场景通常是一组数进、一组数出：

$$f(x, y) = (2x + y,\ \ x + 3y)$$

### 它其实是两个公式并排

```text
f(x, y) = ( 2x + y ,  x + 3y )
             ↑         ↑
          第1个输出   第2个输出
```

**两条独立的计算规则，共用同一份输入。** 括号只是把两个结果打包成一个向量。等价于代码里返回一个元组：

```python
def f(x, y):
    out1 = 2*x + 1*y
    out2 = 1*x + 3*y
    return (out1, out2)
```

代几个数：

```text
f(5, 2) = (2×5+2, 5+3×2) = (12, 11)
f(3, 4) = (2×3+4, 3+3×4) = (10, 15)
f(1, 0) = (2×1+0, 1+3×0) = (2, 1)
f(0, 1) = (2×0+1, 0+3×1) = (1, 3)
```

### 系数 2、1、1、3 是随便挑的

这一点容易卡住：**这些数字不是推导出来的，就是随手定的**。换成别的常数，比如 $f(x,y)=(5x-y,\ 2x+7y)$，那就是另一个线性函数，同样成立。任意四个常数都定义一个这样的函数。

这四个数就是这个函数的全部身份信息。神经网络里的权重矩阵，里面的数一开始也是随机给的，只是后来被训练调成了有用的值。

### 每个输出都是一个神经元

```text
第1个输出 = 2x + 1y   ←  用权重 (2, 1) 对输入 (x,y) 做加权求和
第2个输出 = 1x + 3y   ←  用权重 (1, 3) 对输入 (x,y) 做加权求和
```

**这正是一个神经元干的事**（见 [[神经网络]] 第 2 节）。所以这个函数就是**两个神经元并排组成的一层**，只是省略了偏置和激活函数：

```text
本例（纯线性）：  f(x,y) = (2x + y,  x + 3y)

神经网络那一层：  h₁ = ReLU(0.5x + 0.2y − 4)
                 h₂ = ReLU(0.1x + 0.5y − 3)
```

结构完全一样，后者多了常数项（偏置）和外面套的 ReLU。

## 6. 核心：线性函数"记不了多少东西"

这是整个线性代数的枢纽。

先定义两个词。**线性组合**指"几个向量各乘一个数再加起来"，如 $3(1,0)+4(0,1)$。**基向量**指各坐标轴方向的单位向量，二维里就是 $(1,0)$ 和 $(0,1)$。

任何二维向量都是这两个基向量的线性组合——这一步只是把坐标的含义写明白：

$$(x, y) = x \cdot (1, 0) + y \cdot (0, 1)$$

现在用线性的两条性质推：

$$f(x, y) = f\big(x(1,0) + y(0,1)\big) \overset{\text{可加}}{=} f\big(x(1,0)\big) + f\big(y(0,1)\big) \overset{\text{齐次}}{=} x \cdot f(1,0) + y \cdot f(0,1)$$

**结论：只要知道 $f$ 把基向量送到了哪里，就能算出它把任何向量送到哪里。**

已知 $f(1,0)=(2,1)$、$f(0,1)=(1,3)$，不用原公式直接组合验证：

```text
f(5, 2) = 5 × (2,1) + 2 × (1,3) = (10,5) + (2,6) = (12, 11)   ← 与原公式一致
f(3, 4) = 3 × (2,1) + 4 × (1,3) = (6,3) + (4,12) = (10, 15)   ← 再验一个
```

这就是"线性"的全部威力：**普通函数有无穷多个输入，必须知道它对每个输入的反应；线性函数只需记住它对 $n$ 个基向量的反应**，其余全由两条性质推出。二维记 2 个输出向量，768 维记 768 个。

## 7. 于是矩阵出现了

上面那两个输出向量 $(2,1)$ 和 $(1,3)$ 就是这个函数的全部信息。把它们**竖着排、并列放好**：

$$M = \begin{bmatrix} 2 & 1 \\ 1 & 3\end{bmatrix}$$

第一列是 $f(1,0)$，第二列是 $f(0,1)$。

**这就是矩阵：一个线性函数的完整说明书，第 j 列记录第 j 个基向量被送到了哪里。**

矩阵乘向量的规则也不再需要死记：

$$M\begin{bmatrix}5\\2\end{bmatrix} = 5 \times \begin{bmatrix}2\\1\end{bmatrix} + 2 \times \begin{bmatrix}1\\3\end{bmatrix} = \begin{bmatrix}12\\11\end{bmatrix}$$

**就是把第 6 节的推导写成记号而已**，不是人为规定的算法。（另一种等价算法是"每行与向量做点积"，结果永远一致，详见 [[矩阵与线性变换]]。）

### 看列，就能读懂矩阵在干什么

```text
⎡2  0⎤    第1列(2,0)：(1,0) → (2,0)     向右的单位步拉长成 2 倍
⎣0  2⎦    第2列(0,2)：(0,1) → (0,2)     向上的单位步也拉长成 2 倍
          → 整个空间放大 2 倍

⎡0 −1⎤    第1列(0,1)：(1,0) → (0,1)     原本朝右，现在朝上
⎣1  0⎦    第2列(−1,0)：(0,1) → (−1,0)   原本朝上，现在朝左
          → 逆时针旋转 90°。验证：(3,4) → (−4,3)

⎡1  0⎤    第1列(1,0)：(1,0) → (1,0)     不变
⎣0  0⎦    第2列(0,0)：(0,1) → (0,0)     被压没了
          → 把整个平面压扁到 x 轴。(3,4) → (3,0)
```

最后这例顺便解释了**为什么逆矩阵不总存在**：它把平面压成一条线，$(3,4)$ 和 $(3,7)$ 都变成 $(3,0)$，信息已经丢失，回不去了。

### 矩阵和向量到底什么关系

**向量是被处理的数据，矩阵是处理数据的动作。** 向量是"一组数"，矩阵是"一个线性函数"；$Mx$ 读作"把变换 M 作用在向量 x 上"。

**矩阵由向量拼成。** 每一列是一个向量（基向量的像），每一行也可看成一个向量（神经网络里就是一个神经元的权重）。

**但矩阵本身也能当向量用**，因为矩阵之间能相加、能乘常数，满足向量空间的全部公理——这就是 [[向量与点积]] 第 3 节"所有 $m\times n$ 矩阵构成一个向量空间"的含义。是向量还是矩阵取决于你把它放在什么位置看，不是固有身份。

## 8. 回到神经网络

$$h = \text{ReLU}(Wx + b)$$

$Wx$ 是**线性变换**。加上 $b$ 后不再过原点，严格说已经是**仿射变换**，不是线性的了（第 2 节 $3x+2$ 的高维版本）。

但仿射仍然不够，因为**仿射复合起来还是仿射**：

$$W_2(W_1x + b_1) + b_2 = (W_2W_1)\,x + (W_2b_1 + b_2)$$

结果还是"一个矩阵乘 x 再加一个向量"的形状——这就是"叠多少层都等价于一层"的严格说法。

**ReLU 的作用就是打破线性**（第 3 节验证过它两条都不满足）。正因为它非线性，层与层才不会坍缩，深度才有意义。

用这套语言重新描述神经网络：**它是"线性变换 → 掰弯 → 线性变换 → 掰弯 → ……"的交替堆叠。** 线性变换负责重新组合信息，非线性负责让整体不退化成一条直线。

## 9. 名词速查

| 名词 | 含义 |
|---|---|
| 标量 | 一个数 |
| 向量 | 一组数，n 个数就是 n 维 |
| 线性组合 | 几个向量各乘一个数再加起来 |
| 基向量 | 各坐标轴方向的单位向量，如 (1,0)、(0,1) |
| 基 | 一组基向量的整体；任何向量都是它们的线性组合 |
| 维数 | 基里向量的个数 |
| 张成 | 一堆向量的所有线性组合能覆盖到的范围 |
| 线性函数 | 满足可加性与齐次性的函数；别名线性变换、线性映射 |
| 仿射函数 | 线性函数 + 一个常数（不过原点），如 $Wx+b$ |
| 正齐次 | 只在正数倍下满足齐次性，如 ReLU |
| 矩阵 | 一个线性函数的说明书，第 j 列 = 第 j 个基向量的去处 |
| 线性代数 | 研究向量空间与其间线性函数的学科 |
