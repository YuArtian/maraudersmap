# 向量与点积

> AI 世界的通用语言：一排数字，以及衡量两排数字"像不像"的方法

## TL;DR

- **向量 = 一排数字**，仅此而已（代码里就是数组）
- **加权求和 = 每个数乘上重要性系数再加起来**，深度学习的地基
- **点积 = 两个向量对应格子相乘再求和 = 加权求和**，结果是一个数，衡量两向量像不像
- 同一模型内**所有向量长度严格相等**；句子变长，变的是向量个数，不是长度
- 注意力（Q·K）、RAG 检索、神经元计算，底层全是这一个动作

---

## 1. 向量 = 一排数字

```text
[120, 3, 2]   ← 一个向量（长度为 3）
```

一套房子有三个特征——面积 120、卧室 3、距离 2km——排成一排就是"这套房子的向量"。AI 里一个词也被表示成一排数字（词向量，见 [[Token 与 Embedding 表]]），每个数字可粗糙理解为该词在某个特征维度上的取值。

---

## 2. 加权求和

不同因素重要程度不同，各配一个"重要性系数"（**权重**）：

```text
面积 120 × 3    = 360   ← 权重 3，很重要
卧室 3   × 1    = 3     ← 权重 1，一般
距离 2   × 0.5  = 1     ← 权重 0.5，不太重要
─────────────────────
加起来          = 364   ← 加权求和
```

**"加权" = 各乘各的重要性系数，"求和" = 加起来。** 对比普通求和（120+3+2=125）：那是一视同仁，距离和面积影响力一样大，不合理。

一个神经元做的事就是"加权求和 + 激活函数"；模型"学习"学的就是这些权重（见 [[神经网络]]、[[大模型如何训练]]）。

---

## 3. 点积（dot product）

**两个向量对应格子相乘、再全部加起来**，得到一个数：

```text
房子向量:  [120,   3,   2 ]
             ×     ×    ×      ← 上下对齐，各乘各的
权重向量:  [ 3,    1,  0.5]
             ↓     ↓    ↓
           360  +  3  +  1  = 364
```

三个易错点：

- **"对应位置"的"位置" = 格子编号**（第 1 格乘第 1 格），和 Transformer 的"位置编码"（词在句子里的位置）是两回事，纯属中文撞车
- 位置**不参与计算**，只决定谁跟谁配对——两队人握手，1 号跟 1 号握，号码牌决定配对，握手的是格子里的数
- 点积是对称的，**两排数字互为权重**——点积就是加权求和的另一个名字

---

## 4. 点积为什么能衡量"像不像"

玩具例子（3 个格子，假装标上含义；真实模型几千格、含义是训练自发形成的）：

```text
格子含义:        [跟吃有关, 跟火锅有关, 跟编程有关]

Q "附近的火锅店" = [1,  2,  0]
K 海底捞         = [2,  3,  0]
K 川菜馆         = [2,  1,  0]
K Python教程     = [0, -1,  2]

Q·K(海底捞) = 1×2 + 2×3 + 0×0  = 8    ← 非常匹配
Q·K(川菜馆) = 1×2 + 2×1 + 0×0  = 4    ← 沾点边
Q·K(Python) = 1×0 + 2×(-1) + 0×2 = -2 ← 毫不相干
```

一格要贡献大正数，必须**两个向量在这格上都有大数字**——"我们俩在同一特征上都很强"。点积大 = 强项重合 = 语义相近。注意力的 Q·K 匹配分（[[Transformer]]）、RAG 的相似度检索（[[Vector Database]]）算的都是它。

---

## 5. 向量长度的规矩

**同一模型内，所有向量长度严格相等**（这个长度叫"维度"：原始 Transformer 512，BERT-base 768，LLaMA-2 4096）。三个原因：

| 原因 | 说明 |
|---|---|
| 点积要求格子对齐 | 3 格对 5 格，多出的 2 格找谁乘？ |
| 权重矩阵尺寸固定 | 模具只接受固定尺寸的原料 |
| 残差连接要求 x+F(x) 能相加 | 对应格子相加，前后必须等长 |

**易混点：句子变长，变的是向量"个数"不是"长度"**。"我爱火锅"是 4 个向量，千字文是一千多个向量，每个都还是 768 格。数据形状 = 词数 × 维度，行数随句子变，列数永远固定。

**推论**：不同模型维度不同、坐标系不通 → 向量互相不可比 → RAG 换 embedding 模型要整库重灌。
