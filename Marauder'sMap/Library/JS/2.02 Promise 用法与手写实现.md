# Promise 用法与手写实现

## TL;DR

**Promise 是状态机：pending 只能单向变为 fulfilled 或 rejected，一锤定音**。then 返回新 Promise 实现链式调用；四个静态组合方法记差异——all 一错全错、allSettled 全收、race 先到先得、any 一成即成。手写核心三件事：状态机 + 回调收集 + then 返回值解析。

---

## 1. 三态与链式调用

```js
new Promise((resolve, reject) => { ... })   // executor 同步执行
  .then(onFulfilled, onRejected)            // 返回【新】Promise
  .catch(onRejected)                        // = then(null, fn)
  .finally(fn);                             // 不接收值、透传结果
```

链式规则（then 返回的新 Promise 如何定状态）：

- 回调返回普通值 → 新 Promise 以该值 fulfilled；
- 回调返回 Promise/thenable → **跟随**它的状态；
- 回调抛错 → 新 Promise rejected；
- 值穿透：then 的参数不是函数时被忽略，值向后透传——`then(null).then(v => ...)` 拿得到值。

为什么 try/catch 抓不到异步回调里的错：回调在**未来的事件循环**执行，早已离开 try 块的调用栈。Promise 把「未来的错」变成 rejected 状态沿链传递，async/await 则让 try/catch 重新有效。

## 2. 四个静态组合方法

| 方法 | 成功条件 | 失败条件 | 典型场景 |
|---|---|---|---|
| `all` | 全部成功（结果按传入顺序） | 任一失败立即 reject | 页面并行请求，缺一不可 |
| `allSettled` | 永不 reject，逐项 `{status, value/reason}` | — | 批量任务要知道每个结果 |
| `race` | 第一个 settle 的结果 | 同左 | 超时控制 |
| `any` | 任一成功 | 全部失败（AggregateError） | 多源容灾，谁快用谁 |

手写 all（判分点：计数器而不是数组 length、保序、空数组直接 resolve）：

```js
Promise.myAll = (list) =>
  new Promise((resolve, reject) => {
    const results = [];
    let count = 0;
    const items = [...list];
    if (items.length === 0) return resolve([]);
    items.forEach((p, i) => {
      Promise.resolve(p).then(   // 兼容非 Promise 元素
        (v) => {
          results[i] = v;         // 按位置存，保证顺序
          if (++count === items.length) resolve(results);
        },
        reject,                   // 任一失败直接 reject
      );
    });
  });
```

allSettled 的手写 = 把每个 p 包一层 `then(v => ({status:'fulfilled', value:v}), e => ({status:'rejected', reason:e}))` 再交给 all。

## 3. 手写 Promise 核心（A+ 规范骨架）

```js
class MyPromise {
  #state = 'pending';
  #value;
  #callbacks = [];               // pending 期间收集 [onFulfilled, onRejected]

  constructor(executor) {
    const settle = (state, value) => {
      if (this.#state !== 'pending') return;   // 状态不可逆
      this.#state = state;
      this.#value = value;
      this.#callbacks.forEach(run => run());
    };
    try {
      executor(v => settle('fulfilled', v), e => settle('rejected', e));
    } catch (e) { settle('rejected', e); }
  }

  then(onFulfilled, onRejected) {
    // 非函数参数 → 制造透传
    onFulfilled = typeof onFulfilled === 'function' ? onFulfilled : v => v;
    onRejected  = typeof onRejected  === 'function' ? onRejected  : e => { throw e; };

    const p2 = new MyPromise((resolve, reject) => {
      const run = () => queueMicrotask(() => {   // 回调必须异步（微任务）
        try {
          const cb = this.#state === 'fulfilled' ? onFulfilled : onRejected;
          resolvePromise(p2, cb(this.#value), resolve, reject);
        } catch (e) { reject(e); }
      });
      this.#state === 'pending' ? this.#callbacks.push(run) : run();
    });
    return p2;
  }
}

// then 返回值解析：区分普通值 / thenable，防循环引用、防重复调用
function resolvePromise(p2, x, resolve, reject) {
  if (x === p2) return reject(new TypeError('循环引用'));
  if ((typeof x === 'object' && x !== null) || typeof x === 'function') {
    let called = false;
    try {
      const then = x.then;
      if (typeof then === 'function') {
        then.call(x,
          y => { if (!called) { called = true; resolvePromise(p2, y, resolve, reject); } },
          e => { if (!called) { called = true; reject(e); } });
      } else resolve(x);
    } catch (e) { if (!called) { called = true; reject(e); } }
  } else resolve(x);
}
```

五个判分点：**状态不可逆**、**pending 时收集回调**（发布订阅）、**回调走微任务**、**then 返回新 Promise**、**resolvePromise 处理 thenable 与循环引用**。

## 4. 高频衍生手写题

```js
// sleep：万金油
const sleep = ms => new Promise(r => setTimeout(r, ms));

// promisify：错误优先回调 → Promise（Node util.promisify 思路）
const promisify = fn => (...args) =>
  new Promise((resolve, reject) => {
    fn(...args, (err, res) => (err ? reject(err) : resolve(res)));
  });

// retry：失败自动重试 + 间隔
const retry = async (task, times = 3, delay = 0) => {
  for (let i = 0; i < times; i++) {
    try { return await task(); }
    catch (e) {
      if (i === times - 1) throw e;
      if (delay) await sleep(delay);
    }
  }
};

// 超时控制：race 的标准应用
const withTimeout = (p, ms) =>
  Promise.race([p, sleep(ms).then(() => { throw new Error('timeout'); })]);
```

**「中断」Promise**：Promise 本身不可取消，所谓中断有两层做法——

1. **race 包装**（让结果不再被关心）：`Promise.race([p, interrupter])`，暴露 interrupter 的 reject 作为 abort()；原任务仍在跑，只是结果被忽略。
2. **真正取消底层操作**：用 `AbortController`——fetch 原生支持 `signal`，自定义任务监听 `signal.addEventListener('abort', ...)` 清理定时器/连接。现代答案要提到它。

## 面试问答

### Q: Promise 解决了什么问题？

满分答案：回调地狱的两大痛点——嵌套导致的可读性问题，和「控制反转」（回调交给第三方，可能不调/多调）。Promise 用状态机保证结果只 settle 一次，链式调用把嵌套拉平，错误沿链传播到统一的 catch；配合 async/await 进一步获得同步书写体验和可用的 try/catch。

### Q: Promise.all、allSettled、race、any 的区别？

满分答案：all 全成才成、一败即败，结果保序，适合缺一不可的并行请求；allSettled 永不失败，返回每项的 status/value/reason，适合批量任务收尾；race 第一个 settle 定结果，标准用途是超时控制；any 第一个成功定结果，全败抛 AggregateError，适合多源容灾。手写 all 的要点：计数器判完成、按下标保序、Promise.resolve 包装非 Promise 项、空数组直接 resolve。

### Q: 手写 Promise 的核心要点？

满分答案：五点——状态机单向不可逆；executor 同步执行、抛错转 reject；pending 时把 then 回调收集进队列（发布订阅），settle 后统一触发；then 返回新 Promise，回调用微任务执行；返回值经 resolvePromise 解析——普通值直接 resolve，thenable 递归展开，返回自身抛循环引用 TypeError，且 called 标记防多次调用。

### Q: 如何取消一个 Promise？

满分答案：分两层。Promise 状态本身不可从外部取消，常见「中断」是 race 包装一个可手动 reject 的 Promise，让业务不再等待原结果——但底层任务仍在执行。要真取消底层操作用 AbortController：fetch 传 signal 即可中止请求，自定义异步任务监听 abort 事件做清理。回答时区分「忽略结果」和「终止操作」两个概念是关键。

### Q: try/catch 为什么捕获不到 setTimeout 回调里的错误？

满分答案：try 只保护当前调用栈，回调在之后的事件循环里以全新调用栈执行，错误抛出时 try 块早已退出。解决：把异步包成 Promise，错误变成 rejection 沿链传递，用 catch 或 async/await + try/catch 捕获；全局兜底用 unhandledrejection 事件。
