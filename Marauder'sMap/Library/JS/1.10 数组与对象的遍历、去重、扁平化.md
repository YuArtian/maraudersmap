# 数组与对象的遍历、去重、扁平化

## TL;DR

**遍历数组值用 for...of，遍历对象用 Object.keys/entries，要中途退出别用 forEach**。去重首选 `[...new Set(arr)]`（对象数组按唯一键用 Map），扁平化首选 `arr.flat(Infinity)`，手写版本考的是递归和 reduce。

> for...in 与 for...of 的机制与陷阱详见 [[for 循环]]。

---

## 1. 数组遍历方法选型

| 方法 | 返回 | 能否中途退出 | 适用 |
|---|---|---|---|
| `for` / `for...of` | — | break ✓ | 需要中断、await 的场景 |
| `forEach(fn)` | undefined | ✗ | 纯副作用遍历 |
| `map(fn)` | 新数组 | ✗ | 一对一变换 |
| `filter(fn)` | 新数组 | ✗ | 筛选 |
| `some(fn)` | boolean | 命中即停 | 「存在一个」 |
| `every(fn)` | boolean | 失败即停 | 「全部满足」 |
| `find` / `findIndex` | 元素 / 下标 | 命中即停 | 查找 |
| `reduce(fn, init)` | 累计值 | ✗ | 聚合、万能改写 |

高频细节：

- **forEach 与 map 的区别**：forEach 返回 undefined，map 返回等长新数组；都不改变原数组（但回调里可以改）、都跳过稀疏数组的空位。
- **forEach 无法 break/return 中断**：`return` 只是跳过本次回调。要中断就换 `some`（回调返回 true 停）、`every`（返回 false 停）或干脆 for...of。
- **forEach 里 await 不生效**（forEach 不等待回调的 Promise），异步遍历用 `for...of` + await，并发则 `Promise.all(arr.map(...))`——详见 [[2.04 并发控制与耗时任务优化]]。

## 2. 对象遍历

```js
Object.keys(obj)      // 自身可枚举字符串键
Object.values(obj)    // 对应的值
Object.entries(obj)   // [key, value] 对，配合 for...of 解构最顺手
Object.getOwnPropertyNames(obj)   // 自身全部字符串键（含不可枚举）
Object.getOwnPropertySymbols(obj) // 自身 Symbol 键
Reflect.ownKeys(obj)  // 自身所有键 = 上面两者之和
```

范围记忆：**for...in 是唯一会查原型链的**（需 hasOwnProperty 过滤）；keys/values/entries 只看「自身 + 可枚举 + 字符串键」；要一网打尽用 Reflect.ownKeys。

自定义对象想被 for...of 遍历，实现 `Symbol.iterator` 即可：

```js
const range = {
  from: 1, to: 3,
  [Symbol.iterator]() {
    let cur = this.from, last = this.to;
    return { next: () => cur <= last
      ? { value: cur++, done: false }
      : { value: undefined, done: true } };
  },
};
[...range]  // [1, 2, 3]
```

## 3. 数组去重

```js
// ① 原始值数组：一行
[...new Set(arr)]                    // NaN 也能去重（SameValueZero）

// ② 对象数组按业务唯一键：Map
[...new Map(list.map(o => [o.id, o])).values()]

// ③ 面试手写：不借助 Set，兼顾 NaN
function unique(arr) {
  const res = [];
  for (const item of arr) {
    // includes 用 SameValueZero，能识别 NaN；indexOf 不能
    if (!res.includes(item)) res.push(item);
  }
  return res;
}
```

进阶版「内容相同的对象也算重复」的思路：写一个 `isEqual`（原始值用 `Object.is`，对象比 key 数量再递归逐 key 比较），外层双循环 + `continue outer` 标签跳出。这题真正考察的是**深比较**。

## 4. 数组扁平化

```js
// ① 标准 API（ES2019）
arr.flat(Infinity)

// ② 递归 reduce（手写高频）
function flatten(arr) {
  return arr.reduce(
    (acc, cur) => acc.concat(Array.isArray(cur) ? flatten(cur) : cur),
    [],
  );
}

// ③ 迭代 + 栈（防深层递归爆栈）
function flattenIter(arr) {
  const stack = [...arr], res = [];
  while (stack.length) {
    const top = stack.pop();
    Array.isArray(top) ? stack.push(...top) : res.push(top);
  }
  return res.reverse();
}

// ④ 只含数字时的取巧写法
arr.toString().split(',').map(Number)
```

指定深度版本：给 ② 加个 depth 参数，`depth > 0` 才递归、每层减一，就是 `flat(depth)` 的 polyfill。

## 5. reduce 的两个经典应用

```js
// 用 reduce 实现 map
Array.prototype.myMap = function (fn, thisArg) {
  return this.reduce((acc, cur, i, arr) => {
    acc[i] = fn.call(thisArg, cur, i, arr);   // 注意用 acc[i] 保留稀疏位语义
    return acc;
  }, []);
};

// 统计出现次数
const count = list.reduce((acc, k) => (acc[k] = (acc[k] ?? 0) + 1, acc), {});
```

手写 reduce 本体的判分点：没传初始值时把第一个元素当累计值、从下标 1 开始；空数组且无初始值要抛 TypeError。

## 面试问答

### Q: forEach 和 map 的区别？

满分答案：map 返回一对一变换后的新数组，forEach 返回 undefined 只做副作用；两者都不改变原数组、跳过稀疏空位、无法 break。加分点：forEach 不等待异步回调，串行异步要用 for...of + await；需要中断语义时用 some/every/find 代替。

### Q: forEach 为什么不能 break？想中断怎么办？

满分答案：forEach 的回调是逐个调用的函数，return 只结束当次回调，规范没有提供中断机制（除了抛异常这种反模式）。要中断：some（回调返回 true 即停）、every（返回 false 即停）、find/findIndex（命中即停），或直接 for...of + break——它还天然支持 await 和 continue。

### Q: 数组去重有哪些方法？

满分答案：首选 [...new Set(arr)]，一行且 NaN 也能去重；对象数组按唯一键用 new Map(list.map(o => [o.id, o])) 再取 values；手写通用版用 includes（SameValueZero，能识别 NaN，indexOf 不能）。若要求「内容相同的对象算重复」，本质是深比较问题：递归逐 key 比较，原始值用 Object.is。

### Q: 手写数组扁平化？flat(Infinity) 的 polyfill？

满分答案：递归 reduce 版三行——reduce 累计，元素是数组就递归展开再 concat。带深度参数则 depth > 0 才递归、每层 depth-1。防爆栈用显式栈迭代：pop 出来是数组就展开压回，否则收集，最后 reverse。加分点：flat 还会顺带清掉稀疏数组的空位。

### Q: Object.keys 和 for...in 的区别？

满分答案：两者都只看可枚举字符串键，但 for...in 会沿原型链向上查，Object.keys 只查自身。要含不可枚举的用 getOwnPropertyNames，要 Symbol 键用 getOwnPropertySymbols，全都要用 Reflect.ownKeys。
