# 深拷贝与浅拷贝

## TL;DR

**浅拷贝只复制一层（嵌套对象共享引用），深拷贝递归复制整棵树**。现代首选原生 `structuredClone`；手写深拷贝的判分点是：递归 + 特殊类型（Date/RegExp/Map/Set）+ **用 WeakMap 解决循环引用**。`JSON.parse(JSON.stringify())` 是残缺方案，要能列出它丢什么。

---

## 1. 浅拷贝的所有姿势

```js
{ ...obj }                    // 展开运算符
Object.assign({}, obj)        // 等价
arr.slice() / [...arr]        // 数组
Array.from(arr)
```

共同点：只复制第一层的值/引用，`copy.inner === obj.inner`。改嵌套对象会互相影响——这是「为什么我改了副本原对象也变了」的标准病因。

---

## 2. JSON.parse(JSON.stringify(obj)) 的缺陷清单（高频考点）

| 输入 | 结果 |
|---|---|
| `undefined`、函数、Symbol 值 | **丢失**（对象里直接消失，数组里变 null） |
| `Date` | 变成字符串 |
| `RegExp`、`Error` | 变成 `{}` |
| `NaN`、`Infinity` | 变成 null |
| `Map`、`Set` | 变成 `{}` |
| 循环引用 | **直接抛错** |
| 原型链 | 丢失（全部变纯对象） |

只适合「纯 JSON 数据」的快速克隆。

---

## 3. 原生方案：structuredClone

```js
const copy = structuredClone(obj);
```

现代浏览器与 Node 17+ 原生支持：处理循环引用、Date、RegExp、Map、Set、ArrayBuffer、Blob 等结构化克隆算法支持的一切。仍然不能克隆：**函数、DOM 节点、属性描述符/原型链**（抛 DataCloneError 或忽略）。面试先答它，再展示手写能力。

## 4. 手写深拷贝（完整判分版）

```js
function deepClone(target, map = new WeakMap()) {
  // 1) 原始值与函数直接返回（函数一般共享而不是克隆）
  if (target === null || typeof target !== 'object') return target;

  // 2) 特殊内置类型
  if (target instanceof Date) return new Date(target);
  if (target instanceof RegExp) return new RegExp(target.source, target.flags);
  if (target instanceof Map) {
    const m = new Map();
    map.set(target, m);
    target.forEach((v, k) => m.set(deepClone(k, map), deepClone(v, map)));
    return m;
  }
  if (target instanceof Set) {
    const s = new Set();
    map.set(target, s);
    target.forEach(v => s.add(deepClone(v, map)));
    return s;
  }

  // 3) 循环引用：拷贝过就直接还缓存
  if (map.has(target)) return map.get(target);

  // 4) 保留原型（数组/普通对象/自定义类实例通吃）
  const clone = Object.create(Object.getPrototypeOf(target));
  map.set(target, clone);               // 先登记再递归，防环
  for (const key of Reflect.ownKeys(target)) {   // 含 Symbol 键
    clone[key] = deepClone(target[key], map);
  }
  return clone;
}
```

答题时主动报判分点：

1. **WeakMap 记忆已拷贝对象**——既解循环引用，又保证「同一个子对象拷贝后仍是同一个」；用 WeakMap 而非 Map 是为了不阻碍原对象回收；
2. **先 set 再递归**，否则环上就死循环了；
3. Date/RegExp/Map/Set 各自 new；
4. `Reflect.ownKeys` 连 Symbol 键一起拷；`Object.create(getPrototypeOf)` 保留原型。

爆栈加分项：超深对象可改**显式栈迭代**（同扁平化的思路，见 [[1.10 数组与对象的遍历、去重、扁平化]]）。

## 5. 衍生题：lodash 的 get / set / merge

```js
// get：安全取深层属性，路径 'a[0].b.c'
function get(obj, path, defaultValue) {
  const keys = Array.isArray(path)
    ? path
    : path.replace(/\[(\d+)\]/g, '.$1').split('.').filter(Boolean);
  let cur = obj;
  for (const k of keys) {
    if (cur == null) return defaultValue;
    cur = cur[k];
  }
  return cur === undefined ? defaultValue : cur;
}

// set：沿路径写入，途中缺失的层级按 key 类型补对象/数组
function set(obj, path, value) {
  const keys = path.replace(/\[(\d+)\]/g, '.$1').split('.').filter(Boolean);
  keys.reduce((cur, k, i) => {
    if (i === keys.length - 1) { cur[k] = value; return; }
    if (cur[k] == null) cur[k] = /^\d+$/.test(keys[i + 1]) ? [] : {};
    return cur[k];
  }, obj);
  return obj;
}

// merge：与浅合并的区别——两边同 key 且都是对象时递归合并而非整体覆盖
function merge(target, source) {
  for (const key of Object.keys(source)) {
    const t = target[key], s = source[key];
    if (t && s && typeof t === 'object' && typeof s === 'object') merge(t, s);
    else if (s !== undefined) target[key] = s;
  }
  return target;
}
```

考点本质都一样：**路径解析 + 递归/迭代地走引用**。现代替代：get 的场景多数被可选链 `a?.[0]?.b ?? def` 覆盖。

## 面试问答

### Q: 深拷贝和浅拷贝的区别？各有哪些实现？

满分答案：浅拷贝复制一层，嵌套引用共享——展开运算符、Object.assign、slice；深拷贝递归复制整棵树，互不影响——首选原生 structuredClone（支持循环引用和大部分内置类型，但不能克隆函数和 DOM），JSON 法只适合纯数据（丢 undefined/函数/Date 类型、循环引用报错），要求完整就手写递归。

### Q: 手写深拷贝要处理哪些边界？

满分答案：五类——原始值直接返回；Date/RegExp/Map/Set 等内置类型分别重建；循环引用用 WeakMap 缓存「原对象 → 副本」，进入递归前先登记；Symbol 键用 Reflect.ownKeys 覆盖；原型用 Object.create(Object.getPrototypeOf()) 保留。选 WeakMap 是因为弱引用不影响垃圾回收。超深结构可用显式栈改迭代防爆栈。

### Q: structuredClone 和手写深拷贝怎么选？

满分答案：业务代码直接 structuredClone——原生、快、处理循环引用；它的边界是函数、DOM 节点、原型链和属性描述符不支持。需要克隆类实例（保留原型）、克隆含函数的配置对象，或要自定义拷贝策略（如某些字段浅拷）时才手写。lodash cloneDeep 是工程上的稳妥兜底。
